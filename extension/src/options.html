Settings are synced across your Chrome profiles.

Base URL of your running tesserae serve. Clips POST to <endpoint>/api/clip. Same machine: use 127.0.0.1 (not localhost — the server is IPv4-only). Another machine: use the server's LAN IP and run it with tesserae serve --host 0.0.0.0; saving a non-local endpoint will ask for permission to reach that host.

Sent as the X-Tesserae-Token header. Set this only if you run the server with TESSERAE_CLIP_TOKEN=… (recommended when the endpoint is exposed on a LAN/public IP) — it must match exactly.

Project alias to clip into. Needed only when the server runs in fleet mode (tesserae serve with no --project, serving every registered project) and more than one project is registered. Sent as the project field of the clip body. Empty is fine for a normal single-project tesserae serve.

Comma-separated. Pre-filled in the popup for every clip.
