Выпущено **2026-07-11** · [PyPI](https://pypi.org/project/tesserae/0.19.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.19.0) · `pip install --upgrade tesserae==0.19.0`

Релиз конца жизненного цикла бэкендов. Начиная с v0.18.0 цикл обновления и извлечения графа знаний по умолчанию полностью собственный — типизированный конвейер ResearchGraph записывает граф (включая нативное извлечение кодового графа), а `ask` планирует извлечение по нему с помощью LLM. Этот релиз удаляет два прикрученных сбоку бэкенда, которые больше не оправдывали своё содержание.

## understand-anything: удалён

Его единственный вклад — слияние внешне сгенерированного `knowledge-graph.json` с узлами структуры кода в ResearchGraph — стал избыточным с момента появления нативного экстрактора кодового графа. Адаптер, модуль refresh, слияние на этапе компиляции, обнаружение зависимостей и записи в setup удалены. `tesserae integrations refresh understand-anything` печатает однострочный указатель на нативный инжест кода и выходит с кодом 2. Старые конфигурации с записью understand-anything в `external_tools` загружаются с одним примечанием; узлы, созданные UA в существующих графах, остаются действительными.

## cognee: удалён

cognee дублировал граф *наружу* в собственное хранилище и никогда ничего не возвращал обратно; до 0.18 он к тому же засорял вывод `ask` логами и запасным вариантом с `OperationalError` на установках по умолчанию. После одного релиза льготного периода с выключением по умолчанию он полностью удалён: модули adapter/direct/query, проход cognify на этапе компиляции и экспорт бандла, экстра `[cognee]`, подсказки мастера настройки и ссылки в схеме MCP (~1,100 LOC и 6 файлов тестов). `query --backend cognee` и каждый флаг `--cognee-*` / `--enable-cognee` печатают однострочную заглушку об удалении и выходят с кодом 2. Конфигурации с секцией `memory_backends.cognee` по-прежнему загружаются и компилируются — ровно с одним примечанием на процесс.

## rag-anything: оставлен, намеренно

Единственный бэкенд с возможностью, которой графу знаний действительно не хватает — мультимодальный документный RAG (PDF, изображения) — остаётся как опциональная экстра `tesserae[raganything]`, выключенная по умолчанию и доступная через `tesserae query --backend raganything`.

## Ломающие изменения

Согласно конвенции проекта, ничто не падает молча — каждая удалённая поверхность печатает свою замену или объяснение и выходит с кодом 2: `integrations refresh understand-anything`, `query --backend cognee`, `--cognee-search-type`, `--cognee-dataset`, `--enable-cognee` и остальные флаги setup/extract `--cognee-*`. Итог двух удалений: **−5,500 строк** против +1,600, при полностью зелёном наборе тестов (2,251 passed).
