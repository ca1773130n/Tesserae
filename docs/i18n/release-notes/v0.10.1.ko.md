**2026-06-20** 릴리스됨 · [PyPI](https://pypi.org/project/tesserae/0.10.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.1) · `pip install --upgrade tesserae==0.10.1`

버그 수정 릴리스입니다. v0.10.0 위에 바로 올려도 됩니다.

## 수정 사항

- **`tesserae config status`는 이제 LLM 백엔드뿐만 아니라 전체 시스템 전체 설정을 표시합니다.** 해석된 provider/effort를 보고했지만 `tesserae config setup`이 관리하는 다른 모든 것을 숨겼으므로 cognee 활성화 및 선택적 의존성 상태가 보이지 않았습니다. 이제 `status`는 **시스템 전체 설정** 섹션(cognee on/off + mode)과 **선택적 의존성** 섹션(memex / cognee / raganything / understand-anything — 설치 여부)을 추가하고, liveness ping 전에 출력되므로 항상 표시됩니다.

## 이 릴리스에도 포함됨

- **cognee** 어댑터가 **cognee 1.x**로 포팅되었고 시스템 전체 cognee 활성화(`config setup --enable-cognee`)가 출시되어, 단일 전역 설정이 모든 프로젝트에 대해 cognify pass를 켭니다. self-capture 세션 필터는 cognee 1.x의 자신의 writing-assistant 프롬프트를 인식하도록 확장되었습니다.

## v0.10.0에서 업그레이드

바로 올려도 됩니다. `tesserae config status`를 실행하여 보다 완전한 시스템 전체 그림을 보세요.
