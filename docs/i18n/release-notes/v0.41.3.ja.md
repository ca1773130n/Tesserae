リリース **2026-09-16** · [PyPI](https://pypi.org/project/tesserae/0.41.3/) · [GitHub リリース](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.3) · `pip install --upgrade tesserae==0.41.3`

v0.41.2 はコマンド監査で最も深刻な 12 件を閉じました。今回は残る 19 件、つまりすべてを
閉じます。

## 何が変わったか

- **7 つのコマンドが誤りに文章で答えます。** 誤ったパス、解釈できない日付、プロバイダでは
  ない設定値 — これらはいずれも以前はスタックトレースで終わっていました。最悪だったのは
  `tesserae compile` で、読めないファイル 1 つのためにコーパス全体を中断していました。今は
  スキップしたものを名指しし、残りをコンパイルします。
- **7 つのコマンドが起きていないことを報告しなくなりました。** `status` は一度もコンパイル
  されていないプロジェクトにコンパイル時刻を表示していました。`config status` はファイルが
  設定した値を既定値のせいにしていました。`schema-drift` はクラスタリングしていない型に
  ついてクラスタが見つからなかったと述べていました。`graph-map` は受け取ったものと同一の
  ページングカーソルを返し、それに従う呼び出し側は永遠に繰り返していました。
- **5 つのコマンドが拒否すべきものを受け入れなくなりました。** 綴りを誤ったエージェント名が
  本物のように答えていました。`projects register` は 2 つのディレクトリが同じ名前を生むとき
  別のプロジェクトを黙って登録解除していました。`domains status` はプロジェクトでない
  ディレクトリにコンパイルを実行せよと告げていました。
- **プレビューがプレビューするものをプレビューします。** `sessions prune-internal
  --dry-run` は削除する件数を意味する場所に、保存済みレコードの総数を出力していました。

## アップグレード

移行するものはありません。以前は静かに 0 で終わっていた場所で 2 で終わるコマンドが増えたので、
その沈黙に頼っていたスクリプトは、すでに起きていた失敗を報告し始めます。
