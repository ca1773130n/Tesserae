リリース **2026-06-30** · [PyPI](https://pypi.org/project/tesserae/0.13.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.13.1) · `pip install --upgrade tesserae==0.13.1`

小さな追加リリース: `config.json` を手で編集する代わりに、CLI からプロジェクトのコンパイル スコープを管理できます。

## `tesserae sources` — add / list / remove

`tesserae compile` (引数なし) はプロジェクトの `sources` リストのディレクトリをコンパイルします。これで CLI からそのリストを管理できます。ソースは **ローカル** (プロジェクト内) または **グローバル** (ディスク上のどこでも) になります:

```bash
tesserae sources add docs                 # local  — inside the project (stored project-relative)
tesserae sources add /data/shared-notes   # global — an absolute path outside the project
tesserae sources add ../sibling-project   # global — a relative path that escapes the root
tesserae sources list                     # tags each source local/global, flags missing ones
tesserae sources remove docs
```

- プロジェクト **内** のパスはプロジェクト相対パスで保存されます (`config.json` がポータブルのままになるように)。**外** のものは **絶対** パスで保存されます。どちらもコンパイル時に解決されるため、グローバル ソースはローカル ソースと同じようにコンパイルされます。
- 追加は **解決された場所で重複排除** されます。同じディレクトリの絶対形式と `../` 相対形式は二重カウントされません。
- `list` は各エントリを `local` / `global` でマークし、ディスク上に存在しなくなったものにフラグを付けます。

以前は `sources` 配列は `init` 時にのみ設定されました (そして `init` を再実行するとコンフィグが追加されるのではなく再構築されます)。これはプロジェクトのスコープを拡大するための追加的で非破壊的な方法です。
