リリース **2026-09-17** · [PyPI](https://pypi.org/project/tesserae/0.41.5/) · [GitHub リリース](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.5) · `pip install --upgrade tesserae==0.41.5`

71,783 件の主張を持つグラフで、夜間の矛盾チェックが止まりました。矛盾検出がすべての主張ペアを比較し、
ペアごとに両方のテキストを作り直していたため、終わりませんでした。正しい答えはペアなしでした。
`CONTRADICTING_CLAIMS` lint チェックにも同じループがありました。

## 何が変わったか

- **矛盾検出は、矛盾しうる主張どうしだけを比較します。** 矛盾には "outperforms" と言う主張と
  "is outperformed by" と言う主張が 1 つずつ必要です。主張をどちらを言っているかで分け、両側から 1 つずつ
  取ったペアだけを比較するようになりました。片側が空なら何も比較しません。そのグラフと同じ形の合成主張は
  今は 0.042 秒で終わります。
- **`lint` も同じ修正を受けました。** `CONTRADICTING_CLAIMS` チェックも同じ全ペアのループでした。
- **結果は変わりません。** どちらも以前とまったく同じ結果を返し、数千のランダムなグラフで旧コードと
  突き合わせて確認しました。

## アップグレード

移行作業はありません。1 つのトピックの両側に数千件ずつ主張があるグラフは、今も時間がかかります。
そのペア一つひとつが答えの一部だからです。
