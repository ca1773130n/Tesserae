Released **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.0) · `pip install --upgrade tesserae==0.10.0`

Eine Feature-Version: Wissensaustausch, schnellere Sitzungssuche und einmaliges maschinenweites Setup. Alles ist additiv — ein einfaches `tesserae compile` bleibt unverändert, und projektspezifische Konfiguration überschreibt weiterhin die neuen globalen Vorgaben.

## 1. Google OKF v0.1 Import/Export

`tesserae export okf` schreibt den Graphen als ein [Google **Open Knowledge Format** v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog) Bundle — ein Baum von Markdown-Dateien mit YAML-Frontmatter und relativen Link-Relationen. `--import DIR` liest es zurück. Tesseraes eigene Bundles führen **verlustfrei** durch einen `x_tesserae` Frontmatter-Namespace hin und her (echte Knoten-IDs + typisierte Kanten + Kantensmetadaten); fremde Bundles importieren „best-effort" (unbekannter `type` → `Concept`, untypierte Links → `references`), tolerierend fehlende Typen und defekte/symverlinkte Dateien gemäß der Spezifikation.

## 2. Schnelle Transkriptsuche auf dem Sessions-Dashboard

Das Sessions-Dashboard von `tesserae serve` erhält ein Volltextsuchfeld über jeden indizierten Claude/Codex-Transkript, angetrieben von [`nicosuave/memex`](https://github.com/nicosuave/memex) (BM25). Es ist optional und reaktionsfähig: ohne die `memex` Binärdatei zeigt das Feld eine umsetzbare Nachricht und der Rest des Dashboards ist unbeeinträchtigt. Der `GET /api/transcript-search` Endpunkt ist auf Same-Origin/Loopback-Anrufer begrenzt, damit eine besuchte Webseite die lokale Geschichte nicht abtasten kann, und Ergebnisse werden über `textContent` gerendert (keine Markup-Injektion).

## 3. Memex-ähnliche Lesedisziplin für MCP

Inspiriert von Databricks' „programmierbarem Scratchpad" akzeptiert `compile_context` nun `preview=N`: anstatt einen enormen Text in den Kontext des Agenten zu dumpen, gibt es eine begrenzte Vorschau plus einen inhaltsgeräte **Handle** zurück, und das neue **`get_handle`** Tool holt den Rest auf Anfrage. Standard `preview=0` behält das vollständige Verhalten bei.

## 4. Extraktionsqualitätssignale

Sitzungsergebnisse tragen nun `confidence` + `confidence_rationale` + `revisit_signals` aus dem Extraktor destilliert (Ideen von Jonasb8/memex; kein Code kopiert). Sie fahren den inhaltsgeräuten Extraktions-Cache, sodass sie byte-idempotent bleiben, und erscheinen im `fresh_insights` MCP-Tool als Flags (nie Wahrheitsgarantien).

## 5. Maschinenweites Setup + Abhängigkeitsinstallationen

`tesserae config setup` setzt LLM-Vorgaben für **alle** Projekte (`--llm-provider`, `--reasoning-effort`, `--codex-home`, `--claude-config-dir`) **und** installiert optionale Abhängigkeiten (`--install all`) in einem Schritt. `tesserae config deps` listet/installiert **memex**, **cognee**, **raganything** und **understand-anything**; `tesserae config llm` erhielt `--reasoning-effort`; und `tesserae init` bietet an, memex während eines interaktiven Setups zu installieren. Auflösungsreihenfolge: env → Projektkonfiguration → maschinenweite Konfiguration → eingebaut.

## Upgrade von v0.9.x

Drop-in. Führen Sie `tesserae config setup` aus, um die maschinenweiten Vorgaben einmalig zu konfigurieren, oder behalten Sie Ihre projektspezifische `.tesserae/config.json` — sie gewinnt weiterhin.
