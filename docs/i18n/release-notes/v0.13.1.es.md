Un pequeño lanzamiento aditivo: gestiona el alcance de compilación de un proyecto desde la CLI en lugar de editar manualmente `config.json`.

## `tesserae sources` — agregar / listar / quitar

`tesserae compile` (sin argumentos) compila los directorios en la lista `sources` del proyecto. Ahora puedes gestionar esa lista desde la CLI — y una fuente puede ser **local** (dentro del proyecto) o **global** (en cualquier lugar del disco):

```bash
tesserae sources add docs                 # local  — inside the project (stored project-relative)
tesserae sources add /data/shared-notes   # global — an absolute path outside the project
tesserae sources add ../sibling-project   # global — a relative path that escapes the root
tesserae sources list                     # tags each source local/global, flags missing ones
tesserae sources remove docs
```

- Una ruta **dentro** del proyecto se almacena **relativa al proyecto** (por lo que `config.json` permanece portátil); cualquier cosa **fuera** se almacena **absoluta**. Ambas se resuelven en tiempo de compilación, por lo que una fuente global se compila exactamente como una local.
- Los agregados se **desduplican por ubicación resuelta** — las formas absolutas y relativas `../` del mismo directorio nunca se duplican.
- `list` marca cada entrada como `local` / `global` e indica cualquiera que ya no exista en el disco.

Anteriormente, la matriz `sources` solo se establecía en el tiempo `init` (y ejecutar `init` nuevamente reconstruye la configuración en lugar de agregarla). Esta es la forma aditiva y no destructiva de expandir el alcance de un proyecto.
