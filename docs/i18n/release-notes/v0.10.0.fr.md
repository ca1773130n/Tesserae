Publié **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.0) · `pip install --upgrade tesserae==0.10.0`

Une version de fonctionnalité : échange de connaissances, recherche plus rapide de sessions, et configuration machine-wide en une étape. Tout est additif — une simple `tesserae compile` reste inchangée, et la configuration par projet remplace toujours les nouveaux défauts globaux.

## 1. Import/export Google OKF v0.1

`tesserae export okf` écrit le graphe sous forme de bundle [Google **Open Knowledge Format** v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog) — un arborescence de fichiers Markdown avec frontmatter YAML et relations à liens relatifs. `--import DIR` en relit un. Les propres bundles Tesserae font un round-trip **sans perte** via un namespace frontmatter `x_tesserae` (vrais identifiants de nœud + arêtes typées + métadonnées d'arêtes) ; les bundles étrangers s'importent au mieux effort (type inconnu → `Concept`, liens non typés → `references`), en tolérant les types manquants et les fichiers cassés/symlinkés selon la spec.

## 2. Recherche rapide de transcriptions sur le tableau de bord des sessions

Le tableau de bord des sessions de `tesserae serve` gagne une boîte de recherche texte complète sur chaque transcription Claude/Codex indexée, alimentée par [`nicosuave/memex`](https://github.com/nicosuave/memex) (BM25). C'est optionnel et gracieux : sans le binaire `memex`, la boîte affiche un message actionnable et le reste du tableau de bord est inaffecté. Le point de terminaison `GET /api/transcript-search` est limité aux appelants same-origin/loopback pour qu'une page web visitée ne puisse pas sonder l'historique local, et les résultats se rendent via `textContent` (pas d'injection de markup).

## 3. Discipline de lecture de style memex pour MCP

Inspirée par le "programmable scratchpad" de Databricks, `compile_context` accepte maintenant `preview=N` : au lieu de décharger un corps énorme dans le contexte de l'agent, il retourne une prévisualisation bornée plus une **handle** content-keyed, et le nouvel outil **`get_handle`** pagine le reste à la demande. Le `preview=0` par défaut conserve le comportement d'un corps complet.

## 4. Signaux de qualité d'extraction

Les résultats de session transportent maintenant `confidence` + `confidence_rationale` + `revisit_signals` distillés de l'extracteur (idées de Jonasb8/memex ; aucun code copié). Ils chevaucher le cache d'extraction content-keyed, ils restent donc byte-idempotents, et surfacent dans l'outil MCP `fresh_insights` en tant que drapeaux (jamais des garanties de vérité).

## 5. Configuration machine-wide + installations de dépendances

`tesserae config setup` définit les défauts LLM pour **tous** les projets (`--llm-provider`, `--reasoning-effort`, `--codex-home`, `--claude-config-dir`) **et** installe les dépendances optionnelles (`--install all`) en une étape. `tesserae config deps` énumère/installe **memex**, **cognee**, **raganything**, et **understand-anything** ; `tesserae config llm` a gagné `--reasoning-effort` ; et `tesserae init` propose d'installer memex pendant une configuration interactive. Ordre de résolution : env → config du projet → config machine-wide → default.

## Mise à niveau depuis v0.9.x

Drop-in. Exécutez `tesserae config setup` pour configurer les défauts machine-wide une fois, ou gardez votre `.tesserae/config.json` par projet — il gagne toujours.
