Выпущено **2026-09-17** · [PyPI](https://pypi.org/project/tesserae/0.41.5/) · [GitHub релиз](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.5) · `pip install --upgrade tesserae==0.41.5`

Ночная проверка противоречий зависла на графе из 71,783 утверждений. Поиск противоречий сравнивал каждую
пару утверждений, заново собирая оба текста для каждой пары, и так и не завершился. Правильный ответ —
ни одной пары. В lint-проверке `CONTRADICTING_CLAIMS` был тот же цикл.

## Что изменилось

- **Поиск противоречий сравнивает только утверждения, которые могут противоречить друг другу.**
  Для противоречия нужно одно утверждение со словами "outperforms" и другое со словами "is outperformed
  by". Теперь утверждения делятся по тому, что из двух в них сказано, и сравниваются только пары с одним
  утверждением с каждой стороны. Если одна сторона пуста, ничего не сравнивается: синтетические
  утверждения той же формы, что и этот граф, теперь обрабатываются за 0.042 секунды.
- **`lint` получил то же исправление.** Его проверка `CONTRADICTING_CLAIMS` проходила тот же цикл по
  всем парам.
- **Результаты не изменились.** Обе функции возвращают ровно то же, что и раньше; это сверено со старым
  кодом на тысячах случайных графов.

## Обновление

Мигрировать нечего. Граф, где по обе стороны одной темы тысячи утверждений, по-прежнему обрабатывается
долго: каждая такая пара входит в ответ.
