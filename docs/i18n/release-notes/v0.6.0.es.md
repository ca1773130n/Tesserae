Fecha de publicación **2026-06-08** · [PyPI](https://pypi.org/project/tesserae/0.6.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.6.0) · `pip install --upgrade tesserae==0.6.0`

Tesserae 0.6.0 es un **rediseño de la CLI**. Todo lo que hace el motor estaba enterrado bajo `tesserae project <26 subcomandos ocultos>`, con un `setup` de 29 flags y un `compile` de 26; un `tesserae` a secas volcaba un parser de extracción en bruto. 0.6.0 reemplaza eso con un **árbol de comandos de verbos planos**: verbos cotidianos en el nivel superior, un puñado de pequeños grupos sustantivos, ayuda agrupada y `EXAMPLES` en cada comando. Es un **cambio incompatible**, tomado de forma deliberada antes de la 1.0: los comandos antiguos no se convierten silenciosamente en alias, sino que imprimen una redirección de una línea `… has moved → …` y salen con código 2, de modo que la migración resulta evidente en lugar de misteriosa. El motor, el grafo, las herramientas MCP y el servidor `tesserae_mcp` no han cambiado: esta versión trata por completo sobre la superficie que teclea una persona.

## 1. El nuevo árbol de comandos

```
tesserae <command>

EVERYDAY    init compile context ask serve status
AUTOMATION  engine refresh research
ANALYSIS    query lint
GROUPS      sessions vault export code config projects integrations extract
LAB         lab
```

- **Los verbos cotidianos están en el nivel superior.** `tesserae compile`, `tesserae serve`, `tesserae ask`, `tesserae context "…"`: sin el prefijo `project`.
- **`status`** es un nuevo resumen de solo lectura (recuentos de nodos/aristas, última compilación, vault, sitio).
- **`serve`** construye el sitio automáticamente cuando falta o está obsoleto (omítelo con `--no-build`).
- **Los comandos especializados viven en pequeños grupos sustantivos:** `sessions import|discover|list`, `vault sync|export|prune|set-root|sync-all`, `export harness|graphiti|site`, `code ingest|sync`, `config llm|show`, `projects register|list|activate|unregister|mcp-config`, `integrations refresh <name>`, `extract`, `lab evolve|schema-drift`.
- **`export site`** absorbe los antiguos verbos `build-site`, `deploy` (`--deploy`) y `watch` (`--watch`).
- **Ayuda raíz agrupada + `EXAMPLES`**: `tesserae` sin argumentos muestra el árbol agrupado; el `--help` de cada comando termina con ejemplos reales y ejecutables.

## 2. `init` y `compile` a dieta

- **`init`: de 29 a 8 flags.** Asistente por defecto; `--yes` lo ejecuta de forma no interactiva (las integraciones opcionales —Cognee, RAG-Anything, Understand-Anything— están **desactivadas** por defecto, y el color se desactiva automáticamente fuera de un TTY, subsumiendo los antiguos flags `--no-color`/`--no-cognee`/`--skip-*`). `--bare` escribe el espacio de trabajo sin el asistente. Los flags del backend de LLM (`--llm-provider`, `--claude-config-dir`, `--codex-home`) se mantienen.
- **`compile`: de 26 a 8 flags.** Los flags cotidianos permanecen (`--changed-only`, `--no-sessions`, `--limit`, `--refresh-integrations`, los tres flags de LLM y el `compile <paths>` ad hoc). Cada perilla de integración eliminada (kuzu/cognee/trends/vault-pull/…) se traslada a un bloque **`compile_options`** en `.tesserae/config.json` con el mismo nombre, conservando su antiguo valor por defecto, de modo que el comportamiento es idéntico; solo se ha silenciado la superficie. Consulta la tabla completa de `compile_options` en la [guía rápida](../quickstart.es.md).

## 3. Migración de ruptura limpia: sin alias silenciosos

Cada invocación heredada imprime exactamente una línea y sale con código 2:

```
$ tesserae project compile
tesserae project compile has moved → tesserae compile
```

La tabla de redirección cubre todos los comandos antiguos (incluidas formas de tres tokens como `project sessions import` y los antiguos comandos de nivel superior `wiki`/`llm-defaults`), y una ruta markdown a secas (`tesserae notes/x.md`) te dirige a `tesserae extract`. Los hooks, el smoke de CI, el flujo de publicación y todas las cadenas de tiempo de ejecución del repositorio se migraron al unísono; la documentación y los ocho README (más cada copia localizada) ahora hablan el idioma del nuevo árbol.

## Actualizar desde v0.5.0

- **Vuelve a aprender los verbos que usas en scripts.** Los reemplazos más comunes: `project setup --yes …` → `tesserae init --yes`, `project compile` → `tesserae compile`, `project build-site` → `tesserae export site`, `project serve` → `tesserae serve`, `project obsidian-sync` → `tesserae vault sync`, `project sync-code` → `tesserae code sync`, `tesserae llm-defaults …` → `tesserae config llm …`, `tesserae wiki …` → `tesserae projects …`. Ejecuta una vez la forma antigua de un comando: el mensaje `… has moved → …` te indicará la nueva.
- **¿Moviste un flag de `compile`?** Si usabas en scripts `compile --trends`, `--no-vault-pull`, `--cognee-*`, etc., establece en su lugar el `compile_options.<key>` correspondiente en `.tesserae/config.json` (la tabla está en la guía rápida).
- **Los flags de integración de `init` ya no están en la CLI.** Activa Cognee / RAG-Anything / Understand-Anything respondiendo a las preguntas del asistente `tesserae init`, o editando `.tesserae/config.json` y ejecutando `tesserae integrations refresh <name>`.
- Nada relacionado con el **grafo, el vault, el sitio, las herramientas MCP o el servidor `tesserae_mcp`** cambió: solo la CLI orientada a las personas.
