Released **2026-07-09** · [PyPI](https://pypi.org/project/tesserae/0.17.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.17.0) · `pip install --upgrade tesserae==0.17.0`

이 릴리스는 두 개의 자매 LLM-위키 프로젝트 — [alfadur7/llm-wiki-newsroom](https://github.com/alfadur7/llm-wiki-newsroom)과 [langchain-ai/openwiki](https://github.com/langchain-ai/openwiki) — 에 대한 심층 비교에서 나온 최고의 아이디어들을 통합하며, 모든 것이 채택되기 전에 Tesserae가 이미 가진 것에 대해 검증되었습니다. 주제: **에이전트가 소비하는 것이 이제 정확하고, 신선하며, 구성상 발견 가능합니다.**

## 컴파일된 컨텍스트가 더 이상 낙오자를 인용하지 않음

`compile_context`는 이제 기본적으로 대체된 노드와 중재 패배자를 제외합니다 (`include_superseded=True`로 복원할 수 있음). LLM 중재에서 진 주장은 이전에 우승자와 동일하게 인용되었습니다. 공유 `superseded_ids()` 헬퍼가 이제 `search_nodes`, `fresh_insights`, `node_context`에서 이러한 노드들을 일관되게 억제하거나 플래그를 지정합니다. 합성 페이지는 추가로 모든 인용을 실제 입력 노드 ID에 대해 검증합니다 — 위조된 ID는 이제 검증에 실패하고 결정적 본문으로 폴백합니다.

## 양쪽 게이트의 발행

린트는 **모든 컴파일의 끝**에서 안전하게 실행되므로 `lint-report.md`는 항상 최신입니다. `tesserae compile --strict`는 발견 사항을 CI를 위한 0이 아닌 종료 코드로 바꾸고 — 린트 자체가 충돌하면 **폐쇄 상태로** 실패합니다. 선택적 `lint --verify-claims`는 더 나아갑니다: 인용된 노드가 실제로 *인용하는 문장을 지원*하는지 LLM이 확인합니다 (제한됨, 결정적으로 샘플링됨, 컴파일 블로커가 아님).

## 출력 스냅샷 게이트

각 컴파일 후 Tesserae는 컴파일된 아티팩트를 해시하고 `Output: changed/unchanged`를 보고합니다. `--strict`에서 *의심스러운* 상태 — 입력은 변경되지 않았지만 출력이 변경된 경우 — 빌드가 실패합니다: 바이트 멱등성 버그 클래스에 대한 영구적인 함정입니다. 복사 준비가 된 CI 새로고침 워크플로우는 `docs/integrations/ci-refresh.md`에 있습니다.

## 에이전트가 지식 기반을 스스로 찾음

`tesserae setup`은 이제 대상 저장소의 `AGENTS.md`/`CLAUDE.md`에 마커로 구분된 **Tesserae 포인터 블록**을 설치합니다 (멱등성; 형식이 잘못되거나 중복된 마커에서 변경되지 않은 상태로 유지; 다른 관리 블록과 공존). 위키 루트 `index.md`는 **에이전트 진입점**으로 다시 작성되었습니다: 오리엔테이션, MCP 우선 "쿼리 방법" 섹션, 종류 테이블, 및 상위 커뮤니티. 커뮤니티 페이지는 멤버 소스 파일을 나열하는 결정적 `## Sources` 푸터를 얻습니다.

## 컴파일이 더 저렴해지고 오래된 정보가 보이기 시작함

코드 그래프 계층은 이제 **전체 계층 추출 캐시** (`.tesserae/code-graph-cache.json`)를 유지합니다: 소스 트리의 통계 매니페스트가 변경되지 않았을 때 캐시된 그래프는 전체 재추출 경로를 지불하는 대신 바이트 동일하게 재수화됩니다 (대규모 저장소에서 수십 초). CLI는 `reused` 또는 `+added ~changed -removed` 델타 개수를 보고합니다. 빌드 기록은 컴파일 시간의 git HEAD를 기록하고, 린트는 소스 파일이 변경된 이후의 코드 그래프 노드에 대한 정보 결과를 내보냅니다 — 또한 `contradictions.md` 위키 페이지는 이제 열림/해결됨/폐기됨 주장 충돌을 추적하고, `graph_ppr`은 Memex 스타일의 예상 밖의 연결 발견을 위해 `exclude_direct_neighbors`를 얻습니다.

커뮤니티 요약 캐시는 또한 멤버 *콘텐츠* 다이제스트 (단순 멤버십이 아님)에 대해 무효화되므로 변경된 설명은 오래된 설명을 영원히 제공하는 대신 재요약합니다.

## 업그레이드 참고사항

- 업그레이드 후 첫 번째 컴파일은 `Output: changed`를 한 번 보고합니다 (커뮤니티 페이지는 Sources 섹션을 얻고, `index.md`는 진입점이 됨); 이후 컴파일은 바이트 안정적입니다.
- `tesserae setup` (포함 `--yes`)은 기본적으로 에이전트 포인터를 설치합니다; 계획에서 `install_agent_pointer=false`를 설정하여 선택 해제합니다.
