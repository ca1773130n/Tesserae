릴리스됨 **2026-06-29** · [PyPI](https://pypi.org/project/tesserae/0.12.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.12.0) · `pip install --upgrade tesserae==0.12.0`

더 이상 "활성 프로젝트"가 없습니다. 등록된 모든 프로젝트가 동시에 실시간으로 작동합니다 — `ask`는 프로젝트 전체에서 자체 경로를 설정하고, `serve`는 단일 사이트 아래에서 모두 제공하며, `compile`은 이제 결정론적 추출기가 생략하는 LLM 개념 계층을 빌드할 수 있습니다.

## 활성 프로젝트 없음 — 스마트 `ask` 라우터

"활성 프로젝트" 개념이 없어졌습니다: `tesserae projects activate`와 `activate_project` MCP 도구가 제거되었고, 모든 프로젝트별 명령은 현재 디렉터리에서 프로젝트를 해결합니다. 등록된 모든 프로젝트는 동등합니다.

단순한 `tesserae ask`는 이제 **자체 경로를 설정합니다**:

- 프로젝트 이름 지정 → 해당 프로젝트;
- 비교 또는 일반 질문 → **연합** (통합 전체에 걸친 하나의 병합된 상호 참조 답변);
- 후속 질문("그리고 왜?")은 이전 경로를 유지합니다; 주제 변경("*다른 것*에 대해서는?")은 경로를 다시 설정합니다.

명확한 경우는 자동으로 해결됩니다; 선택 사항인 LLM 동점 결정 도구가 진정으로 모호한 중간을 처리하고, 짧은 대화별 기록이 다중 질문 스레드를 일관성 있게 유지합니다. 명시적 `--scope current|all-registered|federated`도 여전히 작동합니다.

## 모든 프로젝트를 위한 하나의 서버 — `tesserae serve`

단순한 `tesserae serve`는 이제 단일 서버 아래에서 **모든 등록된 프로젝트**를 제공합니다: `/`에 프로젝트 랜딩 페이지, 각 프로젝트는 `/<alias>/` 경로에, 헤더의 프로젝트 전환기, 프로젝트별 세션 보기. 페이지 내 ask 위젯은 실시간으로 작동하며 질문을 한 페이지의 프로젝트로 라우팅됩니다. `tesserae serve --project X`는 여전히 단일 프로젝트를 제공합니다. 요청은 경로로 포함되어 있으며(프로젝트의 사이트 디렉터리 이스케이프 불가능) ask 엔드포인트는 동일 출처 게이트와 요청 크기 제한이 있습니다.

## `compile`에서 개념 계층 빌드 — `--extractor`

`tesserae compile --extractor claude-cli`(또는 `--extractor selective-claude --claude-include "<glob>" --claude-limit N`)은 결정론적 기본값이 희소하게 두는 개념/주장 계층을 빌드합니다 — 개념, 주장, 기능, 증거 범위, 타입 엣지. 이는 실제 코퍼스를 위해 강화되었으며, 여기서 한 개의 잡음이 많거나 느린 문서가 전체 컴파일을 중단했습니다:

- 제어되는 어휘 외부의 엣지 타입은 **삭제되며** 치명적이지 않습니다;
- 문서별 타임아웃을 초과하는 문서는 해당 파일에 대해 **결정론적 추출로 대체됩니다**;
- 일시적 유효하지 않은 생성은 **재시도됩니다**(모델은 비결정론적이므로 재호출은 거의 항상 유효성을 검사합니다).

## 이번 릴리스의 기타 사항

- **Cognee 1.0 호환성** — Cognee 1.0은 Tesserae가 기본값으로 설정한 `INSIGHTS` 검색 타입을 제거했으며, 이는 cognee `ask` 백엔드를 조용히 중단했습니다. 이제 `GRAPH_COMPLETION`(지식 그래프에 대한 답변)에 매핑되므로 cognee가 다시 작동합니다; 원시 검색을 위해 `--cognee-search-type CHUNKS`를 전달합니다.
- **`tesserae setup`** — 최상위 수준의 대화형 머신 전체 설정(LLM 공급자/노력 + 설치할 선택 사항 종속성); 플래그는 프롬프트를 건너뛰고 pip 없는 `uv tool` 환경에서 설치가 작동합니다.
- **문서** — README, 빠른 시작, 설치, MCP 가이드, 기능 맵, 통합 가이드가 위의 내용으로 업데이트되었습니다("활성 프로젝트" 없음).

## v0.11.x에서 업그레이드

대부분 그대로 사용할 수 있습니다. **중단:** `tesserae projects activate`와 `activate_project` MCP 도구가 제거되었습니다 — 프로젝트별 명령은 현재 디렉터리로 해결되고 `ask`는 프로젝트 전체에 자동으로 라우팅됩니다. `projects activate`를 스크립트로 작성한 경우 그냥 삭제합니다. 단일 프로젝트 사용은 변경되지 않습니다.
