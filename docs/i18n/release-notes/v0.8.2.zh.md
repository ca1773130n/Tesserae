Released **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.2/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.2) · `pip install --upgrade tesserae==0.8.2`

小版本更新，为知识库添加了浏览器导入路径。"自主、主动的知识摄入"这一支柱现已可以从任何网页一键使用——同时该摄入功能也通过 MCP 对代理开放。

## 1. 网页剪裁摄入端点（`POST /api/clip`）

`tesserae serve` 新增了一个 JSON 路由，可将剪裁的页面转换为类型化图形节点。它会写入带有来源标记的 `data/ingested/<slug>.md`（front-matter 包含 `url`/`title`/`tags`/`note`/`clipped_at`，可选的 `## TL;DR`，你的 `## Note`，以及 `## Content`），然后运行 CLI 使用的相同增量 `ingest_sources` 路径。TL;DR 由 CLI 支持的 Claude 层提供最佳努力生成（无需 API 密钥）；缺失或失败的摘要生成永远不会阻止剪裁。响应报告 `{status, path, tldr, node_count, edge_count}`。

## 2. `ingest` MCP 工具

相同的摄入核心现已成为 MCP 工具，所以代理可以摄入它找到的内容——无需浏览器。输入：`content`（必需）、`url`、`title`、`note`、`tags`、`tldr`（默认开启）。它将摄入到活跃项目中，并返回与 `/api/clip` 相同的报告。

## 3. Chrome 扩展程序（网页剪裁工具）

一个 Manifest V3 扩展程序位于 `extension/`（加载未打包；Chrome Web Store 上的列表正在审核）。它捕获页面的可读内容——或仅你的选择——带有可选的笔记和标签，以及按剪裁开启的 TL;DR 切换，然后 POST 到你本地的 `tesserae serve`。默认快捷键 `Ctrl+Shift+S`（macOS `Cmd+Shift+S`）。参见 [docs/integrations/chrome-extension.md](../integrations/chrome-extension.md)。

## 4. 剪裁端点默认加强

由于浏览器现在与 `localhost` 通信，`/api/clip` 被锁定：

- **源检查 CORS。** 仅浏览器扩展（`chrome-extension://…`）和本地回环源会被反映；外部网站源将被拒绝 `403` 且不进行任何工作——所以你碰巧访问的页面无法 POST 到你的图形中。
- **私有网络访问。** 预检响应 `Access-Control-Allow-Private-Network: true`，所以 Web Store 扩展可以在当前 Chrome 下到达 `localhost`。
- **正文上限。** 请求在读入内存前被限制在 5 MB。

## 从 v0.8.1 升级

即插即用。要使用剪裁工具，请升级以使 `tesserae serve` 公开 `/api/clip`，然后运行 `tesserae serve` 并加载扩展程序。无需对图形或配置进行任何更改。
