Lanzado **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.15.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.15.0) · `pip install --upgrade tesserae==0.15.0`

Pregúntale a Tesserae qué fue **decidido** — entre todos los proyectos registrados, en cualquier rango de tiempo. Basándose en los resúmenes de actividad v0.14.0, esta versión extrae las decisiones mismas.

## `tesserae decisions`

```bash
tesserae decisions --since 2026-06-30          # todos los proyectos desde una fecha
tesserae decisions --week                       # los últimos 7 días
tesserae decisions --project my-repo --no-llm   # solo decisiones humanas
tesserae decisions --since 2026-06-30 --json    # salida estructurada
```

También disponible como la herramienta MCP **`query_decisions`** (para que un agente pueda responder "¿qué decisiones se tomaron desde el lunes pasado?") y el comando slash **`/decisions`**.

### Dos tipos de decisiones

- **Decisiones humanas — deterministas.** Cada elección que tomaste a través de la herramienta `AskUserQuestion` de Claude Code se extrae exactamente de la transcripción: la pregunta hecha, la opción que elegiste y las alternativas ofrecidas. Sin LLM, completamente reproducible.
- **Decisiones de agente — extraídas.** Las opciones y compromisos que el agente resolvió en la conversación se extraen por el LLM. Pasa `--no-llm` (o `include_agent=false`) para solo las decisiones humanas deterministas.

Cada decisión está fechada por su **propio** timestamp — nunca por el inicio de una sesión larga — por lo que una ventana de tiempo es exacta. La salida es una lista estructurada agrupada por proyecto (`--json` para forma legible por máquina). Las mismas decisiones humanas explícitas ahora también alimentan la sección **Decisions & Insights** del resumen de actividad.

## Actualizando

Compatible en v0.14.x. El nuevo comando es aditivo; nada más cambia. Lee tus sesiones existentes sobre la marcha — no se requiere migración ni recompilación.
