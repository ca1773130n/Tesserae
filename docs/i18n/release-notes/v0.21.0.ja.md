Released **2026-07-20** · [PyPI](https://pypi.org/project/tesserae/0.21.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.21.0) · `pip install --upgrade tesserae==0.21.0`

人間は何もかもを覚えられず、エージェントのコンテキストウィンドウでも何もかもを収めることはできません。このリリースは Tesserae に**エージェント単位の階層化された知識ベース**を提供します — エンジンスパイン以来、最大の機能です。すべてのエージェントは独自のメモリを持ち、そのメモリは定期的に上位層に蒸留され、マネージャーは自分のレポートの蒸留層のみを見て、組織ツリーに沿って再帰的に上がります。完全にオプトインで加算的です。

## アイデア

専門知識は事実の分割ではなく、共有された事実に対する*重み付け*です。エージェントが実際に働く場所を深くします。したがって、巨大なグラフ 1 つまたは N 個の断片化されたグラフの代わりに、Tesserae は 1 つの基盤上に 3 つの層を保ちます:

- **L0** — あなたがすでに持っているプロジェクトグラフ、変わらず、バイト等冪性。コンパイルは観測されたエージェント単位で 1 つの `Agent` ノードと `performed_by` エッジを生成します — 生の帰属、ゼロ LLM コスト。
- **L1** — エージェント単位の蒸留アーティファクト (`.tesserae/agents/<key>/distilled.graph.json`)、単一の 48k リードに制限されているため、エージェントは 1 回の呼び出しで全メモリをロードできます。
- **L2'** — マネージャー集計: レポートを持つエージェントの蒸留は、レポートの最良のノートを**逐語的に**実行します (LLM 再要約の深さは 1 に上限 — パラフレーズのパラフレーズではなく)、任意の深さまで再帰します。

## 何ができるのか

```bash
tesserae agents init                    # discover agents, propose the org registry
tesserae agents set-parent <child> <manager>
export TESSERAE_AGENT_DISTILL=1
tesserae distill                        # every agent, leaves first, managers last
```

その後、すべてのグラフ読み取り MCP ツールは `agent=` 引数を受け取ります: **ワーカーキー**(独自の生の経験と独自の蒸留ノート)、**マネージャーキー**(レポートの蒸留層のみの連邦 — 生は決して上に流れない)、または**`org`**(チーム全体、ゼロ設定)。新しいツール `agent_view_explain`(誰が何を知っており、どの程度古いか)と `drill_down`(蒸留ノートを生の証拠に解決し、監査ログ)が揃えます。

## 削除しない忘却

ユーザーの「忘れる」は吸収(衰退した知見を蒸留に折り込み、引用する)と降格(エージェントのインデックスのタイトル+リファレンス行にドロップ)に分解されます — 年齢だけでは知識を見えなくすることはなく、`drill_down` / `include_superseded` 経由ですべてがアクセス可能です。すべてのプロモーション、デモーション、吸収は台帳に書き込まれ、`tesserae lint` に表示されるため、縮小は*その決定をコストする前に*見えます。

## 成長ループ

生成された `purpose.md` を含むエージェント単位のハーネスディレクトリ; エージェント単位の抽出ガイダンスストリーム(1 つのエージェントを操作し、他のエージェントには影響を与えない); オプトイン クロスエージェント セマンティックブリッジ; エージェント単位のトピックマップ; およびサブエージェント プロモーション — `reviewer` サブエージェントの実行は、レビュアー エージェント自身の専門知識に蓄積されます。`TESSERAE_AGENT_DISTILL` が設定されている場合、`tesserae refresh` は自動的に統合されます — ただし、メモリプレッシャー下のエージェントのみ(生の回想が 1 リードに収まらなくなった)、MemGPT スタイルのトリガーです。

## 決定論性は全体を通じて保たれました

プロジェクトグラフはバイト等冪性を保ちます; 蒸留アーティファクトは、宣言された入力を前提として決定論的です。時間は常に**コーパス クロック** — セッション自体の最新の瞬間 — 壁時計ではなく; ノード ID は LLM の言葉遣いに決して依存しません; そして、lint プローブはタイムスタンプ/カウンター形状のメタデータを拒否します。これは以前、バイト等冪性を破ったことがあります。
