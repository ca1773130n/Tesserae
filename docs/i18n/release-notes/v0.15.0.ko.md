공개됨 **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.15.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.15.0) · `pip install --upgrade tesserae==0.15.0`

Tesserae에 **결정**된 사항을 물어보세요 — 모든 등록된 프로젝트에서, 모든 시간 범위 내에서. v0.14.0 활동 요약을 기반으로 이번 릴리스는 결정 자체를 추출합니다.

## `tesserae decisions`

```bash
tesserae decisions --since 2026-06-30          # all projects since a date
tesserae decisions --week                       # the last 7 days
tesserae decisions --project my-repo --no-llm   # human decisions only
tesserae decisions --since 2026-06-30 --json    # structured output
```

또한 **`query_decisions`** MCP 도구로도 사용 가능합니다 (에이전트가 "지난 월요일 이후 어떤 결정이 내려졌는가?"에 답할 수 있도록) 그리고 **`/decisions`** 슬래시 명령어로도 사용 가능합니다.

### 두 가지 종류의 결정

- **인간의 결정 — 결정론적입니다.** Claude Code의 `AskUserQuestion` 도구를 통해 내린 모든 선택은 트랜스크립트에서 정확히 추출됩니다: 질문된 내용, 선택한 옵션, 제시된 대안들. LLM 없이 완전히 재현 가능합니다.
- **에이전트 결정 — 채굴됨.** 에이전트가 대화에서 결정한 선택과 트레이드오프는 LLM에 의해 추출됩니다. 결정론적인 인간의 결정만을 위해서는 `--no-llm` (또는 `include_agent=false`)을 전달하세요.

각 결정은 자신의 **고유한** 타임스탬프로 날짜가 지정됩니다 — 절대 장시간 실행되는 세션의 시작 시간이 아닙니다 — 따라서 시간 범위는 정확합니다. 출력은 프로젝트별로 그룹화된 구조화된 목록입니다 (`--json`은 기계 가독 형식의 경우). 동일한 명시적 인간 결정이 이제 활동 요약의 **Decisions & Insights** 섹션에도 포함됩니다.

## 업그레이드

v0.14.x를 직접 대체합니다. 새로운 명령은 추가형입니다; 다른 것은 변경되지 않습니다. 기존 세션을 즉시 읽습니다 — 마이그레이션 또는 재컴파일이 필요하지 않습니다.
