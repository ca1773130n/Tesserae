Релиз с новыми возможностями: **задавайте вопросы всем вашим зарегистрированным проектам одновременно**, получая единый перекрёстно-ссылаемый ответ. Совместима с v0.10.x.

## Федеративный граф между проектами

`tesserae ask --scope federated --scope-aliases research work "…"` (и MCP-инструмент `ask` с `scope: "federated"`) собирает **один** граф из названных вами проектов и возвращает единый ответ с перекрёстными ссылками — вместо `all-registered` fan-out, который возвращает один ответ на проект. Ваш файл `.tesserae/graph.json` для каждого проекта остаётся нетронутым; федерация собирается в памяти во время запроса.

Проекты связываются двумя способами:

- **Слияние идентичности (всегда включено).** Одна и та же *сущность* в разных проектах — один и тот же arXiv id, репозиторий, хеш контента или символ кода — сворачивается в один узел. Высокая точность, детерминированный результат, без встраиваний. Например, статья, которую вы обрезали в `research` и на которую ссылаетесь в `work`, становится единственным цитируемым узлом.
- **Семантические связи (включены по умолчанию, можно отключить).** Одна и та же *идея* разными словами — например, решение о кешировании в `work` и статья о кеше в `research` — получает поддерживаемую встраиванием перекрёстно-проектную связь, чтобы поиск мог соединять *связанные*, а не только идентичные, концепции. Вес уменьшен, так что совпадение идентичности всегда будет опережать нечёткий мост. Передайте `--no-semantic` для режима только идентичности. Требуется реальный бэкенд встраивания (`pip install tesserae[semantic]`); без него работает плавно и об этом сообщает.

Порог связи (`0.55`) и вес моста (`0.5`) — не предположения, они установлены на основе точности/полноты + оценки перегрузки (`evals/federation/`, защищённо в CI).

## Исследуйте это

- `tesserae federation status [aliases] [--semantic]` — количество узлов для каждого проекта, слияния идентичности, количество семантических связей.
- `tesserae federation explain <node> [aliases]` — почему узел связывает проекты: какие проекты он соединил по идентичности и его семантические связи (с сходством и целевым проектом). Принимает пространство имён id или слитый id.

Федеративные семантические связи кешируются в `~/.tesserae/federation/`, ключ основан на содержимом проекта, поэтому кеш автоматически инвалидируется при перекомпиляции любого проекта.

## Обновление с v0.10.x

Совместима. Федерация включается по выбору для каждого запроса (`--scope federated`); ничего не меняется для использования одного проекта. Для семантического соединения используйте `pip install tesserae[semantic]`.
