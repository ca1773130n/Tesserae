Released **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.1) · `pip install --upgrade tesserae==0.10.1`

Ein Bugfix-Release. Drop-in über v0.10.0.

## Fixes

- **`tesserae config status` zeigt nun die gesamte maschinenweite Konfiguration, nicht nur das
  LLM-Backend.** Das Tool meldete den aufgelösten Provider/Effort, verbarg aber alles andere,
  das `tesserae config setup` verwaltet, sodass cognee-Aktivierung und der Zustand optionaler
  Abhängigkeiten unsichtbar waren. `status` fügt nun einen Abschnitt **Machine-wide settings**
  (cognee ein/aus + Modus) und einen Abschnitt **Optional dependencies**
  (memex / cognee / raganything / understand-anything — installiert oder nicht) hinzu,
  gedruckt vor dem Liveness-Ping, sodass sie immer angezeigt werden.

## Auch in diesem Release

- Der **cognee**-Adapter wurde auf **cognee 1.x** portiert und die maschinenweite cognee-Aktivierung
  (`config setup --enable-cognee`) gelandet, sodass eine einzelne globale Einstellung die cognify-Pass
  für jedes Projekt einschaltet. Der Session-Filter für Selbsterfassung wurde erweitert, um
  cognee 1.x's eigene writing-assistant-Prompts zu erkennen.

## Upgrade von v0.10.0

Drop-in. Führen Sie `tesserae config status` aus, um das umfassendere maschinenweite Bild zu sehen.
