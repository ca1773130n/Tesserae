Released **2026-07-21** · [PyPI](https://pypi.org/project/tesserae/0.22.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.22.1) · `pip install --upgrade tesserae==0.22.1`

v0.22.0에서 출시된 에이전트 조직 도구의 작은 사용성 개선입니다.

`tesserae agents init`은 서브에이전트 역할로부터 조직 계층 구조를 추론합니다. 다만 v0.21.0 이전에 가져온 세션 저장소(서브에이전트 설명자 캡처가 적용되기 전)에는 역할 정보가 없으므로, 모든 에이전트가 주 `:default` 키로 축소되어 조직이 평탄해집니다. v0.22.0에서는 이런 상황이 조용히 발생하여 기능이 작동하지 않는 것처럼 보였습니다.

이제 `init`은 이를 알려주고, 해결 방법을 제시합니다:

```
Note: only main (:default) agents were observed, so the org is flat — no
subagent roles to build a hierarchy from.
If you use subagents, re-import to capture them, then re-run init:
  tesserae sessions discover --import && tesserae agents init --force
```

"레지스트리가 이미 존재합니다" 메시지는 이제 같은 재가져오기 경로를 가리킵니다. 오래된 레지스트리도 같은 함정의 원인이기 때문입니다. 둘 다 `--flat`으로 실행할 때(명시적 선택) 그리고 실제 계층 구조가 있을 때 표시되지 않습니다.

추론 로직에는 동작 변화가 없습니다. `pip install --upgrade tesserae==0.22.1` (또는 `npm i -g @jokerized/tesserae@0.22.1`)를 실행하세요.
