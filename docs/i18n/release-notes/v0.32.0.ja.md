リリース **2026-08-17** · [PyPI](https://pypi.org/project/tesserae/0.32.0/) · [GitHub リリース](https://github.com/ca1773130n/Tesserae/releases/tag/v0.32.0) · `pip install --upgrade tesserae==0.32.0`

ノードが 6 万個あるグラフは、従業員が 6 万人いる会社と同じ問題を抱えています。正面から
入ってそのまま読み始めることはできません。これまで入口は、手持ちのうち最も大きなノード
を大きさ順にエージェントへ渡し、それが何のためのものかは自分で解き明かさせていました。
このプロジェクト自身のグラフでは、それは 32.5 秒で名前のないカード 1,852 枚でした。建物
の机をすべて並べ、机の順に並べ替えた名簿です。

このリリースは、グラフに組織図を与えます。

## 憲章

コンパイルはコーパスから一つの組織を導出するようになりました。部門、部署、チームがあ
り、それぞれが、人が見て分かる名前と指し示せるアンカーを持つドメインです。入口は大きさ
の順位ではなくこの木をたどり、同じグラフで 1.6 秒、見出しの付いたカード 4 枚になります。

`graph_map` は名前の一覧として開き、名前のないカードは大きいという理由で昇格しません。
`charter_route` はタスクを木の三階層目まで配置するか、あるいは何も指名しません。常に答え
るルーターとは、ときどき自信を持って間違えるルーターであり、こちらは棄権するほうを選び
ます。各ドメインの背後にはブリーフがあります。ドメインの slug をキーにしたコミュニティ
要約で、一度生成してキャッシュされたもの、つまりエージェントがノードの羅列の代わりに受
け取る、読める段落です。

ドメインは自らの出典によって日付が付き、日付を付けられないときはそう言います。この区別
は聞こえる以上に重要です。導出した日付を事実として提示すること、それこそがグラフが、自
分のコーパスが一度も述べていないことを主張し始める道筋です。

`engine` デーモンはアイドルのティック中にブリーフをウォーミングするので、読み手が背後に
何も書かれていないドメインへ着くことがなくなります。そして二つの新しい lint プローブが、
メモリ上のオブジェクトではなくディスク上の憲章ファイルを検査します。その二つこそ、互い
に食い違っていくものだからです。Tesserae 自身のコーパスで測定した結果は、ドメイン
1,411 個のうち 1,410 個がウォーミング済みです。冷たいままの一つは国勢調査ドメインで、こ
れは設計上けっしてウォーミングされません。

## 検索が二度払うのをやめます

ここには四つの変更があり、四つとも、やり直されていた仕事を取り除くものです。ベクトルが
永続化されるようになり、クエリは前回埋め込んだコーパスを埋め込み直さなくなりました。
BM25 レーンはクエリのたびにコーパスを組み立て直すのをやめます。埋め込みレーンはループで
はなく一回の行列積としてコーパスを採点します。そしてクエリは各レーンがいくら費やしたか
を報告するので、遅い答えは推測する対象ではなく原因を帰属できる対象になります。

あわせて検索はビューレジストリを得ました。ビュー範囲の走査を伴う、名前の付いた辺の分割
です。さらにランク融合を備えた多視点走査が加わり、結果はどのビューから出たかを言えるよ
うになりました。

## 時間と、意図して間違えること

サイドカーがトランザクション時間軸を得て、一つの時計が自分を二つと呼ぶのをやめます。事
実が置き換えられたとき、`resolved_by` は負けた側から区間を閉じます。勝者が場所を主張す
るのではなく、負けた事実が何に置き換えられたかを記録します。事実は内容として検索される
ようになり、*日付なし* は、自分で気づかねばならない欠落ではなく、こちらから要求できる述
語になりました。

間違っていることの扱いも以前より直接的です。エージェントは代替物をでっち上げることを強
いられずに事実を撤回できます。つまり「これは間違いだ」と言えます。死んだノード id は生き
残りへ解決されるので、二つのノードを併合しても以前の参照がすべてぶら下がりポインタにな
ることはありません。ある実行で却下された候補ペアは、次の実行でも却下されたままです。そ
して求められたとき、読み取りは自分の読み手を名乗れます。

## 主張より証拠

このリリースは、プロジェクトができる最も華のない仕事に実際の労力を割きました。自分の
README が本当かどうかを確かめる仕事です。

Tesserae は Neo4j の TCK に答えるようになり、93 件の適合性クエリのうち 34 件を意図的に
失敗します。Bronze は 93 件中 57 件、Silver は 67 件中 0 件です。等級は仄めかされるので
はなく明記されます。QA スコアラーがあるので、競合実行は語りではなく数字を出します。
LongMemEval-MAB では BM25 が recall@10 で 0.843、密ベクトル検索が 0.473 で、測定は無料
かつ再現可能です。どちらもベースラインであり、このベンチマークにおける Tesserae 自身の
アームは**まだ測定されていません**。レポートは表にそう暗示させるのではなく、そのことを
はっきり述べます。

より難しい問いのためのハーネスもあります。コーパスが変わら*ない*とき、記憶は改善するの
か、という問いです。コーパスを凍結し、その上で統合を実行し、測り直します。作る過程で二
つの性質が出てきました。関連付けは LLM 呼び出しを一切使いません。ローカル埋め込み器の上
のコサイン類似度だからです。そして冪等です。ですから凍結したコーパスでは、曲線の正直な
形は坂ではなく一段の階段です。これは「入力なしに改善し続ける」より狭い主張であり、誰か
が三サイクル回して確かめても生き残るほうの主張です。

ドキュメント内の誇張された主張が七つ訂正され、比較に関する主張三つは、リポジトリのどこ
にもそれを測定したものがないという理由で撤回されました。

## 静かに腐れないドキュメント

`docs/` 配下のすべての文書は七言語へミラーされます。いま 553 のミラー全体に機械的なパリ
ティ・ラチェットが走ります。翻訳は、英語が持つ識別子や構造要素を落としてはなりません。
これは誤った翻訳ではなく、欠けた翻訳だけを捕まえられます。ですから、二度以上誤訳された
ことのある用語をまとめた用語集と一緒に出荷されます。それに照らして、実在する誤訳が四件
解消されました。

## その他

端末のないコンパイルは、ハングしたように見えるのではなく自らを語ります。しかも求められ
たときだけでなく既定で語ります。図・表・数式は一級の Artifact 証拠ノードになります。図の
番号はそれが属する文書のものであり、辺に乗って運ばれます。Artifact の図はバイト列として
サイトに届きます。コンパイルロックは可搬になり、Windows の追記が引き裂くことはできませ
ん。`.tesserae/` 配下のすべての項目が、誰の持ち物で、消すと何を失うかを述べるようになり
ました。そしてオントロジーの成長ループがついに閉じました。提案は表に出され lint を受け、
昇格は人の編集のままです。

## アップグレード

```bash
pip install --upgrade tesserae==0.32.0
```

既存のグラフはそのまま読まれ、ここにあるどれもリビルドを強制しません。憲章は次のコンパ
イルで導出され、エンジンの残りはそれなしでも動きます。二度とコンパイルしないプロジェク
トは、いま持っているグラフをそのまま保ちます。
