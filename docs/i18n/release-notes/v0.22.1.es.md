Lanzado **2026-07-21** · [PyPI](https://pypi.org/project/tesserae/0.22.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.22.1) · `pip install --upgrade tesserae==0.22.1`

Una pequeña corrección de usabilidad para las herramientas de org de agente incluidas en v0.22.0.

`tesserae agents init` deduce la jerarquía de org desde roles de subagente — pero un almacén de sesiones importado *antes* de v0.21.0 (cuando llegó la captura de descriptor de subagente) no lleva ninguno, así que cada agente colapsa a su clave `:default` principal y la org resulta plana. En v0.22.0 eso ocurrió silenciosamente, por lo que el resultado parecía que la característica no hacía nada.

Ahora `init` lo dice, y te dice cómo arreglarlo:

```
Note: only main (:default) agents were observed, so the org is flat — no
subagent roles to build a hierarchy from.
If you use subagents, re-import to capture them, then re-run init:
  tesserae sessions discover --import && tesserae agents init --force
```

El mensaje "registry already exists" ahora apunta al mismo camino de re-importación, ya que un registro obsoleto es la otra mitad de la misma trampa. Ambos se suprimen bajo `--flat` (una opción explícita) y cuando está presente una jerarquía real.

Sin cambios de comportamiento en la inferencia en sí. `pip install --upgrade tesserae==0.22.1` (o `npm i -g @jokerized/tesserae@0.22.1`).
