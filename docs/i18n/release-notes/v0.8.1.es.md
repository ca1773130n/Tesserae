Publicado el **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.1) · `pip install --upgrade tesserae==0.8.1`

Parche derivado de la primera ejecución real de `tesserae engine --all` (5 proyectos). Reinicia el motor tras actualizar.

## 1. Fin de las tormentas sqlite "unable to open database file"

Las compilaciones en proceso más varios tailers de sesión continuos agotan el **límite blando de 256 archivos abiertos** de macOS por defecto; una vez agotado, cada apertura de sqlite en el proceso falla y el tailer imprimía un traceback por cada archivo rastreado. `tesserae engine` ahora eleva `RLIMIT_NOFILE` a 8192 en el arranque, y un fallo de tick sistémico registra **un solo** traceback más un resumen del número de errores suprimidos.

## 2. Los reinicios omiten el barrido en frío

La primera ejecución del tailer de sesiones barre todo el historial de despliegue de Codex una vez para encontrar sesiones de proyecto — decenas de minutos en historiales grandes, y anteriormente lo hacía de nuevo en **cada** reinicio. El piso del barrido ahora se persiste en la BD de sesiones; los reinicios se reanudan desde él (con una retrospectiva de 7 días para sesiones reanudadas recientemente) y anuncian si el arranque fue frío o caliente, la duración y los conteos.

## 3. Logs silenciosos e informativos

- Seis nuevos tipos de fila de transcripción de Claude Code (`last-prompt`, `queue-operation`, `mode`, `ai-title`, `file-history-snapshot`, `pr-link`) se reconocen como metadatos benignos — ya no hay spam de advertencias en el tailing en vivo; los tipos verdaderamente desconocidos advierten **una sola vez por proceso**.
- Cada ejecución del pipeline registra `pipeline starting for <project>` — una compilación larga ya no parece un cuelgue, porque la única otra salida solía aparecer *después* de que terminaba.

## 4. Renovación del README

El README (y los siete espejos de idioma) fue reescrito: conjunto de funciones actual (`ingest`, `engine --all`, sessions), requisito correcto de Python (3.10+), estructura más limpia con la matriz de comparación y los GIF de demostración plegados en desplegables.

## Actualización desde v0.8.0

Sustitución directa. Reinicia cualquier `tesserae engine` / `tesserae engine --all` en ejecución para aplicar las correcciones — el primer reinicio aún realiza un barrido en frío final para inicializar el piso persistido; todos los reinicios posteriores son rápidos.
