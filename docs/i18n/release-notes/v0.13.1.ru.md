## `tesserae sources` — добавить / список / удалить

`tesserae compile` (без аргументов) компилирует каталоги из списка `sources` проекта. Теперь вы можете управлять этим списком из CLI — и источник может быть **локальным** (внутри проекта) или **глобальным** (где угодно на диске):

```bash
tesserae sources add docs                 # local  — inside the project (stored project-relative)
tesserae sources add /data/shared-notes   # global — an absolute path outside the project
tesserae sources add ../sibling-project   # global — a relative path that escapes the root
tesserae sources list                     # tags each source local/global, flags missing ones
tesserae sources remove docs
```

- Путь **внутри** проекта сохраняется **относительно проекта** (так что `config.json` остаётся переносимым); всё, что **снаружи**, сохраняется **абсолютным путём**. Оба варианта разрешаются во время компиляции, поэтому глобальный источник компилируется точно так же, как локальный.
- Добавления **дедуплицируются по разрешённому расположению** — абсолютная форма и форма с `../` одного и того же каталога никогда не учитываются дважды.
- `list` отмечает каждую запись как `local` / `global` и выделяет те, которые больше не существуют на диске.

Раньше массив `sources` задавался только во время `init` (а повторный запуск `init` перестраивает конфигурацию, а не дополняет её). Это аддитивный, неразрушающий способ расширить область проекта.
