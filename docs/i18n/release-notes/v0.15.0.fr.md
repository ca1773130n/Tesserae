Demandez à Tesserae ce qui a été **décidé** — dans chaque projet enregistré, dans n'importe quel intervalle de temps. S'appuyant sur les résumés d'activité de v0.14.0, cette version extrait les décisions elles-mêmes.

## `tesserae decisions`

```bash
tesserae decisions --since 2026-06-30          # all projects since a date
tesserae decisions --week                       # the last 7 days
tesserae decisions --project my-repo --no-llm   # human decisions only
tesserae decisions --since 2026-06-30 --json    # structured output
```

Également disponible en tant qu'outil MCP **`query_decisions`** (pour qu'un agent puisse répondre « quelles décisions ont été prises depuis lundi dernier ? ») et commande slash **`/decisions`**.

### Deux types de décisions

- **Décisions humaines — déterministes.** Chaque choix que vous avez effectué via l'outil `AskUserQuestion` de Claude Code est extrait exactement de la transcription : la question posée, l'option que vous avez choisie et les alternatives proposées. Pas de LLM, entièrement reproductible.
- **Décisions d'agent — minées.** Les choix et les compromis que l'agent a réglés dans la conversation sont extraits par le LLM. Passez `--no-llm` (ou `include_agent=false`) pour les décisions humaines déterministes uniquement.

Chaque décision est datée par son propre horodatage — jamais le début d'une session de longue durée — donc une fenêtre de temps est exacte. La sortie est une liste structurée regroupée par projet (`--json` pour un formulaire lisible par machine). Les mêmes décisions humaines explicites alimentent désormais également la section **Decisions & Insights** du résumé d'activité.

## Mise à niveau

Remplacement direct de v0.14.x. La nouvelle commande est additive ; rien d'autre ne change. Elle lit vos sessions existantes à la volée — aucune migration ou recompilation requise.
