公開 **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.14.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.14.0) · `pip install --upgrade tesserae==0.14.0`

新しい**アクティビティサマリー**エンジン: 特定の日または1週間全体で何が起きたかを Tesserae に尋ねると、実際の作業から答えを再構築します — すべての AI エージェントセッション、コミット、PR、取り込まれたドキュメント — すべての AI アカウントにわたって。

## `tesserae summary`

```bash
tesserae summary --day 2026-07-05
tesserae summary --week
tesserae summary --day 2026-07-05 --project agented   # scope to one project
```

**`activity_summary`** MCP ツール（エージェントがコンテキストとしてダイジェストを取得できる）および **`/summary`** スラッシュコマンドとしても利用できます。

### 何をするか

- **すべての AI アカウントを直接読み込みます。** 要求されたウィンドウについて、遅延しうるバックグラウンドインデックスに頼るのではなく、ハーネス設定ルート — `~/.claude*`、`~/.codex*`、ワークツリーなど — をスキャンします。1 日はほんの数個のトランスクリプトに触れるだけなので、全アカウント横断スキャンでも高速に保たれます。
- **各ターン自身のタイムスタンプでウィンドウを切ります**（**KST** 基準）— 長時間実行されるセッションの開始時刻ではありません。つまり、複数日にまたがるセッションは、実際にその日に収まるターンだけを寄与します。
- **1 日全体を集約します:** エージェントメッセージ、git コミット、GitHub PR（オープン / マージ / クローズ）、取り込まれたドキュメント — それぞれが自身の時刻でウィンドウされます。
- **単に数えるのではなく、会話を要約します。** 出力は構造化されたプロジェクトごとのナラティブです — **Shipped / Fixed / Decisions & Insights / In progress / Docs / Watch** — さらに *各セッション* が実際に何をしたかの 1 行要約が付きます。決定論的で監査可能なファクトダイジェストがその下に続きます。
- **週次**は 7 日分を 1 つのナラティブにまとめ上げます。

サマリーは `.tesserae/summaries/<project>/daily-YYYY-MM-DD.md` に書き込まれます。

## 引用は `node-<hash>` ではなく名前を表示します

`ask`、`compile_context`、および wiki 合成における引用の根拠は、以前は生のノード ID（`node-<hash>`）を引用マーカーとして漏らしていました。現在はエンティティの実際のタイトルへ解決されるため、回答が読みやすくなります。

## アップグレード

v0.13.x の上にそのまま置き換えられます。新しいコマンドは追加的であり、それ以外は変わりません。`tesserae summary` は既存のセッションをその場で読み込みます — マイグレーションや再コンパイルは不要です。
