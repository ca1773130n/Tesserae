Released **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.2/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.2) · `pip install --upgrade tesserae==0.8.2`

지식 베이스로의 브라우저 경로를 추가하는 마이너 릴리스입니다. "자율적이고 선제적인 지식 수집" 기둥이 이제 모든 웹 페이지에서 한 번의 클릭으로 접근 가능하며, 같은 수집 기능이 MCP를 통해 에이전트에게 노출됩니다.

## 1. 웹 클립 수집 엔드포인트 (`POST /api/clip`)

`tesserae serve`는 클립된 페이지를 타입화된 그래프 노드로 변환하는 JSON 라우트를 추가합니다. 프로벤언스 타임스탬프가 있는 `data/ingested/<slug>.md` 파일을 생성하며(프론트매터 `url`/`title`/`tags`/`note`/`clipped_at`, 선택적 `## TL;DR`, 당신의 `## Note`, 그리고 `## Content`), CLI에서 사용하는 동일한 증분 `ingest_sources` 경로를 실행합니다. TL;DR은 CLI 기반 Claude 레이어를 통해 최선을 다해 작성되며(API 키 없음), 누락되거나 실패한 요약생성기가 클립을 차단하지 않습니다. 응답은 `{status, path, tldr, node_count, edge_count}`를 보고합니다.

## 2. `ingest` MCP 도구

동일한 수집 핵심이 이제 MCP 도구가 되어, 에이전트가 발견한 콘텐츠를 수집할 수 있습니다 — 브라우저가 필요 없습니다. 입력: `content` (필수), `url`, `title`, `note`, `tags`, `tldr` (기본값 활성화). 활성 프로젝트로 수집하고 `/api/clip`과 동일한 보고서를 반환합니다.

## 3. Chrome 확장 프로그램 (웹 클리퍼)

Manifest V3 확장 프로그램이 `extension/` 디렉토리에 있습니다(로드 언팩; Chrome 웹 스토어 등록 검토 중). 페이지의 읽기 가능한 콘텐츠 — 또는 선택 내용만 — 선택적 메모와 태그, 그리고 클립별 TL;DR 토글과 함께 캡처한 후 로컬 `tesserae serve`로 POST합니다. 기본 단축키 `Ctrl+Shift+S` (macOS `Cmd+Shift+S`). [docs/integrations/chrome-extension.md](../integrations/chrome-extension.md)를 참고하세요.

## 4. 클립 엔드포인트는 기본적으로 강화됩니다

브라우저가 이제 `localhost`와 통신하고 있으므로, `/api/clip`은 잠겨있습니다:

- **Origin 검증 CORS.** 브라우저 확장(`chrome-extension://…`)과 루프백 오리진만 반영되며, 외부 웹사이트 오리진은 모든 작업 전에 `403`으로 거부됩니다 — 따라서 방문 중인 페이지가 그래프에 POST할 수 없습니다.
- **프라이빗 네트워크 액세스.** 프리플라이트는 `Access-Control-Allow-Private-Network: true`를 응답하여, 웹 스토어 확장이 현재 Chrome에서 `localhost`에 도달할 수 있습니다.
- **본문 제한.** 요청은 메모리에 읽히기 전에 제한되며(5 MB), 메모리에 읽혀집니다.

## v0.8.1에서 업그레이드

직접 교체 가능합니다. 클리퍼를 사용하려면 `tesserae serve`가 `/api/clip`을 노출하도록 업그레이드한 후, `tesserae serve`를 실행하고 확장 프로그램을 로드하세요. 그래프 또는 설정 변경은 필요하지 않습니다.
