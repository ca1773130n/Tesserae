Дата выпуска: **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.1) · `pip install --upgrade tesserae==0.8.1`

Патч-релиз по итогам первого реального запуска `tesserae engine --all` на 5 проектах. После обновления перезапустите движок.

## 1. Конец штормов sqlite "unable to open database file"

Внутрипроцессные компиляции и несколько непрерывных тейлеров сессий исчерпывают **мягкий лимит macOS в 256 открытых файлов**; после его исчерпания каждый вызов sqlite open в процессе завершается ошибкой, а тейлер печатал трассировку на каждый отслеживаемый файл. `tesserae engine` теперь поднимает `RLIMIT_NOFILE` до 8192 при запуске, а системный сбой tick логирует **одну** трассировку плюс сводку о подавленных ошибках.

## 2. Перезапуск пропускает холодный обход

При первом запуске тейлер сессий единожды обходит всю историю развёртываний Codex для поиска сессий проекта — это занимает десятки минут на большой истории, и ранее повторялось при **каждом** перезапуске. Нижняя граница обхода теперь сохраняется в БД сессий; перезапуски возобновляются с неё (с 7-дневным ретроспективным просмотром для недавно возобновлённых сессий) и сообщают: холодный или тёплый запуск, длительность и количество записей.

## 3. Тихие и информативные логи

- Шесть новых типов строк транскрипта Claude Code (`last-prompt`, `queue-operation`, `mode`, `ai-title`, `file-history-snapshot`, `pr-link`) распознаются как безвредные метаданные — живой тейлинг больше не заспамлен предупреждениями; действительно неизвестные типы предупреждают **один раз на процесс**.
- Каждый запуск конвейера логирует `pipeline starting for <project>` — длинная компиляция больше не выглядит как зависание, поскольку раньше единственный другой вывод появлялся лишь *после* её завершения.

## 4. Обновление README

README (и все семь языковых зеркал) переписан: актуальный набор функций (`ingest`, `engine --all`, sessions), правильное требование к Python (3.10+), более чёткая структура с матрицей сравнения и обучающими GIF, убранными в сворачиваемые блоки.

## Обновление с v0.8.0

Прямая замена. Перезапустите все запущенные `tesserae engine` / `tesserae engine --all` для применения исправлений — при первом перезапуске всё ещё выполняется один финальный холодный обход для инициализации сохранённой границы; все последующие перезапуски быстрые.
