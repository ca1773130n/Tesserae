Выпущено **2026-08-31** · [PyPI](https://pypi.org/project/tesserae/0.37.0/) · [Релиз на GitHub](https://github.com/ca1773130n/Tesserae/releases/tag/v0.37.0) · `pip install --upgrade tesserae==0.37.0`

Этот выпуск добавляет один переключатель и исправляет несколько утверждений.

## Плотная дорожка может запросить обученный кодировщик

На корпусе из 148 статей поставляемый статический эмбеддер `model2vec` был всем
разрывом между графом и обычным векторным хранилищем. Полнота по различным
документам при том же слиянии, том же графе и той же дедупликации документов:

| вариант | @10 документов | @50 документов |
| --- | --- | --- |
| Сырое хранилище фрагментов Mem0 OSS, свой кодировщик | 0.784 | 0.942 |
| Сырое хранилище фрагментов Mem0 OSS, тот же bge-base | 0.775 | 0.944 |
| Tesserae, поставляемый статический model2vec | 0.754 | 0.914 |
| **Tesserae, bge-base в плотной дорожке** | **0.791** | **0.962** |

`TESSERAE_EMBEDDING_PREFER` выбирает бэкенд, когда вызывающая сторона просит
`auto` (`model2vec`, `st`, `openai`, `hash`); значение, не называющее ни одного
бэкенда, сообщается и игнорируется, а не проваливается молча в хэш-заглушку.
`TESSERAE_ST_MODEL` задаёт модель sentence-transformers — значение по умолчанию
меняется с неизмеренной `all-MiniLM-L6-v2` на измеренную `BAAI/bge-base-en-v1.5`.

```bash
uv pip install sentence-transformers
export TESSERAE_EMBEDDING_PREFER=st
export TESSERAE_ST_MODEL=BAAI/bge-base-en-v1.5   # the default; any Hugging Face name
```

Лестница auto не изменилась: сначала `model2vec`, поэтому `pip install tesserae`
остаётся без torch, а установка, где переменная никогда не задавалась, ведёт себя
ровно как раньше.

## Что измерение показало на самом деле

При одном и том же кодировщике граф и сырое хранилище фрагментов находят одни и те
же документы: попарно на 57 вопросах это 8 побед, 8 поражений и 41 ничья на десяти
документах (знаковый критерий p=1.0). Это паритет, и документация теперь говорит
о паритете — прежняя формулировка утверждала, что граф впереди, но сравнивала два
разных кодировщика.

Ретривер также больше не видит собственную отметку даты и текст инструкции
LongMemEval, которые входили в запрос для каждой дорожки.

## Где дизайн действительно отличается

Упаковка выбранных графом документов как исходной прозы, а не как извлечённых
утверждений, дала +28.9% против контроля из пассажей под судьёй `gpt-4o-mini`.
При повторе с локальным судьёй на 7B это +7%, незначимо, а на втором корпусе она
проигрывает. README несёт все три числа, а не лучшее из них.

## Обновление

Мигрировать нечего. Существующие графы не затронуты; переключатель включается явно,
бэкенд по умолчанию не изменился.
