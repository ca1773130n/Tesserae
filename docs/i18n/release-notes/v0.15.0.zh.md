已发布 **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.15.0/) · [GitHub 发布](https://github.com/ca1773130n/Tesserae/releases/tag/v0.15.0) · `pip install --upgrade tesserae==0.15.0`

询问 Tesserae 什么被**决定**了 — 在每个已注册的项目中，在任何时间范围内。基于 v0.14.0 的活动摘要，此版本提取决策本身。

## `tesserae decisions`

```bash
tesserae decisions --since 2026-06-30          # 所有项目自某个日期以来
tesserae decisions --week                       # 过去 7 天
tesserae decisions --project my-repo --no-llm   # 仅人工决策
tesserae decisions --since 2026-06-30 --json    # 结构化输出
```

也可作为**`query_decisions`** MCP 工具（这样代理可以回答"上周一以来做出了哪些决策？"）和**`/decisions`** 斜杠命令使用。

### 两种决策

- **人工决策 — 确定性的。** 你通过 Claude Code 的 `AskUserQuestion` 工具做出的每项选择都从对话记录中精确提取：提出的问题、你选择的选项以及提供的替代方案。无需 LLM，完全可复现。
- **代理决策 — 挖掘的。** 代理在对话中确定的选择和权衡由 LLM 提取。传递 `--no-llm`（或 `include_agent=false`）仅获取确定性的人工决策。

每个决策都按其**自身**的时间戳标记 — 从不按长时间运行的会话的开始 — 所以时间窗口是精确的。输出是按项目分组的结构化列表（`--json` 用于机器可读的格式）。相同的显式人工决策现在也馈入活动摘要的**决策与见解**部分。

## 升级

直接覆盖 v0.14.x。新命令是添加性的；其他都不改变。它实时读取你的现有会话 — 无需迁移或重新编译。
