Выпущено **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.15.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.15.0) · `pip install --upgrade tesserae==0.15.0`

Спросите Tesserae, что было **решено** — по каждому зарегистрированному проекту, в любом временном диапазоне. На основе сводок активности v0.14.0, этот выпуск извлекает сами решения.

## `tesserae decisions`

```bash
tesserae decisions --since 2026-06-30          # все проекты с определённой даты
tesserae decisions --week                       # последние 7 дней
tesserae decisions --project my-repo --no-llm   # только решения человека
tesserae decisions --since 2026-06-30 --json    # структурированный вывод
```

Также доступно как инструмент MCP **`query_decisions`** (чтобы агент мог ответить "какие решения были приняты с прошлого понедельника?") и команда слэша **`/decisions`**.

### Два вида решений

- **Решения человека — детерминированные.** Каждый выбор, который вы сделали через инструмент Claude Code `AskUserQuestion`, извлекается точно из транскрипта: вопрос, который был задан, выбранный вами вариант и предложенные альтернативы. Без LLM, полностью воспроизводимо.
- **Решения агента — добываемые.** Выборы и компромиссы, которые агент сделал в беседе, извлекаются LLM. Передайте `--no-llm` (или `include_agent=false`) для только детерминированных решений человека.

Каждое решение датировано его **собственной** временной меткой — никогда не началом долгоживущей сессии — поэтому временное окно точно. Выходные данные — структурированный список, сгруппированный по проектам (`--json` для машиночитаемой формы). Те же явные решения человека теперь также питают раздел **Decisions & Insights** сводки активности.

## Обновление

Легко обновляется поверх v0.14.x. Новая команда дополнительна; ничего больше не изменяется. Она читает ваши существующие сессии на лету — миграция или перекомпиляция не требуются.
