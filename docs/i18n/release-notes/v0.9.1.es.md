Lanzado **2026-06-19** · [PyPI](https://pypi.org/project/tesserae/0.9.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.9.1) · `pip install --upgrade tesserae==0.9.1`

Una versión de correcciones de errores. Sin cambios en la API — compatible directamente con v0.9.0.

## Correcciones

- **Se eliminó el bucle de retroalimentación de auto-captura.** El monitor de sesiones registraba las *propias* llamadas a codex/claude de Tesserae en tiempo de compilación (extracción, síntesis, destilación, …) como si fueran tus sesiones de trabajo, inundando la base de datos de sesiones e hizo que la siguiente compilación "extrajera hallazgos" de sus propias llamadas de extracción. Ahora están excluidas en la detección y en el seguimiento en vivo, con `tesserae sessions prune-internal` para limpiar bases de datos contaminadas antes de la corrección.

- **El motor ya no reporta falsamente "ya en ejecución".** Cuando el motor se detuvo sin limpiar su pidfile y el SO luego reciclaba ese PID a un proceso no relacionado, una verificación de liveness simple pasaba y el motor se negaba a iniciarse. El pidfile ahora registra una identidad por encarnación (tiempo de inicio del proceso) y trata el candado como retenido solo cuando el PID está vivo *y* su identidad aún coincide, por lo que un pidfile obsoleto se auto-repara.

- **Política de privacidad de la extensión Chrome.** Se agregó una política de privacidad completa para la extensión "Clip to Tesserae" (requerida para Chrome Web Store).

## Actualización desde v0.9.0

Compatible directo. Si la lista de sesiones de un proyecto se ve contaminada con tus propios prompts de Tesserae, ejecuta `tesserae sessions prune-internal` una vez.
