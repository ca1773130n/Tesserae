Released **2026-07-26** · [PyPI](https://pypi.org/project/tesserae/0.26.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.26.0) · `pip install --upgrade tesserae==0.26.0`

v0.25.1 はコンパイルがウェッジされるのを防ぎました。このリリースは、それらを**高速化**し、
**カバーしたものについて正直に**し、ゴミの取り込みを停止します。

## より高速に

- **並列抽出。** バッチループは 1 つの CLI サブプロセスを生成して、一度に 1 つのドキュメント
  ずつそれをブロックしました — 実時間はすべてのモデルラウンドトリップの文字通りの合計であり、
  161 個のドキュメントで約 2 時間 40 分で測定されました。抽出はデフォルトで 4 つのドキュメント
  を同時に実行するようになりました（`TESSERAE_EXTRACT_CONCURRENCY=1` は順序実行を復元します）。

  同時実行は速度を変更しますが、出力は決して変更しません：作業リストはパス順序で固定され、
  結果はインデックスで収集されます。`merge_graphs` は位置ごとに重複ノード ID を解決するため、
  完了順序コレクションは無声で*異なる* グラフを作成します — 抽出器が逆パス順序で終了する
  テストによって固定されます。

- **レスポンスキャッシュが実際にキャッシュします。** `complete_json` は常に `cache_key` を
  受け取り、両方の CLI クライアントがそれを受け取って捨ててしまいました — Anthropic クライアント
  だけが使用しました。同一内容は毎回コンパイルで全額を支払い直しました。両方とも
  `~/.tesserae/llm_cache` の下でコンテンツアドレス指定キャッシュを読み書きするようになりました。
  コンテンツ**およびモデルと推論努力**でキー付けされており、モデルを切り替えると前のモデルの
  答えを提供する代わりに再度要求します。解析可能な応答のみが保存されます。`TESSERAE_LLM_CACHE=0`
  は無効にします。

## 誠実に

- **抽出失敗は名前が付けられ、飲み込まれません。** 失敗分類学は一時的な故障（再試行）と
  実故障を区別し、`--limit` はグラフカバレッジを放棄しなくなり、ホームごとの認証スコープは
  1 つの不良プロファイルが実行を毒することを防ぎます。

- **`graphed` 完全性マーカー。** マニフェスト行は、そのコンテンツが実際に `graph.json` に
  到達してからのみスタンプされます — したがって、途中で終了するコンパイルはグラフが持たない
  カバレッジを主張する行を残すことができなくなります。削除および名前変更されたドキュメントは、
  永遠に残っている代わりに墓石として処理されます。

- **`--retry-fallbacks` スコープ**は現在、入力抽出が失敗したドキュメントのみを再試行し、
  他には何もしません。

## より清潔に

- **ゴミディレクトリはコーパスから除外されます。** pytest tmpdirs（`pytest-of-<user>/pytest-N/`）
  と pip スクラッチディレクトリは、`TMPDIR` がリポジトリに解決されたときに設定されたソースルート内に
  入り、数千の一回限りのフィクスチャファイルを植え付け、毎回のテスト実行で変化します — 
  候補セットは反復されず、`--changed-only` は無操作になることはできません。1 つの実際のプロジェクト
  マニフェストは、**25,269 個のエントリがあり、そのうち 16,110 個（63%）はもう存在しないファイルを
  指していました**。

  ウォーカーは再帰的下降中にこれらのファミリをスキップするようになりました。これは**ディレクトリ**
  ルールです：`docs/pip-install-guide.md` は通常のドキュメントであり、索引付きのままです — 
  Tesserae 独自のコンセプト Slugifier は、すべての「pip install *x*」見出しから正確にそのファイル名
  形状を作成します。

## また

- **Codex モデルデフォルトは `gpt-5.6-luna` です。**
- **[新しいチューニングリファレンス](../tuning.ja.md)** すべての 29 個の `TESSERAE_*`
  環境変数の文書化 — デフォルト、各ゲートの内容、および変更する時期。v0.25.1 で提供された
  抽出タイムアウトを含む、いくつかはまったく文書化されていません。

## v0.25.1 からのアップグレード

ドロップイン。知る価値のあることが 2 つあります：

**抽出は 4 倍幅で実行されます。** プロバイダーアカウントのレート制限が厳しい場合は、
`TESSERAE_EXTRACT_CONCURRENCY=1` を設定してください。

**アップグレード後の最初のコンパイルは通常より多くの作業をする可能性があります** — 
`graphed` マーカーは古いマニフェストに存在しないため、その前の行は未証明と見なされ、
再度スタンプされます。これは 1 つの是正再コンパイルであり、永続的なコストではありません。
