Veröffentlicht **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.15.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.15.0) · `pip install --upgrade tesserae==0.15.0`

Fragen Sie Tesserae, welche Entscheidungen getroffen wurden — über alle registrierten Projekte hinweg, innerhalb beliebiger Zeiträume. Basierend auf den Aktivitätszusammenfassungen von v0.14.0 extrahiert diese Version die Entscheidungen selbst.

## `tesserae decisions`

```bash
tesserae decisions --since 2026-06-30          # all projects since a date
tesserae decisions --week                       # the last 7 days
tesserae decisions --project my-repo --no-llm   # human decisions only
tesserae decisions --since 2026-06-30 --json    # structured output
```

Auch verfügbar als das **`query_decisions`** MCP-Tool (sodass ein Agent die Frage „Welche Entscheidungen wurden seit letztem Montag getroffen?" beantworten kann) und der **`/decisions`** Schrägstrich-Befehl.

### Zwei Arten von Entscheidungen

- **Menschliche Entscheidungen — deterministisch.** Jede Wahl, die Sie über das `AskUserQuestion`-Tool von Claude Code getroffen haben, wird genau aus dem Transkript extrahiert: die gestellte Frage, die von Ihnen gewählte Option und die angebotenen Alternativen. Keine LLM, vollständig reproduzierbar.
- **Agent-Entscheidungen — gewonnen.** Entscheidungen und Kompromisse, die der Agent im Gespräch getroffen hat, werden durch das LLM extrahiert. Übergeben Sie `--no-llm` (oder `include_agent=false`) für nur die deterministischen menschlichen Entscheidungen.

Jede Entscheidung wird mit ihrem **eigenen** Zeitstempel datiert — niemals beim Start einer langen Sitzung — sodass ein Zeitfenster exakt ist. Die Ausgabe ist eine strukturierte Liste, gruppiert nach Projekt (`--json` für maschinenlesbares Format). Dieselben expliziten menschlichen Entscheidungen speisen auch jetzt den **Decisions & Insights**-Abschnitt der Aktivitätszusammenfassung.

## Upgrading

Drop-in über v0.14.x. Der neue Befehl ist additiv; nichts anderes ändert sich. Er liest Ihre vorhandenen Sitzungen im Handumdrehen — keine Migration oder Neukompilierung erforderlich.
