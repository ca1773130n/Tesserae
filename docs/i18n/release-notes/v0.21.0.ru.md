Выпущено **2026-07-20** · [PyPI](https://pypi.org/project/tesserae/0.21.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.21.0) · `pip install --upgrade tesserae==0.21.0`

Человек не может вспомнить всё, и контекстное окно агента не вмещает всё. В этом релизе Tesserae получает **многоуровневую, персональную базу знаний агента** — самую крупную функцию со времён создания основы движка. Каждый агент наращивает собственную память, эта память периодически сжимается в ограниченный верхний уровень, и менеджеры видят только сжатый уровень отчётов своих подчинённых, рекурсивно вверх по организационной иерархии. Полностью дополнительно и добавочно.

## Идея

Экспертиза — это не разбиение фактов — это *взвешивание* над общими фактами, углубление там, где агент действительно работает. Поэтому вместо одного гигантского графика или N раздробленных, Tesserae держит три слоя над одной подложкой:

- **L0** — граф проекта, который у вас уже есть, неизменный и байт-идемпотентный. Компиляция теперь создаёт один узел `Agent` для каждого наблюдаемого агента плюс рёбра `performed_by` — чистая атрибуция, нулевая стоимость LLM.
- **L1** — один сжатый артефакт для каждого агента (`.tesserae/agents/<key>/distilled.graph.json`), ограниченный одним чтением в 48k, чтобы агент мог загрузить всю свою память в один вызов.
- **L2'** — свёртки менеджера: сжатие агента, у которого есть отчёты, переносит лучшие заметки своих отчётов **дословно** (глубина переобобщения LLM ограничена 1 — никогда не перефраза перефразы), рекурсивно вверх на любую глубину.

## Что вы можете сделать

```bash
tesserae agents init                    # обнаружить агентов, предложить реестр организации
tesserae agents set-parent <child> <manager>
export TESSERAE_AGENT_DISTILL=1
tesserae distill                        # каждый агент, листья сначала, менеджеры в конце
```

Затем каждый инструмент чтения графика MCP принимает аргумент `agent=`: **рабочий ключ** (собственный сырой опыт плюс собственные сжатые заметки), **ключ менеджера** (федерация сжатых уровней отчётов только — сырое никогда не просачивается вверх), или **`org`** (вся команда, нулевая конфигурация). Новые инструменты `agent_view_explain` (кто что знает и насколько устаревшие данные) и `drill_down` (разрешить сжатую заметку обратно в сырое свидетельство, залогировано в журнале аудита) дополняют её.

## Забывание, которое никогда не удаляет

"Забыть" пользователя раскладывается на впитать (свернуть затухающий вывод в сжатие, которое его цитирует) и понизить (сбросить до строки название+ссылка в индексе агента) — возраст один никогда не делает знание невидимым, и всё остаётся доступным через `drill_down` / `include_superseded`. Каждое повышение, понижение и впитывание записывается в журнал и выявляется `tesserae lint`, поэтому сокращение видно *прежде*, чем оно стоит решение, никогда не обнаруживается после.

## Цикл роста

Папки хранилища для каждого агента с сгенерированным `purpose.md`; потоки руководства извлечения для каждого агента (управлять одним агентом без касания остальных); опциональные семантические мосты между агентами; карты тем для каждого агента; и повышение подагента, так что выполняется `reviewer` подагента накапливается в собственную экспертизу агента рецензента. Когда установлен `TESSERAE_AGENT_DISTILL`, `tesserae refresh` консолидирует автоматически — но только для агентов под давлением памяти (сырой отзыв больше не подходит в одном чтении), триггер стиля MemGPT.

## Детерминизм сохранён на всём пути

Граф проекта остаётся байт-идемпотентным; сжатые артефакты детерминированы при наличии их объявленных входов. Время всегда **корпусные часы** — самый новый момент в самих сессиях — никогда не стенные часы; идентичность узла никогда не зависит от формулировки LLM; и зонд lint отклоняет метаданные, похожие на временную метку/счётчик, которые ранее нарушали байт-идемпотентность.

Полный дизайн: [`docs/agent-memory.md`](../agent-memory.md) и спецификация на `docs/superpowers/specs/2026-07-19-layered-agent-kg.md`. `pip install --upgrade tesserae==0.21.0` (или `npm i -g @jokerized/tesserae@0.21.0`).
