发布于 **2026-07-10** · [PyPI](https://pypi.org/project/tesserae/0.18.0/) · [GitHub 发布](https://github.com/ca1773130n/Tesserae/releases/tag/v0.18.0) · `pip install --upgrade tesserae==0.18.0`

这是对命令界面的全面修订，源自一个观察：`tesserae ask "what happened recently?"` 过去返回的是静态概念页面和一句诚实的耸肩。核心主题：**命令现在真正兑现了它们名字的承诺。**

## `ask` 会规划检索——并默认给出回答

`tesserae ask` 不再需要 `--llm`：模型会先阅读你的问题，规划哪些知识图谱原语能够回答它（时间线、最近会话、活动摘要、时态事实、wiki 页面），执行该计划，并合成一个带引用的回答。时态问题会得到有日期的证据，而不是概念页面大杂烩。`--no-llm` 强制仅搜索；`TESSERAE_QUERY_DRY_RUN` 和经典的 BM25 路径在任何失败时仍是确定性回退。原始检索——BM25 命中、语义搜索，以及显式的 raganything/cognee 后端——现在归属于 `tesserae query`。

## 每日会话分块：时间范围召回快 20 倍

引擎的会话尾随器现在把每个观测到的回合写入每日分块存储（`.tesserae/session_chunks.db`），`refresh` 在"已持有则跳过"锁下增量回填它。窗口化读取（`summary`、`decisions`、ask 的活动检索、MCP）对已覆盖的天从分块提供服务——在一个 45k 节点的项目上实测 2.3s 对比 48.8s——并带有保证一致性的原始扫描回退，所以缺失或损坏的分块数据库永远不会改变结果，只会影响速度。`tesserae sessions chunk-backfill [--since]` 可按需构建历史。

## `tesserae doctor`

约两秒内完成二十项健康检查：init/图/配置解析、注册表一致性、陈旧状态、活动锁、登录状态、卫生状况。`--fix` 只应用可证明安全的修复（陈旧的 pidfile、过大的钩子日志、注册表修剪、站点重建），并且永远不会触碰活动的编译锁。报告持久化到 `.tesserae/doctor-report.{md,json}`，并通过 MCP 以 `doctor_report` 提供。

## `init` 就是完整的安装

`tesserae init` 检测你机器上的 LLM CLI，检查它们是否真的已登录，并让你选择——包括一个**自定义 claude 兼容端点**（`--llm-provider custom --llm-base-url … --llm-api-key … --llm-model …`）。密钥按 env → 项目 → 全局解析（`ANTHROPIC_API_KEY`、`ANTHROPIC_BASE_URL`、`TESSERAE_LLM_MODEL`）；明文持久化的密钥会警告一次。重新 init 会合并你的配置而不是覆盖它。

## 更精简的后端，诚实的标志

cognee 现在默认关闭，使用时静默，可通过 `tesserae[cognee]` 安装，并且 `codex_cognify` 模式已移除（−556 LOC）。understand-anything 不再因工件存在而自动采用。一次针对全部 26 个命令的对抗性审查重命名或删除了每个名不副实的标志——`summary --project`→`--name`（带严格的名称验证）、`context --synthesize`→`--llm`、`refresh --skip-sessions`→`--no-sessions`、`vault --poll-interval`→`--interval`、`ingest --exact`→`--full`，死标志被删除——每个旧拼写都会打印一行指向新拼写的提示并以 2 退出。行为修复也随之而来：空的 `sessions import` 不再可能清空存储，`ingest --dry-run` 是真正的干跑，`serve --dry-run` 在构建前运行，MCP 服务器终于报告其真实版本。

## 破坏性变更

每个被删除或重命名的标志/命令都会打印其替代品并以 2 退出——没有任何东西会静默失败。完整列表：`ask --llm|--wiki|--backend|--cognee-*`、`query --llm|--no-llm|--model`、`summary|decisions --project`、`context --synthesize`、`refresh --skip-sessions`、`vault sync --poll-interval`、`vault export --vault`、`ingest --exact`、`research --no-web`、`compile --claude-timeout`、`config setup`、`wiki|projects activate`。
