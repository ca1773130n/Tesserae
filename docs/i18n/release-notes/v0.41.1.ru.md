Выпущено **2026-09-12** · [PyPI](https://pypi.org/project/tesserae/0.41.1/) · [GitHub-релиз](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.1) · `pip install --upgrade tesserae==0.41.1`

Каждая команда в CLI была проверена путём её запуска, а не чтения. Шесть дефектов прошли проверку воспроизведения и получили независимую вторую оценку. Три из них удаляли файлы.

## Что изменилось

- **Три экспортера больше не удаляют то, что назвал `--output`.** `export site`, `export kuzu` и `export okf` каждая открывала путём удаления своего назначения, и это назначение — это путь, который вы печатаете. Директория, содержащая два файла, содержала 54 после одного `export site --output`, и оригиналы исчезли. Сканирование OKF рекурсивно, поэтому оно достигало документы в подпапках, в которые ни один пакет никогда не писал.
- **Назначение, которое не является предыдущим экспортом, отклоняется.** Тест не «пусто ли оно», потому что переэкспорт поверх своего собственного вывода должен оставаться бесшумным. Каждый экспортер вместо этого распознаёт свою собственную работу: сайт по его файлам, Kuzu по магии `KUZU` в самом файле, а не по имени, пакет по `index.md` и `log.md`. Всё остальное требует `--overwrite`.
- **`--overwrite`, намеренно не `--force`.** `export site --force` уже означает «развёртывание с грязным деревом». Придание одному флагу двух значений — это то, как кто-то удаляет папку, пытаясь опубликовать одну.
- **`export site` сообщает, где на самом деле находится сайт.** С v0.40.0 она печатала директорию staging, которую атомная подкачка удаляла при выходе, поэтому путь перед вами уже был удалён.
- **`graph-map --scope org:root` возвращает дерево агента вместо сбоя.** Это единственная точка входа в иерархию памяти агента, и на любом реальном проекте она вызывала `RecursionError`: корень org — это узел агента, всё необъявленное сообщает корню, поэтому корень сообщал сам себе и прогулка никогда не заканчивалась. Прогулка теперь итеративна, и цикл родителя деградирует вместо отключения сервера.
- **`distill` может обслуживать агентов, для которых она существует.** Она не срабатывала для любого агента с реальной историей: самый занятый отобразил 79,445 символов против привязки в 48,000 символов за один раз, и усечение только сбрасывает записи индекса, поэтому единственный доступный рычаг не мог сдвинуть число, которое имело значение. Привязка остаётся по умолчанию, потому что она защищает что-то реальное. `--artifact-chars N` теперь объявленный способ преодолеть это, и отказ говорит вам, какую команду запустить.

## Обновление

Нечего мигрировать. Если вы пишете скрипт `export site`, `export kuzu` или `export okf` для директории, которая содержит что-то, кроме предыдущего экспорта, этот вызов теперь завершается с кодом 2 вместо удаления; добавьте `--overwrite`, если удаление было целью.
