没有人类能记住一切，任何代理的上下文窗口也容纳不了一切。本版本为 Tesserae 带来了**分层的、按代理划分的知识库**——自引擎脊柱以来最大的功能。每个代理都拥有自己的内存，该内存定期被蒸馏成一个有界的更高层次，经理们只能看到其报告的蒸馏层，逐级向上递归贯穿整个组织树。完全可选且可加性的。

## 核心思想

专业知识不是对事实的分割——它是对共享事实的*加权*，在代理实际工作的地方加深。因此，与其维护一个巨大的图或 N 个分散的图，Tesserae 在一个基质上保持三个层次：

- **L0** —— 你已有的项目图，保持不变且字节幂等。编译现在为每个观测到的代理铸造一个 `Agent` 节点，加上 `performed_by` 边 —— 原始归因，零 LLM 成本。
- **L1** —— 每个代理一个蒸馏的工件（`.tesserae/agents/<key>/distilled.graph.json`），限制在单个 48k 读取范围内，这样代理可以在一次调用中加载其整个内存。
- **L2'** —— 经理汇总：蒸馏一个拥有报告的代理时，逐字携带其报告笔记中最好的**原文**（LLM 再总结深度上限为 1——永远不是改述的改述），递归到任何深度。

## 你可以做什么

\`\`\`bash
tesserae agents init                    # discover agents, propose the org registry
tesserae agents set-parent <child> <manager>
export TESSERAE_AGENT_DISTILL=1
tesserae distill                        # every agent, leaves first, managers last
\`\`\`

然后每个图读取 MCP 工具都接受一个 `agent=` 参数：一个**工作者键**（自身的原始经验加上自身的蒸馏笔记）、一个**经理键**（仅包含报告蒸馏层的联邦——原始内容永不上升）或 **`org`**（整个团队，零配置）。新增工具 `agent_view_explain`（谁知道什么，以及多旧）和 `drill_down`（将一个蒸馏笔记解析回原始证据、审计日志）完成了它。

## 遗忘永不删除

用户的"遗忘"分解为吸收（将衰减的发现折叠成引用它的蒸馏）和降级（在代理的索引中降为标题+参考行）——年龄单独永远不会让知识隐形，一切仍可通过 `drill_down` / `include_superseded` 到达。每个提升、降级和吸收都写入一个账本，并由 `tesserae lint` 浮出，所以缩减在造成决策前可见，永远不会在之后才发现。

## 增长循环

按代理的工具目录带有生成的 `purpose.md`；按代理的提取指导流（在不触及他人的情况下引导一个代理）；可选的跨代理语义桥；按代理的主题图；以及子代理晋升，所以 `reviewer` 子代理的运行累积到审查者代理的自身专业知识中。当设置 `TESSERAE_AGENT_DISTILL` 时，`tesserae refresh` 自动整合——但仅针对内存压力下的代理（原始召回不再适应单次读取），MemGPT 风格的触发器。

## 确定性保持不变

项目图保持字节幂等；蒸馏工件对于其声明的输入是确定性的。时间始终是**语料库时钟**——会话本身中的最新时刻——永不是挂钟；节点身份永不依赖于 LLM 措辞；且一个 lint 探针拒绝以前破坏过字节幂等的时间戳/计数器形状的元数据。
