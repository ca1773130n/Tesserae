Veröffentlicht **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.14.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.14.0) · `pip install --upgrade tesserae==0.14.0`

Eine neue **Aktivitätszusammenfassungs**-Engine: Fragen Sie Tesserae, was an einem Tag oder über eine Woche passiert ist, und sie rekonstruiert die Antwort aus Ihrer tatsächlichen Arbeit — jede Agent-Sitzung, jeder Commit, jeder PR und jedes aufgenommene Dokument — über alle Ihre KI-Agent-Konten hinweg.

## `tesserae summary`

```bash
tesserae summary --day 2026-07-05
tesserae summary --week
tesserae summary --day 2026-07-05 --project agented   # scope to one project
```

Auch verfügbar als das **`activity_summary`** MCP-Tool (sodass ein Agent eine Zusammenfassung als Kontext abrufen kann) und der **`/summary`** Schrägstrich-Befehl.

### Was es tut

- **Liest jedes KI-Konto direkt.** Es durchsucht Ihre Harness-Config-Roots — `~/.claude*`, `~/.codex*`, Worktrees und alles — für das angeforderte Zeitfenster, anstatt einem Hintergrund-Index zu vertrauen, der zurückfallen kann. Ein Tag berührt nur wenige Transkripte, sodass ein vollständiger kontenübergreifender Scan schnell bleibt.
- **Fenster bei jedem eigenen Zeitstempel jeder Wendung**, in **KST**, niemals beim Start einer langen Sitzung — sodass eine mehrtägige Sitzung nur die Wendungen beiträgt, die tatsächlich innerhalb des Tages fallen.
- **Sammelt den ganzen Tag:** Agent-Nachrichten, Git-Commits, GitHub-PRs (geöffnet / zusammengeführt / geschlossen) und aufgenommene Dokumente — jedes nach seinem eigenen Zeitpunkt gefenstert.
- **Fasst die Gespräche zusammen, nicht nur Zahlen.** Die Ausgabe ist eine strukturierte, pro-Projekt-Erzählung — **Versandt / Behoben / Entscheidungen & Erkenntnisse / In Bearbeitung / Docs / Überwachen** — plus eine Einzeiler-Zusammenfassung dessen, was *jede Sitzung* tatsächlich getan hat. Darunter befindet sich ein deterministisches, prüfbares Fakten-Digest.
- **Wöchentlich** fasst die sieben Tage in eine Erzählung zusammen.

Zusammenfassungen werden in `.tesserae/summaries/<project>/daily-YYYY-MM-DD.md` geschrieben.

## Zitationen rendern Namen, nicht `node-<hash>`

Zitierte Evidenz in `ask`, `compile_context` und Wiki-Synthese gab zuvor rohe Knoten-IDs (`node-<hash>`) als Zitierungsmarkierungen preis. Sie werden jetzt auf den tatsächlichen Titel der Entität aufgelöst, sodass Antworten lesbar sind.

## Upgrading

Drop-in über v0.13.x. Der neue Befehl ist additiv; nichts anderes ändert sich. `tesserae summary` liest Ihre vorhandenen Sitzungen im Handumdrehen — keine Migration oder Neukompilierung erforderlich.
