发布于 **2026-09-16** · [PyPI](https://pypi.org/project/tesserae/0.41.3/) · [GitHub 发布](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.3) · `pip install --upgrade tesserae==0.41.3`

v0.41.2 关闭了命令审计中最严重的十二项。这次关闭其余十九项，也就是全部。

## 改了什么

- **七个命令用一句话回答错误。** 错误的路径、无法解析的日期、并非提供方的配置值——这些从前
  都以堆栈跟踪收场。最糟的是 `tesserae compile`，它会因为一个无法读取的文件而中止整个语料；
  现在它会指出跳过了什么，并编译其余部分。
- **七个命令不再报告没有发生的事。** `status` 为从未编译过的项目显示编译时间。
  `config status` 把文件设置的值算作默认值。`schema-drift` 对从未聚类过的类型宣称没有找到
  聚类。`graph-map` 返回与收到的完全相同的分页游标，于是遵循它的调用方会永远循环。
- **五个命令不再接受本该拒绝的东西。** 拼错的代理名称会像真实名称一样作答。
  `projects register` 在两个目录生成同一名称时会悄悄注销另一个项目。`domains status` 会让
  一个并非项目的目录去运行编译。
- **预览预览它所预览的东西。** `sessions prune-internal --dry-run` 在本应给出将要删除的数量
  的位置，打印了已存储记录的总数。

## 升级

无需迁移。更多命令在从前安静地返回 0 的地方返回 2，因此依赖那种沉默的脚本将开始报告它本就
一直存在的失败。
