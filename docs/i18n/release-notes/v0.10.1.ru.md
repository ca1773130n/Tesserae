Релиз с исправлениями ошибок. Полностью совместима с v0.10.0.

## Исправления

- **`tesserae config status` теперь показывает всю машинную конфигурацию, а не только
  LLM бэкенд.** Раньше команда отображала только разрешённого провайдера и уровень усилий,
  но скрывала всё остальное, что управляет `tesserae config setup`, поэтому включение cognee
  и состояние опциональных зависимостей были невидимы. `status` теперь добавляет раздел
  **Machine-wide settings** (cognee вкл/выкл + режим) и раздел **Optional dependencies**
  (memex / cognee / raganything / understand-anything — установлены или нет),
  выводимые до проверки доступности, чтобы они всегда отображались.

## Также в этом выпуске

- Адаптер **cognee** был перенесён на **cognee 1.x** и появилась машинная поддержка cognee
  (`config setup --enable-cognee`), поэтому единое глобальное значение включает cognify проход
  для каждого проекта. Фильтр самозахвата сессии был расширен, чтобы распознавать собственные
  writing-assistant подсказки cognee 1.x.

## Обновление с v0.10.0

Прямая замена. Запустите `tesserae config status`, чтобы увидеть более полную машинную картину.
