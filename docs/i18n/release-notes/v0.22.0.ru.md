Выпущено **2026-07-21** · [PyPI](https://pypi.org/project/tesserae/0.22.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.22.0) · `pip install --upgrade tesserae==0.22.0`

v0.21.0 поставил многоуровневую память агентов, но половина была доступна только через MCP, и `tesserae agents init` выплёвывал каждого агента под `org:root`. Этот релиз делает всю функцию пригодной для использования из терминала.

## `init` строит реальную организацию

`tesserae agents init` теперь выводит иерархию из сигнала, который уже существует: роль подагента (`claude-code:me:reviewer`) становится дочерней по отношению к главному агенту, который её спавнил (`claude-code:me:default`), вместо того чтобы все приземлялись плоско под `org:root`. Вы получаете рабочую многоуровневую организацию из одной команды — без необходимости `set-parent`. Передайте `--flat` для старого поведения, и `init` теперь выводит предложенное дерево, так что вы видите, что оно решило.

```
org:root
  claude-code:me:default   Main    sessions=42
    claude-code:me:reviewer   Reviewer   sessions=8   distilled_through=2026-07-20T…
    claude-code:me:planner    Planner    sessions=5   (not distilled)
```

## Обрезанные чтения из CLI

`--agent KEY` теперь работает с `tesserae query`, `ask` и `context` — поиск и синтез работают над разрешённым представлением агента (**рабочий** ключ видит собственные сырые данные и собственные сжатые заметки, **ключ менеджера** видит только сжатые слои отчётов своих подчинённых — сырое никогда не просачивается вверх, `org` видит всю команду). Ранее это масштабирование существовало только как MCP аргумент.

```bash
tesserae query "release checklist" --agent claude-code:me:reviewer
tesserae ask "what does my team know about deploys?" --agent org
```

Неизвестные ключи и не-сжатые агенты падают громко с точной командой устранения, никогда молчаливый пустой ответ.

## Инспектирование организации

- **`tesserae agents tree`** — организационная диаграмма как отступленное дерево, каждый агент аннотирован с кол-вом сессий и давностью его сжатой памяти.
- **`tesserae agents show KEY`** — разрешить представление и вывести его режим, членов агентов, пути артефактов, кол-во узлов и водяные метки свежести.
- **`tesserae agents drill NODE_ID [--agent KEY]`** — проверенная эскалация от сжатой заметки обратно к её сырому L0 свидетельству, теперь первоклассная CLI команда (alive / changed / absorbed / gone). Логика `drill_down` была извлечена так что CLI и MCP сервер делят один проверённый код, так что обе поверхности ведут себя идентично.

## Под капотом

Инференция иерархии роли является чистой, детерминированной функцией; ядро `drill_down` было извлечено так что CLI и MCP сервер делят один проверённый путь кода. Никаких изменений в сжатых артефактах или их гарантиях детерминизма. Полностью дополнительно — каждая существующая команда ведёт себя точно так же, как раньше, когда `--agent` отсутствует.
