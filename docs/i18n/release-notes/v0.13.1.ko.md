작은 추가 기능 릴리스: CLI에서 프로젝트의 컴파일 범위를 관리하며, `config.json`을 직접 편집할 필요가 없습니다.

## `tesserae sources` — 추가 / 목록 / 제거

`tesserae compile`(인자 없음)은 프로젝트의 `sources` 목록에 있는 디렉토리를 컴파일합니다. 이제 CLI에서 해당 목록을 관리할 수 있으며, 소스는 **로컬** (프로젝트 내부) 또는 **글로벌** (디스크의 어느 곳이든)일 수 있습니다:

```bash
tesserae sources add docs                 # local  — inside the project (stored project-relative)
tesserae sources add /data/shared-notes   # global — an absolute path outside the project
tesserae sources add ../sibling-project   # global — a relative path that escapes the root
tesserae sources list                     # tags each source local/global, flags missing ones
tesserae sources remove docs
```

- 프로젝트 **내부**의 경로는 **프로젝트 상대 경로**로 저장되므로 (따라서 `config.json`은 이식 가능함), 프로젝트 **외부**의 경로는 **절대 경로**로 저장됩니다. 둘 다 컴파일 시간에 해결되므로, 글로벌 소스는 로컬 소스와 정확히 같게 컴파일됩니다.
- 추가된 항목은 **해결된 위치별로 중복 제거**되므로, 같은 디렉토리의 절대 경로와 `../` 상대 경로 형태가 절대 중복으로 계산되지 않습니다.
- `list`는 각 항목을 `local` / `global`로 표시하고, 더 이상 디스크에 존재하지 않는 항목을 플래그합니다.

이전에는 `sources` 배열이 `init` 시간에만 설정되었으며 (그리고 `init`을 다시 실행하면 구성을 추가하는 것이 아니라 재구축함), 프로젝트의 범위를 확장하는 추가적이고 비파괴적인 방법입니다.
