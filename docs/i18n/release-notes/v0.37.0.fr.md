Publié le **2026-08-31** · [PyPI](https://pypi.org/project/tesserae/0.37.0/) · [Version GitHub](https://github.com/ca1773130n/Tesserae/releases/tag/v0.37.0) · `pip install --upgrade tesserae==0.37.0`

Cette version ajoute un réglage et corrige plusieurs affirmations.

## La voie dense peut demander un encodeur entraîné

Sur un corpus de 148 articles, l'encodeur statique `model2vec` livré constituait
tout l'écart entre le graphe et un simple magasin vectoriel. Rappel par documents
distincts, à fusion, graphe et déduplication identiques :

| variante | @10 docs | @50 docs |
| --- | --- | --- |
| Magasin de fragments bruts de Mem0 OSS, son propre encodeur | 0.784 | 0.942 |
| Magasin de fragments bruts de Mem0 OSS, le même bge-base | 0.775 | 0.944 |
| Tesserae, model2vec statique livré | 0.754 | 0.914 |
| **Tesserae, bge-base dans la voie dense** | **0.791** | **0.962** |

`TESSERAE_EMBEDDING_PREFER` choisit le backend lorsque l'appelant demande `auto`
(`model2vec`, `st`, `openai`, `hash`) ; une valeur ne nommant aucun backend est
signalée et ignorée plutôt que de retomber en silence sur le substitut par
hachage. `TESSERAE_ST_MODEL` nomme le modèle sentence-transformers — la valeur par
défaut passe du non mesuré `all-MiniLM-L6-v2` au mesuré `BAAI/bge-base-en-v1.5`.

```bash
uv pip install sentence-transformers
export TESSERAE_EMBEDDING_PREFER=st
export TESSERAE_ST_MODEL=BAAI/bge-base-en-v1.5   # the default; any Hugging Face name
```

L'échelle auto est inchangée : `model2vec` d'abord, donc `pip install tesserae`
reste sans torch et une installation qui ne définit jamais la variable se comporte
exactement comme avant.

## Ce que la mesure a réellement montré

À encodeur égal, le graphe et un magasin de fragments bruts trouvent les mêmes
documents : appariés sur 57 questions, cela donne 8 victoires, 8 défaites et 41
égalités à dix documents (test des signes p=1.0). C'est la parité, et la
documentation dit désormais parité — la formulation précédente affirmait que le
graphe était devant, en comparant deux encodeurs différents.

Le récupérateur ne voit plus non plus l'horodatage et le texte d'instruction
propres à LongMemEval, qui faisaient partie de la requête pour chaque bras.

## Là où la conception diffère vraiment

Empaqueter les documents choisis par le graphe sous forme de prose d'origine
plutôt que d'affirmations extraites a marqué +28.9% face à un contrôle de passages
sous un juge `gpt-4o-mini`. Relancé avec un juge local de 7B, c'est +7%, non
significatif, et sur un second corpus il perd. Le README porte les trois chiffres,
pas le meilleur.

## Mise à niveau

Rien à migrer. Les graphes existants ne sont pas affectés ; le réglage est
optionnel et le backend par défaut est inchangé.
