Eine kleine erweiternde Version: Verwaltung des Compile-Umfangs eines Projekts über die CLI statt durch manuelle Bearbeitung von `config.json`.

## `tesserae sources` — add / list / remove

`tesserae compile` (ohne Argumente) kompiliert die Verzeichnisse in der `sources`-Liste des Projekts. Sie können diese Liste nun über die CLI verwalten — und eine Quelle kann **lokal** (innerhalb des Projekts) oder **global** (überall auf der Festplatte) sein:

```bash
tesserae sources add docs                 # local  — inside the project (stored project-relative)
tesserae sources add /data/shared-notes   # global — an absolute path outside the project
tesserae sources add ../sibling-project   # global — a relative path that escapes the root
tesserae sources list                     # tags each source local/global, flags missing ones
tesserae sources remove docs
```

- Ein Pfad **innerhalb** des Projekts wird **projektrelativ** gespeichert (damit `config.json` portierbar bleibt); alles **außerhalb** wird **absolut** gespeichert. Beide werden bei der Kompilierung aufgelöst, sodass eine globale Quelle genau wie eine lokale kompiliert wird.
- Hinzufügungen werden **nach aufgelöstem Pfad dedupliziert** — die absolute und `../`-relative Form desselben Verzeichnisses wird nie doppelt gezählt.
- `list` kennzeichnet jeden Eintrag mit `local` / `global` und zeigt alle fehlenden Einträge an.

Zuvor wurde das `sources`-Array nur beim `init` gesetzt (und erneutes Ausführen von `init` erstellt die Konfiguration neu, statt sie zu ergänzen). Dies ist die additive, nicht-destruktive Methode, um den Umfang eines Projekts zu erweitern.
