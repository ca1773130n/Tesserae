Veröffentlicht am **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.1) · `pip install --upgrade tesserae==0.8.1`

Patch-Release aus dem ersten realen `tesserae engine --all`-Lauf (5 Projekte). Starte die Engine nach dem Upgrade neu.

## 1. Keine sqlite-"unable to open database file"-Stürme mehr

In-Process-Kompilierungen plus mehrere kontinuierlich laufende Session-Tailer erschöpfen macOS' standardmäßiges **Soft-Limit von 256 offenen Dateien**; ist dieses Limit ausgeschöpft, schlägt jedes sqlite open im Prozess fehl, und der Tailer hat pro verfolgter Datei einen Traceback ausgegeben. `tesserae engine` hebt `RLIMIT_NOFILE` nun beim Start auf 8192 an, und ein systemischer Tick-Fehler protokolliert **einen** Traceback plus eine Zusammenfassung der unterdrückten Fehleranzahl.

## 2. Neustarts überspringen den Kaltlauf

Der erste Lauf des Session-Tailers durchsucht einmalig die gesamte Codex-Rollout-Historie nach Projektsessions — bei großen Historien dauert das Dutzende von Minuten, und bisher geschah dies bei **jedem** Neustart erneut. Die Sweep-Untergrenze wird nun in der Sessions-DB persistiert; Neustarts setzen von dort aus fort (mit einem 7-tägigen Rückblick für kürzlich wiederaufgenommene Sessions) und melden: Kalt- oder Warmstart, Dauer und Zählerstände.

## 3. Ruhige, informative Logs

- Sechs neue Claude Code-Transkript-Zeilentypen (`last-prompt`, `queue-operation`, `mode`, `ai-title`, `file-history-snapshot`, `pr-link`) werden als harmlose Metadaten erkannt — kein Warn-Spam beim Live-Tailing mehr; wirklich unbekannte Typen warnen **einmal pro Prozess**.
- Jeder Pipeline-Lauf protokolliert `pipeline starting for <project>` — eine lange Kompilierung sieht nicht mehr wie ein Hänger aus, da die einzige andere Ausgabe bisher erst *nach* Abschluss erschien.

## 4. README-Auffrischung

Das README (und alle sieben Sprachspiegel) wurde neu geschrieben: aktueller Funktionsumfang (`ingest`, `engine --all`, sessions), korrekte Python-Anforderung (3.10+), übersichtlichere Struktur mit Vergleichsmatrix und Walkthrough-GIFs in ausklappbaren Abschnitten.

## Upgrade von v0.8.0

Drop-in-Ersatz. Starte alle laufenden `tesserae engine` / `tesserae engine --all`-Instanzen neu, um die Fixes zu übernehmen — beim ersten Neustart wird noch ein abschließender Kaltlauf durchgeführt, um die persistierte Untergrenze zu initialisieren; alle weiteren Neustarts sind dann schnell.
