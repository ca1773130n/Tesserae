Lanzado **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.2/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.2) · `pip install --upgrade tesserae==0.8.2`

Lanzamiento menor que añade una ruta de navegador hacia la base de conocimiento. El
pilar "captura y asimilación de conocimiento autónoma y proactiva" ahora es accesible con
un clic desde cualquier página web — y la misma asimilación se expone a agentes sobre MCP.

## 1. Punto final de captura web (`POST /api/clip`)

`tesserae serve` obtiene una ruta JSON que convierte una página capturada en nodos de grafo tipados.
Escribe un archivo `data/ingested/<slug>.md` con marca de proveniencia (front-matter
con `url`/`title`/`tags`/`note`/`clipped_at`, un `## TL;DR` opcional, tu `## Note`,
y el `## Content`), luego ejecuta la misma ruta incremental `ingest_sources` que usa
la CLI. El TL;DR es del mejor esfuerzo vía la capa Claude respaldada por CLI (sin clave API);
un resumen faltante/fallido nunca bloquea la captura. La respuesta informa
`{status, path, tldr, node_count, edge_count}`.

## 2. Herramienta MCP `ingest`

El mismo núcleo de asimilación es ahora una herramienta MCP, por lo que un agente
puede asimilar contenido que encontró — sin necesidad de navegador. Entradas: `content` (requerido), `url`, `title`,
`note`, `tags`, `tldr` (activado por defecto). Asimila al proyecto activo y
devuelve el mismo reporte que `/api/clip`.

## 3. Extensión Chrome (Web Clipper)

Una extensión Manifest V3 reside en `extension/` (cargarse sin empaquetar; un
listado de Chrome Web Store está en revisión). Captura contenido legible de una página — o solo
tu selección — con una nota opcional y etiquetas, y un toggle TL;DR por captura,
luego POST a tu `tesserae serve` local. Atajo predeterminado `Ctrl+Shift+S`
(macOS `Cmd+Shift+S`). Ver
[docs/integrations/chrome-extension.md](../integrations/chrome-extension.es.md).

## 4. El punto final de captura está endurecido por defecto

Porque un navegador ahora se comunica con `localhost`, `/api/clip` está bloqueado:

- **CORS verificado por origen.** Solo se reflejan orígenes de extensión de navegador (`chrome-extension://…`) y
  orígenes de loopback; un origen de sitio web externo es rechazado con
  `403` antes de cualquier trabajo — por lo que una página que visitas no puede hacer POST en tu
  grafo.
- **Acceso a Red Privada.** La respuesta de preflight contiene
  `Access-Control-Allow-Private-Network: true`, por lo que una extensión de Web Store puede
  alcanzar `localhost` bajo Chrome actual.
- **Límite de cuerpo.** Las solicitudes están acotadas (5 MB) antes de que se lean en memoria.

## Actualizando desde v0.8.1

Intercambiable. Para usar el clipper, actualiza para que `tesserae serve` exponga `/api/clip`,
luego ejecuta `tesserae serve` y carga la extensión. No se requieren cambios
en el grafo o la configuración.
