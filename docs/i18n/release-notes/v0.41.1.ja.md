公開日 **2026-09-12** · [PyPI](https://pypi.org/project/tesserae/0.41.1/) · [GitHub リリース](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.1) · `pip install --upgrade tesserae==0.41.1`

CLIのすべてのコマンドは、それを読むことではなく、実行することによって監査されました。6つの欠陥が再現と敵対的な第2意見を乗り越えました。そのうち3つはファイルを削除しました。

## 何が変わったか

- **3つのエクスポーターは、`--output`が名前を付けるものを削除しなくなりました。** `export
  site`、`export kuzu`、および`export okf`はそれぞれ宛先を削除することで開きました。その宛先はあなたが入力するパスです。2つのファイルを保持するディレクトリは、1つの`export site --output`の後に54を保持し、元のファイルは消えていました。OKFスイープは再帰的であるため、バンドルが書き込むことのないサブディレクトリ内のドキュメントに達しました。
- **前のエクスポートではない宛先は拒否されます。** テストは「それは空ですか」ではありません。なぜなら、独自の出力上でエクスポートし直すことは静かに留まる必要があるからです。各エクスポーターは代わりにそれ自身の仕事を認識します：サイトはそのファイルによって、Kuzu、名前ではなくファイル自体の`KUZU`マジックによって、バンドルは`index.md`と`log.md`によって。その他のものには`--overwrite`が必要です。
- **`--overwrite`、意図的に`--force`ではありません。** `export site --force`はすでに「ダーティツリーでデプロイ」を意味します。1つのフラグに2つの意味を与えることは、1つを公開しようとしながら誰かがフォルダを削除する方法です。
- **`export site`はサイトが実際にどこにあるかを報告します。** v0.40.0以来、それはステージングディレクトリを印刷し、アトミックスワップは途中で削除するため、あなたの前のパスはすでに消えていました。
- **`graph-map --scope org:root`はクラッシュする代わりにエージェントツリーを返します。** これはエージェントメモリ階層への唯一のエントリポイントであり、実プロジェクトでは`RecursionError`が発生しました：組織ルートはエージェントノードです。宣言されていないものはルートに報告され、ルートはそれ自体に報告されるため、ウォークは終わりませんでした。ウォークは反復的になり、親サイクルはサーバーを利用する代わりに低下します。
- **`distill`はそれが存在するエージェントにサービスを提供できます。** 実際の履歴を持つすべてのエージェントで失敗しました：最も忙しいものは、79,445文字を48,000文字の1回読み取り制限に対してレンダリングし、切り詰めはインデックスエントリのみを削除するため、利用可能な1つのレバーは重要な数を移動できませんでした。バウンドはそれが実際のものを保護するため、デフォルトのままです。`--artifact-chars N`はそれを超える宣言された方法であり、拒否はあなたが実行するコマンドを伝えます。

## アップグレード

移行するものはありません。`export site`、`export kuzu`、または`export okf`を以前のエクスポート以外のものを保持するディレクトリに対してスクリプト化すると、そのコールは削除する代わりに2で終了します。削除が目的だった場合は`--overwrite`を追加してください。
