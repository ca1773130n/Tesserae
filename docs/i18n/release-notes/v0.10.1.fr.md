Publié **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.1) · `pip install --upgrade tesserae==0.10.1`

Une version de correction de bogues. Compatible en tant que remplacement direct pour v0.10.0.

## Corrections

- **`tesserae config status` affiche maintenant la configuration machine-wide entière, pas
  seulement le backend LLM.** Elle rapportait le fournisseur/effort résolus mais masquait tout
  le reste que `tesserae config setup` gère, donc l'activation de cognee et l'état des
  dépendances optionnelles étaient invisibles. `status` ajoute maintenant une section
  **Machine-wide settings** (cognee activé/désactivé + mode) et une section
  **Optional dependencies** (memex / cognee / raganything / understand-anything — installées ou non),
  imprimées avant le ping de vivacité pour qu'elles s'affichent toujours.

## Aussi dans cette version

- L'adaptateur **cognee** a été porté vers **cognee 1.x** et l'activation machine-wide
  de cognee (`config setup --enable-cognee`) a été implémentée, de sorte qu'un seul paramètre
  global active la passe cognify pour chaque projet. Le filtre de session d'auto-capture a été
  étendu pour reconnaître les propres invites d'assistant d'écriture de cognee 1.x.

## Mise à niveau depuis v0.10.0

Compatible en tant que remplacement direct. Exécutez `tesserae config status` pour voir la
vue machine-wide plus complète.
