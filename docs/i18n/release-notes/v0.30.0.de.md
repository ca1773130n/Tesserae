Released **2026-08-08** · [PyPI](https://pypi.org/project/tesserae/0.30.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.30.0) · `pip install --upgrade tesserae==0.30.0`

Drei Dinge landen hier. Quellcode wird nicht mehr indiziert, außer man bittet
darum. Eine Retrieval-Oberfläche, die geschrieben, getestet und unerreichbar war,
wird erreichbar. Und der Graph bekommt ein Organigramm, damit ein
Allzweck-Agent auf eine Domäne gerichtet werden und dort als Experte handeln
kann.

## Quellcode ist jetzt etwas, worum man bittet

Tesserae baute eine Code-Ebene, sobald ein Projekt wie ein Repository *aussah* —
`kind` war `CodeProject`, `Repository` oder `Project`. Das beschreibt, was ein
Projekt ist, und nicht die Aussage seines Eigentümers, dass sein Quellcode
geparst werden soll. Der einzige Ausweg war, über die Art zu lügen.

Die Kosten sammelten sich dort, wo niemand hinsieht. `graph.json` trägt die
Research-Partition, zeigte also **null** Code-Knoten, während die
SQLite-Projektion und die generierten Seiten rund 220.000 Zeilen und 220.000
Seiten trugen. Niemand führt das auf eine Einstellung zurück, die er nie gesetzt
hat. Auf der Maschine des Maintainers waren es 327 MB Artefakte für eine
Funktion, die dieses Projekt abgeschaltet hatte.

Jetzt bittet das Projekt darum:

```json
"external_tools": [{"id": "codegraph"}]
```

Fehlt der Eintrag, ist die Ebene aus. Die Projektart wird überhaupt nicht
herangezogen. Das übernimmt die Form, die die RAG-Anything-Integration ohnehin
liest, statt einen zweiten Schalter zu erfinden.

**Die Pflege folgt demselben Tor** — und das ist die Hälfte, die sonst lecken
würde. Beide sync-code-Hooks prüfen die Aktivierung *vor* ihrer eigenen
`sync_code_on_*`-Einstellung; diese können eine bereits erteilte Erlaubnis also
nur einschränken, niemals erst erzeugen. Eine CodeGraph-Datenbank auf der Platte
ist keine Zustimmung: Ein Agent kann `codegraph init` für eigene Zwecke
ausgeführt haben, ohne eine Meinung dazu zu haben, ob Tesserae sie alle 30
Sekunden verfolgen soll.

`code-graph.json` folgt dem Schalter in beide Richtungen: geschrieben, wenn
aktiviert, entfernt, wenn nicht. Eine übrig gebliebene Datei trägt keinen
Zeitstempel und beantwortet weiter Anfragen mit dem Abbild eines Repositories,
das sich längst bewegt hat.

Gelöscht wurde nichts. Der CodeGraph-Adapter, der Extraktor, der Cache und
`tesserae code ingest|sync` sind alle noch da, hinter dem Schalter.

## Die Retrieval-Regler, die immer schon da waren

`facts_as_of` — bitemporale Abfrage, „was glaubte der Graph an diesem Datum" —
war geschrieben, byte-idempotent und von sieben Tests abgedeckt, bei **null**
Aufrufern. `personalized_pagerank` berücksichtigte `edge_type_weights` bereits.
`compile_context` nahm sechzehn Parameter, der MCP-Server reichte sieben weiter.
Tesserae besaß Bitemporalität und sichtselektive Traversierung und konnte nach
keinem von beidem fragen.

Jetzt schon. `as_of` bei `search_facts` und `timeline`, und `undated_included`
meldet, wie viele der gelieferten Zeilen gar kein Datum tragen. `strategy`,
`scope`, `edge_type_weights`, `tame_hubs` und `recency_weight` bei
`compile_context`.

`as_of` und `current_only` werden zusammen abgelehnt, und zwar absichtlich: Sie
drücken verschiedene Uhren aus, und die Frage, was an einem vergangenen Datum
galt, darf nicht stillschweigend nichts liefern, weil die Antwort später ersetzt
wurde.

## Ein Organigramm über dem Graphen

`tesserae domains status` zeigt eine Struktur über Ihrem Wissensgraphen: aus
seinen Communities abgeleitete Bereiche, rekursive Teilung, wenn das Briefing
einer Domäne über das hinauswächst, was ein Agent in einem Zug lesen kann, und
Identitäten, die eine Reorganisation überstehen — der Slug, auf den Sie einen
Agenten festgelegt haben, löst sich auch dann noch auf, wenn der Graph sich
bewegt hat.

Das ist das Substrat. Das Routing, das es nutzt, folgt als Nächstes.

## Die Aufnahme meldet keinen Erfolg mehr für Arbeit, die sie nicht getan hat

Bisher kopierte `tesserae ingest paper.pdf` die Datei, ließ einen Compile laufen, dessen
Walker nur `.md` liest, und gab Knotenzahlen aus dem übrigen Korpus aus. Nichts auf
diesem Weg konnte „Ihr PDF aufgenommen" von „nichts aufgenommen" unterscheiden. Ein
Verzeichnis voller PDFs verhielt sich genauso, und das ausgegebene `processed=1` zählte
das Verzeichnis.

Jetzt wird pro Datei abgelehnt, mit einem ausführbaren Hinweis:

```
tesserae ingest cannot read these files — compile only extracts from .md:
  - paper.pdf (.pdf): RAG-Anything parses this format, but it is opt-in ...
  - figure.zip (.zip): No Tesserae backend parses this format. Convert it to
    markdown first, then `tesserae ingest figure.md`.
```

Das Holen einer URL ist ebenfalls strenger. Eine PDF-URL wurde als Text dekodiert, unter
einem `.md`-Suffix geschrieben und über den Zeichensalat gehasht — der Walker reichte sie
danach als Prosa an den Extraktor weiter. Ein Body, den die Bytes als binär ausweisen,
ein Body mit binärem deklariertem Typ und eine 200 ohne lesbaren Text werden nun
abgelehnt.

Ein neuer `INTERVAL_COVERAGE`-Lint meldet, wie viel des Graphen sich zeitlich einordnen
lässt. Im Graphen dieses Projekts: **76.095 von 103.705 Fakten (73,4 %) tragen kein
`valid_from`** und sortieren daher in `timeline()` unter der Zeichenkette „undated". Er
meldet auf `info` und lässt `--strict` nicht scheitern; eine Untergrenze braucht eine
Zahl aus einem aktuellen Korpus, und dieser ist es noch nicht.

Der Session-Import zählt die Inhaltsblöcke, die er nicht lesen kann, statt sie
stillschweigend zu verwerfen. Auf 150 echten Transkripten brachte das **9 zuvor
unsichtbare Bildblöcke** ans Licht — sie stecken verschachtelt in `tool_result`, wo der
alte Zähler nie hingesehen hat.

## Upgrade

```bash
pip install --upgrade tesserae==0.30.0
```

Wer Tesserae als Claude-Code-Plugin betreibt: **Das Tor in den Hooks greift erst,
sobald das Plugin dieser Version installiert ist** — frühere Plugin-Kopien prüfen
nur, ob eine CodeGraph-Datenbank existiert, und sehen die Aktivierung nicht. Bis
dahin sind `sync_code_on_edit: false` und `sync_code_on_start: false` in
`.claude/tesserae.local.md` der Schalter, den diese Hooks verstehen.

Bestehende Projekte laufen weiter. Wer seine Code-Ebene zurückwill, fügt den
`external_tools`-Eintrag oben hinzu; wer nicht, bekommt ohne jede Änderung einen
kleineren Graphen, eine kleinere Datenbank und keine Code-Seiten.
