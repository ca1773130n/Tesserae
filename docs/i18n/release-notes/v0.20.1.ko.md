긴 에이전트 세션을 다루는 모든 사람을 위한 버그 수정 릴리스입니다. Tesserae가 제 역할을 하고 있다면, 그것이 바로 모든 사람입니다.

## 300-turn 절단 버그

세션 임포트(`_claude_turns` / `_codex_turns`)는 **세션당 300 turn 이후**로 캡처가 정지되었습니다. 다운스트림의 모든 것 — 청크화된 LLM 익스트랙터, 세션 발견, 결정, 타입화된 그래프 — 긴 세션의 처음 300 turn만 보았습니다. 마라톤 세션의 후반부에서 나온 인사이트, 결정, TODO는 절대 추출되지 않았고, 이를 경고하는 것도 없었습니다.

이 상한선은 청크화된 추출 파이프라인보다 이전에 존재했으며 파이프라인에 의해 더 이상 필요하지 않게 되었습니다: 익스트랙터는 `max_turns_per_chunk` 윈도우에서 turn별 텍스트 상한선으로 히스토리를 읽기 때문에 각 LLM 호출의 프롬프트 크기는 **총 세션 길이와 관계없이** 제한됩니다. 캡처 시간에 절단하는 것은 단지 지식을 버렸을 뿐입니다.

## 수정 사항

임포트 기본값은 이제 절단 지점 대신 런어웨이 파일 백스톱(`100,000` turn)이 되어, 모든 명시적 호출 사이트(activity summary, session chunks, live serve)와 일치합니다. 전체 대화 히스토리는 청크 스토어와 익스트랙터로 유입됩니다. 호출별 LLM 컨텍스트는 청킹 레이어에 의해 제한되어 있으므로 관심사가 그곳에 있습니다.

증분 컴파일은 저렴하게 유지됩니다: 청크 캐시는 인덱스 정렬되어 있으므로 기존 세션의 이전에 추출된 청크는 캐시 히트로 남아 있습니다. 다음 컴파일에서 새로 표시되는 turn만 추출됩니다. 긴 세션이 있는 프로젝트에서 업그레이드 후 첫 번째 재컴파일은 보통보다 많은 LLM 호출을 할 것으로 예상됩니다. 이는 이전에 보이지 않던 히스토리가 한 번에 추출되는 백로그입니다.

API 또는 스키마 변경 없음. `pip install --upgrade tesserae==0.20.1`(`또는 npm i -g @jokerized/tesserae@0.20.1`)을 실행하고 재컴파일하세요.
