Released **2026-07-20** · [PyPI](https://pypi.org/project/tesserae/0.21.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.21.0) · `pip install --upgrade tesserae==0.21.0`

누구도 모든 것을 기억하고, 에이전트의 컨텍스트 윈도우가 모든 것을 담을 수는 없습니다. 이 릴리스는 Tesserae에 **계층화된, 에이전트별 지식 기반**을 도입합니다 — 엔진 백본 이후 가장 큰 기능입니다. 모든 에이전트는 자신의 메모리를 갖고, 그 메모리는 주기적으로 상위 계층으로 증류되며, 관리자는 자신의 보고서의 증류된 계층만 보고, 조직 트리 상향으로 재귀합니다. 완전히 선택적이고 누적적입니다.

## 핵심 개념

전문성은 사실의 분할이 아니라 공유된 사실에 대한 **가중치** — 에이전트가 실제로 일하는 곳을 깊게 합니다. 따라서 거대한 그래프 하나 또는 N개의 분산된 그래프 대신, Tesserae는 하나의 기반 위에 세 계층을 유지합니다:

- **L0** — 이미 가지고 있는 프로젝트 그래프, 변하지 않고 바이트 동일성 보장. 이제 컴파일은 관찰된 에이전트당 하나의 `Agent` 노드와 `performed_by` 엣지를 생성합니다 — 원시 귀속, LLM 비용 없음.
- **L1** — 에이전트당 하나의 증류 아티팩트(`.tesserae/agents/<key>/distilled.graph.json`), 한 번의 호출로 에이전트가 전체 메모리를 로드할 수 있도록 단일 48k 읽기로 제한.
- **L2'** — 관리자 롤업: 보고서가 있는 에이전트를 증류할 때 보고서의 노트 중 최고의 것들을 **그대로** 수행(LLM 재요약 깊이는 1로 제한 — 절대 다시 말한 것의 다시 말한 것이 아님), 어떤 깊이든 재귀.

## 할 수 있는 것

```bash
tesserae agents init                    # 에이전트 발견, 조직 레지스트리 제안
tesserae agents set-parent <child> <manager>
export TESSERAE_AGENT_DISTILL=1
tesserae distill                        # 모든 에이전트, 리프 먼저, 관리자 마지막
```

그러면 모든 그래프 읽기 MCP 도구는 `agent=` 인자를 받습니다: **워커 키**(자신의 원시 경험 더하기 자신의 증류된 노트), **관리자 키**(보고서의 증류된 계층만의 연합 — 원시는 절대 위로 새지 않음), 또는 **`org`**(전체 팀, 설정 없음). 새로운 도구 `agent_view_explain`(누가 무엇을 알고 얼마나 오래됐는지)과 `drill_down`(증류된 노트를 원시 증거로 되돌리기, 감사 기록)이 이를 보완합니다.

## 삭제하지 않는 잊기

사용자의 "잊기"는 흡수(사라지는 발견을 그것을 인용하는 증류물로 접기)와 강등(에이전트의 인덱스에서 제목+참조 줄로 내리기)으로 분해됩니다 — 나이만으로는 지식이 눈에 띄지 않게 만들지 않으며, 모든 것은 `drill_down` / `include_superseded`를 통해 도달 가능합니다. 모든 승격, 강등, 흡수는 원장에 기록되고 `tesserae lint`로 표시되므로, 축소는 결정의 비용이 되기 전에 보이며, 그 후에 발견되지 않습니다.

## 성장 루프

생성된 `purpose.md`를 가진 에이전트별 하네스 디렉토리; 에이전트별 추출 안내 스트림(하나의 에이전트를 조종하되 다른 것은 건드리지 않기); 선택적 크로스 에이전트 의미론적 브리지; 에이전트별 토픽 맵; 및 서브에이전트 승격, 따라서 `reviewer` 서브에이전트의 실행은 리뷰어 에이전트 자신의 전문성으로 축적됩니다. `TESSERAE_AGENT_DISTILL`이 설정되면, `tesserae refresh`는 자동으로 통합합니다 — 하지만 메모리 압박 상태의 에이전트만(원시 회수가 더 이상 한 번의 읽기에 맞지 않음), MemGPT 스타일의 트리거.

## 전체 과정에서 결정론성 유지

프로젝트 그래프는 바이트 동일성을 유지하고, 증류된 아티팩트는 선언된 입력이 주어지면 결정론적입니다. 시간은 항상 **코퍼스 시계** — 세션 자체의 최신 순간 — 절대 월-클록이 아님; 노드 신원은 절대 LLM 표현에 의존하지 않으며; 린트 프로브는 이전에 바이트 동일성을 깬 타임스탬프/카운터 형태 메타데이터를 거부합니다.
