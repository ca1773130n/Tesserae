Publié **2026-07-22** · [PyPI](https://pypi.org/project/tesserae/0.23.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.23.0) · `pip install --upgrade tesserae==0.23.0`

La mémoire d'agent en couches (v0.21) pouvait distiller, mais uniquement à la
demande — sur `tesserae refresh`, sous pression mémoire. Cette version donne
au moteur toujours actif un **cycle de sommeil** : il consolide la mémoire
d'agent de lui-même, comme un cerveau se consolide pendant le repos.

## Consolider au repos

Laissez `tesserae engine` s'exécuter et il observe maintenant une horloge
d'activité. Quand un projet devient **inactif** — pas d'éditions ou de nouvelles
sessions pendant quelques minutes — il exécute la passe de distillation sur tous
les agents du projet, réorganisant et compactant leur expérience accumulée pendant
votre absence. Un **plafond** périodique (par défaut 6h) garantit même qu'un projet
continuellement occupé se consolide quand même.

```bash
tesserae engine                      # consolidation inactif activée par défaut
tesserae engine --consolidate-idle 600 --consolidate-every 43200
tesserae engine --all                # tous les projets enregistrés, à l'inactivité
tesserae engine --no-consolidate     # refuser
```

L'inactivité est le déclencheur neurobiologiquement exact : la consolidation se
produit quand le système est au repos, pas sur une heure arbitraire du mur.

## Sûr par construction

Le cycle enveloppe exactement la passe `maybe_distill_on_refresh` existante, donc
toutes ses garanties se transfèrent :

- **Un non-opération sauf si vous avez opté pour cela.** Rien ne s'exécute jusqu'à
  `TESSERAE_AGENT_DISTILL=1` — la même porte que la distillation a toujours utilisée,
  plus le filigrane par agent et les vérifications de pression mémoire. Les drapeaux
  sont activés par défaut parce que la passe elle-même refuse de rien faire sans l'opt-in.
- **Ne chevauche jamais une recompilation.** La consolidation s'exécute sous la porte
  de compilation, donc elle et le pipeline s'excluent mutuellement — et pour que cela
  tienne en mode démon unique, une porte non définie utilise maintenant un sémaphore
  privé par défaut.
- **Ne perturbe jamais le démon.** Il s'exécute sur son propre thread (l'idiome
  poller existant du démon), ne lève jamais dans la boucle d'événements, se termine
  rapidement à l'arrêt, et est entièrement ignoré pour les exécutions uniques `engine`.
- **Artefacts déterministes, intacts.** Les graphes distillés gardent leur
  idempotence octet ; l'horloge d'activité monotone n'est jamais persistée.

## Drapeaux

| Drapeau | Défaut | Signification |
|---|---|---|
| `--consolidate` / `--no-consolidate` | activé | activer le cycle de sommeil |
| `--consolidate-idle` | `300` | secondes de silence avant consolidation |
| `--consolidate-every` | `21600` | plafond — consolider au moins aussi souvent (`0` = désactivé) |
| `--consolidate-check` | `30` | à quelle fréquence le thread vérifie l'horloge |

Comportement complet et notes de flotte : [`docs/engine-consolidation.md`](../engine-consolidation.md).
