**2026-06-20** 릴리스됨 · [PyPI](https://pypi.org/project/tesserae/0.10.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.0) · `pip install --upgrade tesserae==0.10.0`

피쳐 릴리스입니다: 지식 교환, 더 빠른 세션 검색, 원샷 시스템 전체 설정을 포함합니다. 모든 것이 덧붙여지는 것입니다 — 일반 `tesserae compile`은 변하지 않으며, 프로젝트별 설정은 여전히 새로운 전역 기본값을 재정의합니다.

## 1. Google OKF v0.1 가져오기/내보내기

`tesserae export okf`는 그래프를 [Google **Open Knowledge Format** v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog) 번들로 씁니다 — YAML 프론트매터와 상대 링크 관계가 있는 마크다운 파일의 트리입니다. `--import DIR`은 하나를 다시 읽습니다. Tesserae의 자체 번들은 `x_tesserae` 프론트매터 네임스페이스를 통해 **손실 없이** 왕복합니다(실제 노드 ID + 타입된 엣지 + 엣지 메타데이터); 외부 번들은 최선을 다해 가져옵니다(알 수 없는 `type` → `Concept`, 타입 없는 링크 → `references`), 명세에 따라 누락된 타입과 끊어지거나 심링크된 파일을 허용합니다.

## 2. 세션 대시보드에서의 빠른 트랜스크립트 검색

`tesserae serve`의 세션 대시보드는 모든 인덱싱된 Claude/Codex 트랜스크립트에 대한 전체 텍스트 검색 상자를 얻습니다, [nicosuave/memex](https://github.com/nicosuave/memex)(BM25)로 구동됩니다. 이는 선택사항이고 우아합니다: `memex` 바이너리 없으면 상자는 실행 가능한 메시지를 표시하고 나머지 대시보드는 영향을 받지 않습니다. `GET /api/transcript-search` 엔드포인트는 같은 출처/루프백 발신자로만 제한되므로 방문한 웹 페이지가 로컬 기록을 탐사할 수 없으며, 결과는 `textContent`를 통해 렌더링됩니다(마크업 주입 없음).

## 3. MCP를 위한 memex 스타일 읽기 규칙

Databricks의 "프로그래밍 가능한 스크래치패드"에서 영감을 얻어, `compile_context`는 이제 `preview=N`을 수용합니다: 거대한 본문을 에이전트의 컨텍스트로 덤프하는 대신, 제한된 미리보기와 콘텐츠 키된 **핸들**을 반환하고, 새로운 **`get_handle`** 도구는 필요에 따라 나머지를 페이지합니다. 기본 `preview=0`은 전체 본문 동작을 유지합니다.

## 4. 추출 품질 신호

세션 발견물은 이제 추출자에서 증류된 `confidence` + `confidence_rationale` + `revisit_signals`을 전달합니다(Jonasb8/memex의 아이디어; 코드 복사 없음). 그들은 콘텐츠 키된 추출 캐시를 탑니다, 그래서 그들은 바이트-멱등을 유지하며, `fresh_insights` MCP 도구에 플래그로 표면화됩니다(절대 진실 보장 아님).

## 5. 시스템 전체 설정 + 의존성 설치

`tesserae config setup`은 **모든** 프로젝트에 대해 LLM 기본값을 설정합니다(`--llm-provider`, `--reasoning-effort`, `--codex-home`, `--claude-config-dir`) **그리고** 한 번에 선택적 의존성을 설치합니다(`--install all`). `tesserae config deps`는 **memex**, **cognee**, **raganything**, 그리고 **understand-anything**을 나열/설치합니다; `tesserae config llm`은 `--reasoning-effort`를 얻었습니다; 그리고 `tesserae init`은 대화형 설정 중에 memex를 설치할 것을 제안합니다. 해석 순서: env → 프로젝트 config → 시스템 전체 config → 기본값.

## v0.9.x에서 업그레이드

플러그인 앤 플레이입니다. `tesserae config setup`을 실행하여 시스템 전체 기본값을 한 번 구성하거나, 프로젝트별 `.tesserae/config.json`을 유지하세요 — 여전히 이깁니다.
