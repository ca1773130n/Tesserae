リリース日: **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.1) · `pip install --upgrade tesserae==0.10.1`

バグ修正リリースです。v0.10.0 からのドロップイン アップグレードです。

## 修正

- **`tesserae config status` がマシン規模の config 全体を表示するようになりました。LLM バックエンドのみではなくなります。** 解決されたプロバイダー/effort を報告していましたが、`tesserae config setup` が管理する他のすべてを隠していたため、cognee 有効化とオプション依存関係の状態が見えませんでした。`status` は now **マシン規模設定** セクション (cognee on/off + mode) と **オプション依存関係** セクション (memex / cognee / raganything / understand-anything — インストール済みかどうか) を追加し、liveness ping の前に印刷されるため常に表示されます。

## このリリースに含まれるもの

- **cognee** adapter が **cognee 1.x** に移植されました。マシン規模の cognee 有効化 (`config setup --enable-cognee`) がリリースされたため、単一のグローバル設定がすべてのプロジェクトで cognify パスをオンにします。self-capture session filter は cognee 1.x の独自の writing-assistant prompts を認識するように拡張されました。

## v0.10.0 からのアップグレード

ドロップイン。`tesserae config status` を実行してマシン規模の設定全体を表示してください。
