릴리스 일자 **2026-06-10** · [PyPI](https://pypi.org/project/tesserae/0.7.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.7.0) · `pip install --upgrade tesserae==0.7.0`

이제 `tesserae ask`는 **이미 로그인되어 있는 CLI** 위에서 실제 답변을 합성합니다 — `ANTHROPIC_API_KEY`가 필요하지 않습니다 — 그리고 머신의 모든 계정을 순환하므로 속도 제한이 답변을 막는 일이 없습니다. 여기에 더해, 질문 *대상*이 되는 세션을 검색 가능하게 만드는 두 가지 수정과, 더 이상 중단되지 않는 컴파일이 함께 제공됩니다.

## 1. `tesserae ask`가 claude/codex CLI 위에서 합성합니다 — API 키 없이

예전에는 `tesserae ask`가 `ANTHROPIC_API_KEY`를 필요로 하는 Anthropic SDK를 통해서만 답변을 작성할 수 있었습니다. 일반적인 구성 — `claude` 또는 `codex` CLI에 OAuth로 로그인한 상태 — 을 사용한다면, `ask`는 조용히 `(no LLM answer: LLM disabled)`와 함께 원시 검색 결과로 격하되었습니다.

이제 답변 경로는 JSON 추출기가 이미 사용하던 것과 동일한 OAuth 클라이언트를 재사용합니다. `tesserae ask --llm "<question>"` (또는 `TESSERAE_QUERY_LLM=1`)는 **API 키 없이** 인용이 포함된 답변을 합성합니다 — 엔진의 나머지 부분이 약속하는 바로 그 무(無)키 약속 그대로입니다.

## 2. 머신의 **모든** 계정을 순환합니다

CLI 클라이언트는 이미 모든 `~/.claude*` 구성 디렉터리와 모든 `~/.codex*` 홈을 자동으로 검색합니다. v0.7.0은 `ask`가 이를 사용하도록 만들고 — 이를 *프로바이더* 전반에 걸쳐 연결합니다: 질문은 **모든** 계정이 소진된 후에야 비로소 포기합니다.

실제로는 이렇습니다: 모든 Claude 계정이 Sonnet/주간 한도에 도달한 상태에서, 실제 `tesserae ask --llm`은 이들을 순환한 다음 **Codex로 넘어가** 답변합니다(`model=cli-oauth`) — 키도, 수동 계정 전환도 없습니다. 속도 제한에 걸렸거나 로그아웃된 계정은 건너뛰며, 치명적 오류가 아닙니다.

## 3. 수정: 세션 제목이 더 이상 하네스 머리말로 축소되지 않습니다

Codex는 모든 트랜스크립트 앞에 `# AGENTS.md instructions for <path>`를 붙이므로, 세션 제목 휴리스틱이 *그것*을 **모든** 세션의 제목으로 받아들였습니다 — 그리고 키워드 검색은 동일한 점수를 가진, 구별할 수 없는 상용구의 벽을 반환했습니다. 이제 제목은 주입된 AGENTS/CLAUDE/GEMINI.md 머리말(및 시스템 래퍼)을 건너뛰고 실제 첫 번째 지시문에서 가져옵니다. `ask`는 다시 구별되는, 관련성 있는 결과를 반환합니다.

두 가지 더 작은 `ask` 수정이 함께 따라옵니다: LLM 게이트(`--llm` / `TESSERAE_QUERY_LLM`)가 위키 검색 경로에서 존중되며(이전에는 하드 비활성화되어 있었습니다), `--backend auto`가 더 풍부한 백엔드의 오류(예: cognee 인증 실패)로 인해 폴백할 때, 이제 위키가 시도된 유일한 백엔드인 것처럼 조용히 보이는 대신 그 사실을 알려줍니다.

## 4. 수정: 컴파일이 더 이상 오래된 캐시 참조에서 중단되지 않습니다

전체 `tesserae compile` / `refresh`가 `KeyError: 'CodeFunction:…'` — 더 이상 존재하지 않는 코드 노드 id — 와 함께 실패할 수 있었습니다. 세션 findings는 *추출* 시점에 doc 그래프에 대해 참조를 필터링하지만, findings는 청크 단위로 캐시됩니다. 참조된 노드의 id가 나중에 변경되거나(예: 코드가 편집될 때 content-hash id가 바뀌는 코드 함수) 사라지면, 캐시된 finding이 **오래된** 참조를 재생하여 다운스트림 code-graph 단계를 망가뜨리는 dangling 노드를 날조했습니다. 이제 참조는 병합 시점에 라이브 그래프에 대해 재검증됩니다 — 대상이 여전히 존재하면 연결하고, 존재하지 않으면 버립니다.

## v0.6.1에서 업그레이드하기

드롭인입니다. API 키 없이 `ask`에서 답변을 받으려면, `claude` 또는 `codex` CLI에 로그인한 상태에서 `--llm`을 전달하기만 하면 됩니다. 컴파일 `KeyError`를 만난 적이 있다면, `tesserae compile`(또는 `refresh`)을 다시 실행하세요 — 이제 중단하는 대신 오래된 참조를 건너뜁니다.
