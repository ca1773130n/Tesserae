Released **2026-07-10** · [PyPI](https://pypi.org/project/tesserae/0.18.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.18.0) · `pip install --upgrade tesserae==0.18.0`

コマンドサーフェスの全面的な改訂であり、1 つの観察に基づいています：`tesserae ask "what happened recently?"` は以前、静的なコンセプトページと正直な肩すくめを返していました。テーマは以下の通りです：**コマンドは、その名前が約束することを実行するようになりました。**

## `ask` は取得を計画し — デフォルトで回答します

`tesserae ask` は `--llm` を必要としなくなりました：モデルはまず質問を読み、どのナレッジグラフプリミティブ（タイムライン、最近のセッション、アクティビティダイジェスト、時間的ファクト、wiki ページ）がそれに答えられるかを計画し、その計画を実行し、引用付きの回答を合成します。時間的な質問は、コンセプトページのスープではなく、日付付きの証拠を得ます。`--no-llm` は検索のみを強制します；`TESSERAE_QUERY_DRY_RUN` とクラシックな BM25 パスは、あらゆる失敗時の決定論的フォールバックとして残ります。生の取得 — BM25 ヒット、セマンティック検索、明示的な raganything/cognee バックエンド — は `tesserae query` に移動しました。

## 日次セッションチャンク：時間範囲リコールが 20 倍高速に

エンジンのセッションテイラーは、観測されたすべてのターンを日次チャンクストア（`.tesserae/session_chunks.db`）に書き込むようになり、`refresh` は skip-if-held ロックの下でインクリメンタルにバックフィルします。ウィンドウ読み取り（`summary`、`decisions`、ask のアクティビティ取得、MCP）は、カバーされた日をチャンクから提供します — 45k ノードのプロジェクトで測定した結果 48.8 秒に対して 2.3 秒 — パリティ保証された生スキャンフォールバック付きなので、欠落または破損したチャンク db が結果を変えることは決してなく、変わるのは速度だけです。`tesserae sessions chunk-backfill [--since]` はオンデマンドで履歴を構築します。

## `tesserae doctor`

約 2 秒で 20 のヘルスチェック：init/グラフ/設定のパース、レジストリの整合性、陳腐化、ライブロック、ログイン状態、ハイジーン。`--fix` は証明可能に安全な修復のみ（古い pidfile、肥大化したフックログ、レジストリのプルーニング、サイトの再ビルド）を適用し、ライブなコンパイルロックには決して触れません。レポートは `.tesserae/doctor-report.{md,json}` に永続化され、MCP 経由で `doctor_report` として提供されます。

## `init` がインストールのすべて

`tesserae init` はマシン上の LLM CLI を検出し、それらが実際にログインしているかを確認し、選択させます — **カスタム claude 互換エンドポイント**（`--llm-provider custom --llm-base-url … --llm-api-key … --llm-model …`）を含みます。キーは env → プロジェクト → グローバル（`ANTHROPIC_API_KEY`、`ANTHROPIC_BASE_URL`、`TESSERAE_LLM_MODEL`）の順で解決されます；平文で永続化されたキーは一度警告します。再 init は設定を上書きする代わりにマージします。

## よりリーンなバックエンド、正直なフラグ

cognee はデフォルトでオフになり、使用時はサイレンスされ、`tesserae[cognee]` としてインストール可能になり、`codex_cognify` モードは削除されました（−556 LOC）。understand-anything はアーティファクトの存在で自動採用しなくなりました。また、全 26 コマンドに対する敵対的パスにより、すべての嘘つきフラグがリネームまたは削除されました — `summary --project`→`--name`（厳格な名前検証付き）、`context --synthesize`→`--llm`、`refresh --skip-sessions`→`--no-sessions`、`vault --poll-interval`→`--interval`、`ingest --exact`→`--full`、デッドフラグは削除 — 古い綴りはそれぞれ新しいものへの 1 行のポインタを表示して 2 で終了します。動作修正も同乗しています：空の `sessions import` がストアを消去できなくなり、`ingest --dry-run` は本当にドライになり、`serve --dry-run` はビルドの前に実行され、MCP サーバーはついに実際のバージョンを報告します。

## 破壊的変更

削除またはリネームされたすべてのフラグ/コマンドは、代替を表示して 2 で終了します — 何もサイレントに失敗しません。完全なテーブル：`ask --llm|--wiki|--backend|--cognee-*`、`query --llm|--no-llm|--model`、`summary|decisions --project`、`context --synthesize`、`refresh --skip-sessions`、`vault sync --poll-interval`、`vault export --vault`、`ingest --exact`、`research --no-web`、`compile --claude-timeout`、`config setup`、`wiki|projects activate`。
