Une version de correctif qui complète l'histoire multi-projets `serve` de v0.12.0. Compatible avec v0.12.0.

## Tous les `/api/*` se routent vers le bon projet dans un serveur basique

Dans v0.12.0, le simple `tesserae serve` (servant tous les projets enregistrés) ne routait que `/api/ask` — `/api/clip` et `/api/transcript-search` renvoyaient 404, donc le **clipper Chrome ne pouvait pas clipper vers un serveur multi-projets** et la recherche de sessions par projet ne fonctionnait pas. Maintenant, chaque endpoint se routera :

- **`/api/ask`, `/api/ask/health`, `/api/transcript-search`** — routés par le `Referer` `/<alias>/` de la page vers ce projet.
- **`/api/clip`** — un clip provient d'une *page web externe*, il n'y a donc pas de Referer Tesserae pour router. Le serveur résout le projet cible à partir de (1) un alias `project` dans le corps du clip, (2) le seul projet enregistré s'il n'y en a qu'un, sinon (3) un `400` listant les alias disponibles. L'**extension Chrome** a gagné un paramètre *Target project* qui remplit `project`.

Un seul projet `tesserae serve --project X` est inchangé — sa sécurité (la passerelle CORS de l'extension/loopback, le jeton de clip, et la limite de corps de 5 Mo) est identique au byte, puisque les deux modes partagent maintenant une seule implémentation.

La recherche de transcript **échoue fermée avec `409`** quand deux projets enregistrés partagent un nom de répertoire (memex espace les transcripts par nom de base, donc il ne peut pas les distinguer) — plutôt que de mélanger l'historique des sessions d'un projet dans celui d'un autre.

## Aussi

- **Docs** — `docs/ingest.md` a gagné un guide « Construire la couche de concept (`--extractor`) » pour l'extracteur LLM v0.12.0 ; la valeur par défaut `GRAPH_COMPLETION` du backend cognee et la demande en direct fleet sont maintenant documentées.

## Mise à jour de v0.12.0

Compatible. Pour clipper dans un projet spécifique à partir d'un simple `tesserae serve`, définissez **Target project** dans les options de l'extension sur l'alias de ce projet.
