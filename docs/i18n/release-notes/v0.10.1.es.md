Lanzado **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.1) · `pip install --upgrade tesserae==0.10.1`

Una versión de corrección de errores. Sustitución directa sobre v0.10.0.

## Correcciones

- **`tesserae config status` ahora muestra toda la configuración en toda la máquina, no solo el
  backend de LLM.** Reportaba el proveedor/esfuerzo resueltos pero ocultaba todo lo demás
  que `tesserae config setup` gestiona, por lo que la habilitación de cognee y el
  estado de dependencias opcionales eran invisibles. `status` ahora añade una sección
  **Machine-wide settings** (cognee activado/desactivado + modo) y una sección
  **Optional dependencies** (memex / cognee / raganything / understand-anything —
  instaladas o no), imprimidas antes del ping de disponibilidad para que siempre se muestren.

## También en esta versión

- El adaptador **cognee** fue trasladado a **cognee 1.x** y la habilitación de cognee
  en toda la máquina (`config setup --enable-cognee`) llegó, así que una única configuración
  global activa el paso cognify para cada proyecto. El filtro de sesión de auto-captura
  fue extendido para reconocer los propios prompts writing-assistant de cognee 1.x.

## Actualización desde v0.10.0

Sustitución directa. Ejecuta `tesserae config status` para ver el panorama completo
en toda la máquina.
