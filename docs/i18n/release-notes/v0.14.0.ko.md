공개됨 **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.14.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.14.0) · `pip install --upgrade tesserae==0.14.0`

새로운 **활동 요약** 엔진입니다: Tesserae에 하루 또는 일주일 동안 무엇이 일어났는지 물어보면, 모든 AI 에이전트 계정에서 실제 작업(모든 에이전트 세션, 커밋, PR 및 수집된 문서)으로부터 답변을 재구성합니다.

## `tesserae summary`

```bash
tesserae summary --day 2026-07-05
tesserae summary --week
tesserae summary --day 2026-07-05 --project agented   # scope to one project
```

**`activity_summary`** MCP 도구(에이전트가 컨텍스트로 요약을 가져올 수 있도록) 및 **`/summary`** 슬래시 명령어로도 사용 가능합니다.

### 기능

- **모든 AI 계정을 직접 읽습니다.** 백그라운드 인덱스를 신뢰하는 대신, 요청한 기간 동안 하네스 설정 루트 — `~/.claude*`, `~/.codex*`, 워크트리 등 — 을 스캔합니다. 하루는 소수의 트랜스크립트만 건드리므로, 전체 계정 간 스캔은 빠르게 유지됩니다.
- **각 턴의 자체 타임스탬프(KST)로 윈도우를 설정하며, 장시간 실행되는 세션의 시작이 아닙니다** — 따라서 여러 날 세션은 실제로 해당 날에 포함된 턴만 기여합니다.
- **하루 전체를 수집합니다:** 에이전트 메시지, git 커밋, GitHub PR(열림/병합됨/닫힘), 그리고 수집된 문서 — 각각 자신의 시간으로 윈도우됩니다.
- **대화를 요약하며, 단순히 개수만 세지 않습니다.** 결과물은 구조화된 프로젝트별 내러티브입니다 — **Shipped / Fixed / Decisions & Insights / In progress / Docs / Watch** — 더하기 각 세션이 실제로 수행한 작업의 한 줄 요약입니다. 결정론적이고 감사 가능한 팩트 요약이 그 아래에 있습니다.
- **주간은 7일을 하나의 내러티브로 롤업합니다.**

요약은 `.tesserae/summaries/<project>/daily-YYYY-MM-DD.md`에 작성됩니다.

## 인용은 `node-<hash>` 대신 이름을 표시합니다

`ask`, `compile_context`, 및 위키 합성에서 인용된 증거는 이전에 원본 노드 ID(`node-<hash>`)를 인용 마커로 유출했습니다. 이제 엔티티의 실제 제목으로 해석되므로, 답변을 읽을 수 있습니다.

## 업그레이드

v0.13.x로 직접 대체합니다. 새로운 명령은 추가형입니다; 다른 것은 변경되지 않습니다. `tesserae summary`는 기존 세션을 즉시 읽습니다 — 마이그레이션 또는 재컴파일이 필요하지 않습니다.
