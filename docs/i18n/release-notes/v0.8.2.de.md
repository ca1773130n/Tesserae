Veröffentlicht **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.2/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.2) · `pip install --upgrade tesserae==0.8.2`

Nebenversion, die einen Browser-Weg zur Wissensbasis hinzufügt. Die Säule "autonome, proaktive Wissenserfassung" ist jetzt mit einem Klick von jeder Webseite aus erreichbar — und dieselbe Erfassung wird Agenten über MCP zur Verfügung gestellt.

## 1. Web-Clip-Erfassungsendpunkt (`POST /api/clip`)

`tesserae serve` erhält eine JSON-Route, die eine ausgeschnittene Seite in typisierte Graphen-Knoten umwandelt. Sie schreibt eine mit Provenienz versehene `data/ingested/<slug>.md` (Front-Matter `url`/`title`/`tags`/`note`/`clipped_at`, ein optionales `## TL;DR`, Ihre `## Note` und den `## Content`), dann führt den gleichen inkrementellen `ingest_sources`-Weg durch, den die CLI verwendet. Das TL;DR ist bestmöglich über die CLI-gestützte Claude-Schicht (kein API-Schlüssel); ein fehlender/fehlgeschlagener Zusammenfasser blockiert das Clip nie. Die Antwort meldet `{status, path, tldr, node_count, edge_count}`.

## 2. `ingest` MCP-Tool

Der gleiche Erfassungs-Kern ist jetzt ein MCP-Tool, sodass ein Agent Inhalte, die er gefunden hat, erfassen kann — ohne Browser erforderlich. Eingaben: `content` (erforderlich), `url`, `title`, `note`, `tags`, `tldr` (standardmäßig aktiviert). Es erfasst in das aktive Projekt und gibt den gleichen Bericht wie `/api/clip` zurück.

## 3. Chrome-Erweiterung (Web Clipper)

Eine Manifest-V3-Erweiterung befindet sich in `extension/` (entpackt laden; eine Chrome Web Store-Auflistung wird überprüft). Sie erfasst den lesbaren Inhalt einer Seite — oder nur Ihre Auswahl — mit einer optionalen Notiz und Tags sowie einem Pro-Clip-TL;DR-Umschalter, dann POSTs zu Ihrem lokalen `tesserae serve`. Standardverknüpfung `Ctrl+Shift+S` (macOS `Cmd+Shift+S`). Siehe [docs/integrations/chrome-extension.md](../integrations/chrome-extension.de.md).

## 4. Der Clip-Endpunkt ist standardmäßig gehärtet

Da ein Browser jetzt mit `localhost` spricht, ist `/api/clip` gesperrt:

- **Origin-geprüftes CORS.** Nur Browser-Erweiterungen (`chrome-extension://…`) und Loopback-Origins werden reflektiert; eine fremde Website-Origin wird mit `403` abgelehnt, bevor irgendwelche Arbeiten erfolgen — sodass eine Seite, die Sie zufällig besuchen, nicht in Ihren Graph POST können.
- **Privater Netzwerkzugang.** Die Preflight-Antwort gibt `Access-Control-Allow-Private-Network: true` zurück, sodass eine Web-Store-Erweiterung unter aktuellem Chrome `localhost` erreichen kann.
- **Body-Obergrenze.** Anfragen sind begrenzt (5 MB), bevor sie in den Speicher eingelesen werden.

## Upgrade von v0.8.1

Drop-in. Um den Clipper zu verwenden, aktualisieren Sie, sodass `tesserae serve` `/api/clip` offenlegt, führen Sie dann `tesserae serve` aus und laden Sie die Erweiterung. Es sind keine Graphen- oder Konfigurationsänderungen erforderlich.
