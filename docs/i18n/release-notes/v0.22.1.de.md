Veröffentlicht **2026-07-21** · [PyPI](https://pypi.org/project/tesserae/0.22.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.22.1) · `pip install --upgrade tesserae==0.22.1`

Ein kleiner Benutzerfreundlichkeitsfix für die Agent-Org-Tools aus v0.22.0.

`tesserae agents init` leitet die Organisationshierarchie aus Subagent-Rollen ab — aber ein Session-Store, das vor v0.21.0 importiert wurde (als die Subagent-Deskriptor-Erfassung eingeführt wurde), enthält keine, daher wird jeder Agent auf seinen Hauptschlüssel `:default` reduziert und die Org wird flach. In v0.22.0 passierte das stillschweigend, sodass das Ergebnis aussah, als würde das Feature nichts tun.

Jetzt teilt `init` es mit und sagt dir, wie du es behebst:

```
Note: only main (:default) agents were observed, so the org is flat — no
subagent roles to build a hierarchy from.
If you use subagents, re-import to capture them, then re-run init:
  tesserae sessions discover --import && tesserae agents init --force
```

Die Meldung „registry already exists" verweist jetzt auf denselben Re-Import-Pfad, da eine veraltete Registry die andere Seite derselben Falle ist. Beide werden unter `--flat` (eine bewusste Entscheidung) und wenn eine echte Hierarchie vorhanden ist, unterdrückt.

Kein Verhaltensänderung am Inferenzmechanismus selbst. `pip install --upgrade tesserae==0.22.1` (oder `npm i -g @jokerized/tesserae@0.22.1`).
