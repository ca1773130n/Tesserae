버그 수정 릴리스입니다. API 변경 사항이 없으므로 v0.9.0에서 바로 업그레이드할 수 있습니다.

## 수정 사항

- **자체 캡처 피드백 루프 제거.** 세션 모니터가 Tesserae의
  *자체* 컴파일 시간 codex/claude 호출(추출, 합성, 증류 등)을
  마치 사용자의 작업 세션인 것처럼 기록하여 세션 DB를 넘치게 하고
  다음 컴파일의 "발견물 추출"이 자신의 추출 호출에서 추출하도록
  만들었습니다. 이제 발견 및 라이브 테일링에서 제외되며,
  `tesserae sessions prune-internal`로 수정 전에 오염된 데이터베이스를
  정리할 수 있습니다.

- **엔진이 더 이상 거짓으로 "이미 실행 중"을 보고하지 않습니다.** 엔진이
  pidfile을 정리하지 않고 종료되고 OS가 나중에 그 PID를 관련 없는
  프로세스로 재활용했을 때, 간단한 생존성 확인이 통과하여 엔진이
  시작을 거부했습니다. pidfile은 이제 incarnation별 ID(프로세스 시작 시간)를
  기록하고 PID가 살아있고 *동시에* 그 ID가 여전히 일치할 때만
  잠금이 유지되도록 처리하므로, 오래된 pidfile은 자체적으로 복구됩니다.

- **Chrome 확장 프로그램 개인정보보호정책.** "Clip to Tesserae"
  확장 프로그램의 완전한 개인정보보호정책을 추가했습니다
  (Chrome Web Store 필수).

## v0.9.0에서 업그레이드

바로 업그레이드할 수 있습니다. 프로젝트의 세션 목록이 Tesserae의
자체 프롬프트로 오염되어 보이면 `tesserae sessions prune-internal`을
한 번 실행하세요.
