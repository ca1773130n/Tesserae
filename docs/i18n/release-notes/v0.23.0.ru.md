Выпущено **2026-07-22** · [PyPI](https://pypi.org/project/tesserae/0.23.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.23.0) · `pip install --upgrade tesserae==0.23.0`

Многоуровневая память агентов (v0.21) могла конденсировать, но только по запросу —
на `tesserae refresh`, под давлением памяти. Этот выпуск дает всегда работающему
движку **цикл отдыха**: он консолидирует память агентов самостоятельно, так же как
мозг консолидирует информацию во время отдыха.

## Консолидация во время отдыха

Оставьте `tesserae engine` работающим, и он теперь следит за часами активности.
Когда проект переходит в **режим ожидания** — нет изменений или новых сеансов
несколько минут — он запускает процесс дистилляции для всех агентов этого проекта,
переорганизуя и сжимая их накопленный опыт, пока вы отсутствуете. Периодический
**потолок** (по умолчанию 6ч) гарантирует, что даже постоянно занятой проект все
равно консолидирует данные.

```bash
tesserae engine                      # idle consolidation on by default
tesserae engine --consolidate-idle 600 --consolidate-every 43200
tesserae engine --all                # every registered project, on idle
tesserae engine --no-consolidate     # opt out
```

Режим ожидания — это точный триггер, как в мозге: консолидация происходит,
когда система находится в состоянии покоя, а не в произвольный час по часам.

## Безопасность по конструкции

Цикл оборачивает существующий проход `maybe_distill_on_refresh`, поэтому все его
гарантии сохраняются:

- **Холостой ход, если вы не согласились.** Ничего не запускается без
  `TESSERAE_AGENT_DISTILL=1` — тот же гейт, который всегда использовала
  дистилляция, плюс водяной знак на уровне агента и проверки давления памяти.
  Флаги включены по умолчанию, потому что сам проход отказывается делать что-либо
  без согласия.
- **Никогда не перекрывает переcompilation.** Консолидация работает под гейтом
  компиляции, поэтому она и конвейер взаимно исключают друг друга — и чтобы это
  сохранялось в режиме однопоточного демона, неустановленный гейт теперь по
  умолчанию использует приватный семафор.
- **Никогда не беспокоит демон.** Он работает в своем собственном потоке (существующий
  идиом опроса демона), никогда не повышает в цикл событий, выходит оперативно при
  выключении и полностью пропускается для разовых запусков `engine`.
- **Детерминированные артефакты, нетронутые.** Дистиллированные графики сохраняют
  свою байтовую идемпотентность; монотонные часы активности никогда не сохраняются.

## Флаги

| Флаг | По умолчанию | Значение |
|---|---|---|
| `--consolidate` / `--no-consolidate` | on | включить цикл отдыха |
| `--consolidate-idle` | `300` | секунды тишины перед консолидацией |
| `--consolidate-every` | `21600` | потолок — консолидировать не реже, чем так часто (`0` = выкл) |
| `--consolidate-check` | `30` | как часто поток проверяет часы |

Полное поведение и заметки флота: [`docs/engine-consolidation.md`](../engine-consolidation.ru.md).
`pip install --upgrade tesserae==0.23.0` (или `npm i -g @jokerized/tesserae@0.23.0`).
