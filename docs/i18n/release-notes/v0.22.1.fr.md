Publié **2026-07-21** · [PyPI](https://pypi.org/project/tesserae/0.22.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.22.1) · `pip install --upgrade tesserae==0.22.1`

Un petit correctif d'accessibilité pour les outils d'org d'agents livrés dans v0.22.0.

`tesserae agents init` déduit la hiérarchie d'org à partir des rôles de sous-agents — mais un magasin de sessions importé *avant* v0.21.0 (quand la capture du descripteur de sous-agent a été livrée) n'en porte aucun, donc chaque agent s'effondre sur sa clé `:default` principale et l'org devient plate. Dans v0.22.0, cela s'est produit silencieusement, donc le résultat ressemblait au fait que la fonctionnalité ne faisait rien.

Maintenant `init` le dit, et vous indique comment le corriger :

```
Note: only main (:default) agents were observed, so the org is flat — no
subagent roles to build a hierarchy from.
If you use subagents, re-import to capture them, then re-run init:
  tesserae sessions discover --import && tesserae agents init --force
```

Le message « la registry existe déjà » pointe maintenant vers le même chemin de ré-importation, car une registry obsolète est l'autre moitié du même piège. Les deux sont supprimés sous `--flat` (un choix explicite) et lorsqu'une hiérarchie réelle est présente.

Aucun changement de comportement pour l'inférence elle-même. `pip install --upgrade tesserae==0.22.1` (ou `npm i -g @jokerized/tesserae@0.22.1`).
