Veröffentlicht **2026-06-29** · [PyPI](https://pypi.org/project/tesserae/0.12.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.12.1) · `pip install --upgrade tesserae==0.12.1`

Eine Patch-Release, die die Multi-Projekt-`serve`-Geschichte von v0.12.0 abschließt. Ein direkter Ersatz für v0.12.0.

## Jeder `/api/*`-Endpunkt leitet zum richtigen Projekt auf einem einfachen Server weiter

In v0.12.0 leitete das reine `tesserae serve` (das alle registrierten Projekte serviert) nur `/api/ask` weiter — `/api/clip` und `/api/transcript-search` gaben `404` zurück, sodass das **Chrome-Clipper-Plugin nicht in einen Multi-Projekt-Server clippen konnte** und die per-Projekt-Sitzungssuche nicht funktionierte. Jetzt leitet jeder Endpunkt weiter:

- **`/api/ask`, `/api/ask/health`, `/api/transcript-search`** — leiten weiter basierend auf dem `/<alias>/` Referer der Seite zu diesem Projekt.
- **`/api/clip`** — ein Clip kommt von einer *externen* Webseite, daher gibt es keinen Tesserae Referer zum Weiterleiten. Der Server ermittelt das Zielprojekt aus (1) einem `project`-Alias im Clip-Body, (2) dem einzigen registrierten Projekt, wenn es nur eines gibt, sonst (3) einem `400`, das die verfügbaren Aliase auflistet. Die **Chrome Extension** erhielt eine *Target project*-Einstellung, die `project` ausfüllt.

Single-Projekt `tesserae serve --project X` ist unverändert — seine Sicherheit (das Extension/Loopback-CORS-Gate, das Clip-Token und die 5 MB Body-Obergrenze) ist byte-identisch, da beide Modi jetzt eine Implementierung teilen.

Transkript-Suche **schlägt mit `409` fehl**, wenn zwei registrierte Projekte einen Verzeichnisnamen teilen (memex verwaltet Transkripte nach Basename-Namespace, daher kann es sie nicht unterscheiden) — anstatt die Sitzungshistorie eines Projekts mit einem anderen zu vermischen.

## Außerdem

- **Docs** — `docs/ingest.md` erhielt einen „Building the concept layer (`--extractor`)"-Leitfaden für den v0.12.0 LLM-Extractor; der `GRAPH_COMPLETION`-Standard des Cognee-Backends und die Fleet-Live-Ask sind jetzt dokumentiert.

## Upgrade von v0.12.0

Drop-in. Um in ein bestimmtes Projekt von einem reinen `tesserae serve` zu clippen, stellen Sie **Target project** in den Extension-Optionen auf den Alias dieses Projekts ein.
