Дата выпуска **2026-06-08** · [PyPI](https://pypi.org/project/tesserae/0.6.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.6.0) · `pip install --upgrade tesserae==0.6.0`

Tesserae 0.6.0 — это **переработка CLI**. Всё, что делает движок, было погребено под `tesserae project <26 скрытых подкоманд>`, при этом у `setup` было 29 флагов, а у `compile` — 26; голый `tesserae` вываливал сырой парсер извлечения. 0.6.0 заменяет всё это **плоским деревом команд-глаголов** — повседневные глаголы на верхнем уровне, горстка небольших групп-существительных, сгруппированная справка и `EXAMPLES` у каждой команды. Это **ломающее изменение**, на которое мы сознательно пошли до версии 1.0: старые команды не превращаются молча в псевдонимы, а печатают однострочную переадресацию `… has moved → …` и завершаются с кодом 2, так что миграция становится очевидной, а не загадочной. Движок, граф, инструменты MCP и сервер `tesserae_mcp` не изменились — этот выпуск целиком посвящён той поверхности, которую набирает человек.

## 1. Новое дерево команд

```
tesserae <command>

EVERYDAY    init compile context ask serve status
AUTOMATION  engine refresh research
ANALYSIS    query lint
GROUPS      sessions vault export code config projects integrations extract
LAB         lab
```

- **Повседневные глаголы — на верхнем уровне.** `tesserae compile`, `tesserae serve`, `tesserae ask`, `tesserae context "…"` — без префикса `project`.
- **`status`** — новая сводка только для чтения (число узлов/рёбер, последняя компиляция, vault, сайт).
- **`serve`** автоматически собирает сайт, когда он отсутствует или устарел (пропустить можно через `--no-build`).
- **Специализированные команды живут в небольших группах-существительных:** `sessions import|discover|list`, `vault sync|export|prune|set-root|sync-all`, `export harness|graphiti|site`, `code ingest|sync`, `config llm|show`, `projects register|list|activate|unregister|mcp-config`, `integrations refresh <name>`, `extract`, `lab evolve|schema-drift`.
- **`export site`** вбирает в себя прежние глаголы `build-site`, `deploy` (`--deploy`) и `watch` (`--watch`).
- **Сгруппированная корневая справка + `EXAMPLES`** — `tesserae` без аргументов показывает сгруппированное дерево; справка `--help` каждой команды завершается реальными, исполнимыми примерами.

## 2. `init` и `compile` на диете

- **`init`: 29 → 8 флагов.** По умолчанию — мастер; `--yes` запускает его неинтерактивно (опциональные интеграции — Cognee, RAG-Anything, Understand-Anything — по умолчанию **выключены**, а цвет автоматически отключается вне TTY, поглощая прежние флаги `--no-color`/`--no-cognee`/`--skip-*`). `--bare` создаёт рабочее пространство без мастера. Флаги LLM-бэкенда (`--llm-provider`, `--claude-config-dir`, `--codex-home`) остаются.
- **`compile`: 26 → 8 флагов.** Повседневные флаги сохраняются (`--changed-only`, `--no-sessions`, `--limit`, `--refresh-integrations`, три LLM-флага и произвольный `compile <paths>`). Каждый удалённый рычажок интеграции (kuzu/cognee/trends/vault-pull/…) переезжает в блок **`compile_options`** в `.tesserae/config.json` под тем же именем, с сохранением прежнего значения по умолчанию — поэтому поведение идентично, просто поверхность стала тише. Полную таблицу `compile_options` см. в [кратком руководстве](../quickstart.ru.md).

## 3. Чистый разрыв при миграции — никаких молчаливых псевдонимов

Каждый устаревший вызов печатает ровно одну строку и завершается с кодом 2:

```
$ tesserae project compile
tesserae project compile has moved → tesserae compile
```

Таблица переадресации охватывает все старые команды (включая трёхтокенные формы вроде `project sessions import` и прежние команды верхнего уровня `wiki`/`llm-defaults`), а голый путь к markdown (`tesserae notes/x.md`) направляет вас к `tesserae extract`. Хуки, CI-дымовой тест, релизный процесс и все внутрирепозиторные строки времени выполнения были перенесены синхронно; документация и все восемь README (плюс каждая локализованная копия) теперь говорят на языке нового дерева.

## Обновление с v0.5.0

- **Заново выучите глаголы, которые вы вызываете в скриптах.** Самые частые замены: `project setup --yes …` → `tesserae init --yes`, `project compile` → `tesserae compile`, `project build-site` → `tesserae export site`, `project serve` → `tesserae serve`, `project obsidian-sync` → `tesserae vault sync`, `project sync-code` → `tesserae code sync`, `tesserae llm-defaults …` → `tesserae config llm …`, `tesserae wiki …` → `tesserae projects …`. Запустите старую форму команды один раз — сообщение `… has moved → …` подскажет новую.
- **Перенесли флаг `compile`?** Если вы прописывали в скриптах `compile --trends`, `--no-vault-pull`, `--cognee-*` и т. п., вместо этого задайте соответствующий `compile_options.<key>` в `.tesserae/config.json` (таблица — в кратком руководстве).
- **Флаги интеграций у `init` исчезли из CLI.** Включите Cognee / RAG-Anything / Understand-Anything, ответив на подсказки мастера `tesserae init`, или отредактировав `.tesserae/config.json` и запустив `tesserae integrations refresh <name>`.
- В **графе, vault, сайте, инструментах MCP или сервере `tesserae_mcp`** ничего не изменилось — изменился только обращённый к человеку CLI.
