Veröffentlicht am **2026-08-31** · [PyPI](https://pypi.org/project/tesserae/0.37.0/) · [GitHub-Release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.37.0) · `pip install --upgrade tesserae==0.37.0`

Diese Version fügt einen Schalter hinzu und korrigiert mehrere Aussagen.

## Die dichte Spur kann einen trainierten Encoder anfordern

Auf einem Korpus aus 148 Aufsätzen war der mitgelieferte statische Embedder
`model2vec` der gesamte Abstand zwischen dem Graphen und einem schlichten
Vektorspeicher. Recall über verschiedene Dokumente, bei gleicher Fusion, gleichem
Graphen und gleicher Dokument-Deduplizierung:

| Variante | @10 Dok. | @50 Dok. |
| --- | --- | --- |
| Mem0-OSS-Rohabschnittsspeicher, eigener Encoder | 0.784 | 0.942 |
| Mem0-OSS-Rohabschnittsspeicher, dasselbe bge-base | 0.775 | 0.944 |
| Tesserae, mitgeliefertes statisches model2vec | 0.754 | 0.914 |
| **Tesserae, bge-base in der dichten Spur** | **0.791** | **0.962** |

`TESSERAE_EMBEDDING_PREFER` wählt das Backend, wenn der Aufrufer `auto` verlangt
(`model2vec`, `st`, `openai`, `hash`); ein Wert, der kein Backend benennt, wird
gemeldet und ignoriert, statt still auf den Hash-Platzhalter durchzufallen.
`TESSERAE_ST_MODEL` benennt das sentence-transformers-Modell — die Vorgabe wechselt
vom ungemessenen `all-MiniLM-L6-v2` zum gemessenen `BAAI/bge-base-en-v1.5`.

```bash
uv pip install sentence-transformers
export TESSERAE_EMBEDDING_PREFER=st
export TESSERAE_ST_MODEL=BAAI/bge-base-en-v1.5   # the default; any Hugging Face name
```

Die auto-Leiter bleibt unverändert: `model2vec` zuerst, damit
`pip install tesserae` ohne torch auskommt und eine Installation, die die Variable
nie setzt, sich genau wie zuvor verhält.

## Was die Messung tatsächlich gezeigt hat

Bei gleichem Encoder finden der Graph und ein roher Abschnittsspeicher dieselben
Dokumente: gepaart über 57 Fragen sind es bei zehn Dokumenten 8 Siege, 8
Niederlagen und 41 Unentschieden (Vorzeichentest p=1.0). Das ist Gleichstand, und
die Dokumentation sagt jetzt Gleichstand — die frühere Formulierung behauptete, der
Graph liege vorn, und verglich dabei zwei verschiedene Encoder.

Der Retriever sieht außerdem den Datumsstempel und den Anweisungstext von
LongMemEval nicht mehr, die zuvor für jeden Arm Teil der Anfrage waren.

## Wo sich das Design wirklich unterscheidet

Vom Graphen ausgewählte Dokumente als Originalprosa statt als extrahierte Aussagen
zu packen, erreichte unter einem `gpt-4o-mini`-Richter +28.9% gegenüber einer
Passagen-Kontrolle. Mit einem lokalen 7B-Richter wiederholt sind es +7%, nicht
signifikant, und auf einem zweiten Korpus verliert es. Die README trägt alle drei
Zahlen, nicht die beste.

## Upgrade

Nichts zu migrieren. Bestehende Graphen sind nicht betroffen; der Schalter ist
opt-in und das Standard-Backend bleibt unverändert.
