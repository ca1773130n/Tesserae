Publié le **2026-07-05** · [PyPI](https://pypi.org/project/tesserae/0.14.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.14.0) · `pip install --upgrade tesserae==0.14.0`

Un nouveau moteur de **résumé d'activité** : demandez à Tesserae ce qui s'est passé un jour donné ou au cours d'une semaine, et il reconstruit la réponse à partir de votre travail réel — chaque session d'agent, commit, PR et document ingéré — dans tous vos comptes d'agent IA.

## `tesserae summary`

```bash
tesserae summary --day 2026-07-05
tesserae summary --week
tesserae summary --day 2026-07-05 --project agented   # scope to one project
```

Également disponible en tant qu'outil MCP **`activity_summary`** (pour qu'un agent puisse récupérer un résumé comme contexte) et commande slash **`/summary`**.

### Ce qu'il fait

- **Lit directement tous les comptes IA.** Il analyse vos racines de configuration de harnais — `~/.claude*`, `~/.codex*`, worktrees et tout le reste — pour la fenêtre demandée, plutôt que de faire confiance à un index d'arrière-plan qui peut prendre du retard. Une journée ne touche qu'une poignée de transcriptions, donc une analyse complète entre comptes reste rapide.
- **Fenêtre chaque tour d'après son propre horodatage**, en **KST**, jamais le début d'une session de longue durée — ainsi une session sur plusieurs jours ne contribue que les tours qui tombent réellement dans la journée.
- **Rassemble toute la journée :** messages d'agent, commits git, PR GitHub (ouvertes / fusionnées / fermées) et documents ingérés — chacun fenêtré selon son propre temps.
- **Résume les conversations, pas seulement les décomptes.** La sortie est un récit structuré, par projet — **Shipped / Fixed / Decisions & Insights / In progress / Docs / Watch** — plus un résumé d'une ligne de ce que *chaque session* a réellement fait. Un résumé de faits déterministe et vérifiable se trouve en dessous.
- **L'hebdomadaire** regroupe les sept jours en un seul récit.

Les résumés sont écrits dans `.tesserae/summaries/<project>/daily-YYYY-MM-DD.md`.

## Les citations affichent les noms, pas `node-<hash>`

Les preuves citées dans `ask`, `compile_context` et la synthèse wiki laissaient auparavant fuiter des ids de nœud bruts (`node-<hash>`) comme marqueurs de citation. Elles se résolvent désormais vers le titre réel de l'entité, ce qui rend les réponses lisibles.

## Mise à niveau

Remplacement direct de la v0.13.x. La nouvelle commande est additive ; rien d'autre ne change. `tesserae summary` lit vos sessions existantes à la volée — aucune migration ni recompilation requise.
