发布于 **2026-09-17** · [PyPI](https://pypi.org/project/tesserae/0.41.5/) · [GitHub 发布](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.5) · `pip install --upgrade tesserae==0.41.5`

一次夜间矛盾检查在一个含 71,783 条主张的图上卡住了。矛盾检测比较了每一对主张，并为每一对重建两段文本，
始终没有跑完。正确答案是一对也没有。`CONTRADICTING_CLAIMS` lint 检查也有同样的循环。

## 改了什么

- **矛盾检测只比较可能互相矛盾的主张。** 构成矛盾需要一条说 "outperforms" 的主张和另一条说
  "is outperformed by" 的主张。现在按主张说的是哪一种把它们分开，只比较两边各取一条的组合。
  一边为空时什么都不比较：形状与那张图相同的合成主张现在只需 0.042 秒。
- **`lint` 也做了同样的修复。** 它的 `CONTRADICTING_CLAIMS` 检查走的是同样的逐对循环。
- **结果没有变化。** 两者返回的结果与之前完全相同，已在数千张随机图上与旧代码逐一对照。

## 升级

无需迁移。在同一主题两侧各有数千条主张的图仍然需要时间，因为每一对都是答案的一部分。
