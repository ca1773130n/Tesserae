Released **2026-07-22** · [PyPI](https://pypi.org/project/tesserae/0.24.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.24.0) · `pip install --upgrade tesserae==0.24.0`

v0.23은 유휴 상태 동안 메모리를 압축하는 수면 사이클을 엔진에 제공했습니다. 하지만 뇌의 통합은 단순한 압축만 아닙니다 — 다시는 방문하지 않는 정보를 **제거**하고, 연관된 기억들을 **연결**합니다. 이번 릴리스는 이 두 가지 작업을 추가하여, 데몬의 유휴 사이클이 이제 세 가지를 모두 실행합니다.

## 1 · 미사용 지식 망각 (LRU)

지금까지 발견(finding)의 감쇠는 그 **생성 시간**을 기반으로 했습니다. 이는 체계적으로 오래되고 드물게 보이는 문제들을 묻어버립니다 — 정확히 문제가 재발할 때 가장 필요한 것들입니다. 이제 **모든 의미 있는 읽기는 접근을 기록**합니다: `search`, `ask`, `query`, `context`, `node_context`, `drill_down`, 세션 발견 조회, 그리고 에이전트 범위 읽기 모두 `last_accessed_at`을 메모리 사이드카에 기록합니다.

통합 패스는 **검색 최근성, 생성 시간이 아닌**으로 감쇠합니다. 계속 참고하는 지식은 선명하게 유지되고, 다시 방문하지 않는 지식은 수면 사이클 동안 천천히 퇴색되어 흡수되거나 강등됩니다 — 진정한 LRU 망각입니다. (발견은 절대 *삭제*되지 않습니다; 이를 인용한 요약본에 포함되어 `agents drill`을 통해 도달할 수 있습니다.)

## 2 · 새로운 연결 발견

수면은 또한 기억을 다시 실행하고 먼 것들을 연결합니다. 새로운 **associate** 패스는 통합 중에 실행됩니다: 임베딩을 사용하여 **프로젝트 내 다양한 에이전트 간의** *관련된* — 동일하지 않은 — 노드를 찾고 그들 사이에 `shares_concept_with` 연결을 추가합니다. 발견된 링크는 사이클을 거치면서 **누적**되며, 검색, Personalized PageRank, 연합 쿼리로 순회할 수 있으므로 에이전트는 명시적으로 연결하지 않은 관련 지식에 도달할 수 있습니다.

## 결정론적 아티팩트 보호

두 작업 모두 **사이드카에만 쓰기**합니다 — 접근 상태는 `node_memory` 저장소에, 발견된 링크는 읽기 시에 메모리에 병합되는 누적 `.tesserae` 오버레이에 씁니다. **`graph.json`은 절대 건드리지 않으므로**, 컴파일은 바이트 동일성을 유지합니다. 발견된 링크는 임베딩 기반이고 (따라서 머신 종속적이므로), 정확히 이 이유로 오버레이에 존재하고 결정론적 그래프에는 절대 존재하지 않습니다. 연결은 실제 임베딩 백엔드 (`pip install "tesserae[semantic]"`)에서 차단되며, 없으면 조용한 no-op입니다.

## 완전한 사이클

```bash
export TESSERAE_AGENT_DISTILL=1
tesserae engine        # idle → compress · forget-by-disuse · associate
```

설정할 새로운 항목이 없습니다 — 세 가지 작업은 기존의 유휴 통합 틱 내에서 실행되며, 컴파일 게이트 아래에 있고, 재컴파일을 차단하지 않습니다. 전체 세부 사항: [`docs/engine-consolidation.md`](../engine-consolidation.ko.md).

`pip install --upgrade tesserae==0.24.0` (또는 `npm i -g @jokerized/tesserae@0.24.0`를 실행하세요.
