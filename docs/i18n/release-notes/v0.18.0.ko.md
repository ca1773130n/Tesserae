하나의 관찰에서 출발한 명령어 표면의 전면 개정입니다: `tesserae ask "what happened recently?"`는 예전에 정적 개념 페이지와 솔직한 어깨 으쓱을 반환했습니다. 주제: **명령어들이 이제 이름이 약속하는 일을 합니다.**

## `ask`가 검색을 계획하고 — 기본적으로 답변합니다

`tesserae ask`는 더 이상 `--llm`이 필요하지 않습니다: 모델이 먼저 질문을 읽고, 어떤 지식 그래프 프리미티브(타임라인, 최근 세션, 활동 다이제스트, 시간적 사실, 위키 페이지)가 답할 수 있는지 계획하고, 그 계획을 실행하고, 인용이 포함된 답변을 합성합니다. 시간 관련 질문은 개념 페이지 수프 대신 날짜가 있는 증거를 얻습니다. `--no-llm`은 검색 전용을 강제합니다; `TESSERAE_QUERY_DRY_RUN`과 클래식 BM25 경로는 모든 실패 시 결정적 폴백으로 남습니다. 원시 검색 — BM25 히트, 시맨틱 검색, 명시적 raganything/cognee 백엔드 — 은 이제 `tesserae query`에 있습니다.

## 일별 세션 청크: 20배 빠른 시간 범위 조회

엔진의 세션 테일러는 이제 관찰된 모든 턴을 일별 청크 저장소(`.tesserae/session_chunks.db`)에 기록하고, `refresh`는 skip-if-held 잠금 아래에서 이를 증분 백필합니다. 윈도우 읽기(`summary`, `decisions`, ask의 활동 검색, MCP)는 커버된 날짜를 청크에서 제공합니다 — 45k 노드 프로젝트에서 측정 결과 48.8초 대비 2.3초 — 그리고 패리티가 보장된 원시 스캔 폴백이 있어, 누락되거나 손상된 청크 db는 결과를 바꿀 수 없고 속도만 바꿉니다. `tesserae sessions chunk-backfill [--since]`은 필요 시 이력을 구축합니다.

## `tesserae doctor`

약 2초 안에 20개의 상태 점검: init/그래프/구성 파싱, 레지스트리 일관성, 오래됨, 라이브 잠금, 로그인 상태, 위생. `--fix`는 확실히 안전한 복구만 적용하고 (오래된 pidfile, 과대 훅 로그, 레지스트리 정리, 사이트 재빌드) 라이브 컴파일 잠금은 절대 건드리지 않습니다. 보고서는 `.tesserae/doctor-report.{md,json}`에 지속되고 MCP를 통해 `doctor_report`로 제공됩니다.

## `init`이 설치의 전부입니다

`tesserae init`은 머신의 LLM CLI들을 감지하고, 실제로 로그인되어 있는지 확인하고, 선택하게 합니다 — **커스텀 claude 호환 엔드포인트** (`--llm-provider custom --llm-base-url … --llm-api-key … --llm-model …`) 포함. 키는 env → 프로젝트 → 전역 순으로 해석됩니다 (`ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL`, `TESSERAE_LLM_MODEL`); 평문으로 저장된 키는 한 번 경고합니다. 재-init은 구성을 덮어쓰는 대신 병합합니다.

## 더 가벼운 백엔드, 정직한 플래그

cognee는 이제 기본적으로 꺼져 있고, 사용 시 조용하며, `tesserae[cognee]`로 설치 가능하고, `codex_cognify` 모드는 사라졌습니다 (−556 LOC). understand-anything는 더 이상 아티팩트 존재만으로 자동 채택되지 않습니다. 그리고 26개 명령어 전체에 대한 적대적 검토가 모든 거짓말하는 플래그를 이름 변경하거나 제거했습니다 — `summary --project`→`--name` (엄격한 이름 검증 포함), `context --synthesize`→`--llm`, `refresh --skip-sessions`→`--no-sessions`, `vault --poll-interval`→`--interval`, `ingest --exact`→`--full`, 죽은 플래그 삭제 — 각 이전 표기는 새 표기를 가리키는 한 줄을 출력하고 2로 종료합니다. 동작 수정도 함께 들어갔습니다: 빈 `sessions import`는 더 이상 저장소를 지울 수 없고, `ingest --dry-run`은 진짜로 dry이며, `serve --dry-run`은 빌드 전에 실행되고, MCP 서버는 마침내 실제 버전을 보고합니다.

## 파괴적 변경 사항

제거되거나 이름이 바뀐 모든 플래그/명령어는 대체물을 출력하고 2로 종료합니다 — 아무것도 조용히 실패하지 않습니다. 전체 표: `ask --llm|--wiki|--backend|--cognee-*`, `query --llm|--no-llm|--model`, `summary|decisions --project`, `context --synthesize`, `refresh --skip-sessions`, `vault sync --poll-interval`, `vault export --vault`, `ingest --exact`, `research --no-web`, `compile --claude-timeout`, `config setup`, `wiki|projects activate`.
