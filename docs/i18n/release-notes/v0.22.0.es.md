Lanzado **2026-07-21** · [PyPI](https://pypi.org/project/tesserae/0.22.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.22.0) · `pip install --upgrade tesserae==0.22.0`

v0.21.0 incluía memoria por agente en capas, pero la mitad solo era accesible a través de MCP y `tesserae agents init` colocaba cada agente bajo `org:root`. Esta versión hace que toda la característica sea usable desde la terminal.

## `init` construye una organización real

`tesserae agents init` ahora deduce la jerarquía desde una señal que ya existe: un rol de subagente (`claude-code:me:reviewer`) se vincula al agente principal que lo generó (`claude-code:me:default`), en lugar de que todos terminen planos bajo `org:root`. Obtienes una organización multinivel funcional con un solo comando — sin necesidad de `set-parent`. Pasa `--flat` para el comportamiento anterior, e `init` ahora imprime el árbol propuesto para que veas lo que decidió.

```
org:root
  claude-code:me:default   Main    sessions=42
    claude-code:me:reviewer   Reviewer   sessions=8   distilled_through=2026-07-20T…
    claude-code:me:planner    Planner    sessions=5   (not distilled)
```

## Lecturas con alcance desde la CLI

`--agent KEY` ahora funciona en `tesserae query`, `ask` y `context` — la recuperación y síntesis se ejecutan sobre la vista resuelta del agente (una clave **worker** ve su propia memoria bruta + destilada, una clave **manager** ve las capas destiladas de sus reportes, `org` ve todo el equipo). Anteriormente, este alcance existía solo como un argumento de MCP.

```bash
tesserae query "release checklist" --agent claude-code:me:reviewer
tesserae ask "what does my team know about deploys?" --agent org
```

Las claves desconocidas y los agentes no destilados fallan ruidosamente con el comando de remedio exacto, nunca una respuesta silenciosamente vacía.

## Inspeccionar la organización

- **`tesserae agents tree`** — el organigrama como árbol indentado, cada agente anotado con recuento de sesiones y cuán antigua es su memoria destilada.
- **`tesserae agents show KEY`** — resuelve una vista e imprime su modo, agentes miembros, rutas de artefactos, recuentos de nodos y marcas de antigüedad.
- **`tesserae agents drill NODE_ID [--agent KEY]`** — la escalada auditada desde una nota destilada hasta su evidencia bruta L0, ahora un comando CLI de primera clase (alive / changed / absorbed / gone). La lógica `drill_down` se comparte con la herramienta MCP, por lo que ambas superficies se comportan idénticamente.

## Bajo el capó

La inferencia de jerarquía de roles es una función pura y determinista; el núcleo `drill_down` se extrajo para que el servidor CLI y MCP compartan una ruta de código auditada. Sin cambios en los artefactos destilados o sus garantías de determinismo. Puramente aditivo — cada comando existente se comporta exactamente igual cuando `--agent` está ausente.

Guía: [`docs/agent-memory.md`](../agent-memory.md). `pip install --upgrade tesserae==0.22.0` (o `npm i -g @jokerized/tesserae@0.22.0`).
