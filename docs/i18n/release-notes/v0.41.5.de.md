Veröffentlicht am **2026-09-17** · [PyPI](https://pypi.org/project/tesserae/0.41.5/) · [GitHub-Release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.5) · `pip install --upgrade tesserae==0.41.5`

Ein nächtlicher Widerspruchslauf blieb auf einem Graphen mit 71,783 Aussagen hängen. Die
Widerspruchserkennung verglich jedes Paar von Aussagen, baute für jedes Paar beide Texte neu auf und wurde
nie fertig. Die richtige Antwort war: kein einziges Paar. Die Lint-Prüfung `CONTRADICTING_CLAIMS` hatte
dieselbe Schleife.

## Was sich geändert hat

- **Die Widerspruchserkennung vergleicht nur Aussagen, die sich widersprechen können.** Ein Widerspruch
  braucht eine Aussage mit "outperforms" und eine andere mit "is outperformed by". Aussagen werden jetzt
  danach getrennt, welche der beiden sie enthalten, und nur Paare mit je einer Aussage von jeder Seite
  werden verglichen. Ist eine Seite leer, wird nichts verglichen: synthetische Aussagen in der Form
  dieses Graphen brauchen jetzt 0.042 Sekunden.
- **`lint` hat dieselbe Korrektur bekommen.** Seine Prüfung `CONTRADICTING_CLAIMS` durchlief dieselbe
  Schleife über alle Paare.
- **Die Ergebnisse sind unverändert.** Beide liefern genau dasselbe wie vorher, geprüft gegen den alten
  Code auf Tausenden zufälliger Graphen.

## Upgrade

Nichts zu migrieren. Ein Graph mit Tausenden Aussagen auf beiden Seiten eines Themas braucht weiterhin
Zeit, denn jedes dieser Paare gehört zur Antwort.
