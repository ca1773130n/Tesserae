Released **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.2/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.2) · `pip install --upgrade tesserae==0.8.2`

Минорный релиз, который добавляет путь сбора контента из браузера в базу знаний. Столп "автономный, проактивный сбор знаний" теперь доступен одним кликом с любой веб-страницы — и тот же сбор контента доступен агентам через MCP.

## 1. Конечная точка сбора веб-страниц (`POST /api/clip`)

`tesserae serve` получает JSON-маршрут, который преобразует скопированную страницу в узлы типизированного графа. Он записывает помеченный по источникам файл `data/ingested/<slug>.md` (фронт-материал `url`/`title`/`tags`/`note`/`clipped_at`, опциональный раздел `## TL;DR`, ваш раздел `## Note` и раздел `## Content`), затем запускает тот же инкрементальный путь `ingest_sources`, который использует CLI. TL;DR создаётся на основе слоя Claude, поддерживаемого CLI (без API ключа); отсутствие или ошибка резюме никогда не блокируют сбор контента. Ответ содержит `{status, path, tldr, node_count, edge_count}`.

## 2. Инструмент `ingest` для MCP

Теперь то же ядро сбора контента — это инструмент MCP, поэтому агент может собирать найденный контент — браузер не требуется. Входные параметры: `content` (обязательный), `url`, `title`, `note`, `tags`, `tldr` (по умолчанию включен). Он выполняет сбор в активный проект и возвращает тот же отчет, что и `/api/clip`.

## 3. Расширение Chrome (Web Clipper)

Расширение Manifest V3 находится в папке `extension/` (загрузить распакованное; листинг в Chrome Web Store находится на рассмотрении). Оно захватывает читаемый контент страницы — или только ваше выделение — с опциональной заметкой и тегами, а также переключателем TL;DR на каждый клип, затем отправляет POST на ваш локальный `tesserae serve`. Комбинация по умолчанию `Ctrl+Shift+S` (macOS `Cmd+Shift+S`). См. [docs/integrations/chrome-extension.md](../integrations/chrome-extension.md).

## 4. Конечная точка клипа защищена по умолчанию

Поскольку браузер теперь обращается к `localhost`, `/api/clip` защищена по умолчанию:

- **Проверка источника CORS.** Только источники расширения браузера (`chrome-extension://…`) и loopback отражаются; иностранный источник отклоняется с ошибкой `403` до выполнения любой работы — поэтому страница, которую вы случайно посещаете, не может выполнить POST в ваш граф.
- **Private Network Access.** Preflight ответ содержит `Access-Control-Allow-Private-Network: true`, поэтому расширение из Web Store может обращаться к `localhost` в текущей версии Chrome.
- **Ограничение размера тела.** Запросы ограничены (5 МБ) перед чтением в памяти.

## Обновление с v0.8.1

Drop-in. Чтобы использовать клипер, обновитесь так, чтобы `tesserae serve` предоставлял `/api/clip`, затем запустите `tesserae serve` и загрузите расширение. Никаких изменений графа или конфигурации не требуется.
