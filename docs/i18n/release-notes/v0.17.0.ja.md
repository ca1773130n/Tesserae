Released **2026-07-09** · [PyPI](https://pypi.org/project/tesserae/0.17.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.17.0) · `pip install --upgrade tesserae==0.17.0`

このリリースでは、兄弟プロジェクトの 2 つの LLM-wiki — [alfadur7/llm-wiki-newsroom](https://github.com/alfadur7/llm-wiki-newsroom) と [langchain-ai/openwiki](https://github.com/langchain-ai/openwiki) — との深い比較から最適なアイデアを統合し、すべてが Tesserae が既に持っていたものに対して採用される前に検証されました。テーマは以下の通りです：**エージェントが消費するものは、構造上、正確で、新鮮で、発見可能です。**

## コンパイルされたコンテキストが敗者の引用をやめる

`compile_context` は、デフォルトで置き換えられたノードと仲裁敗者を除外するようになりました（`include_superseded=True` でそれらを復元します）。LLM 仲裁に負けたクレームは、以前は勝者と同じように引用されていました。共有された `superseded_ids()` ヘルパーは、`search_nodes`、`fresh_insights`、`node_context` 全体でこれらを一貫して抑制またはフラグするようになりました。合成ページはさらに、すべての引用を実際の入力ノード ID に対して検証します。作成されたいかなる ID も検証に失敗し、決定論的本体にフォールバックします。

## 両面の公開ゲート

Lint はすべてのコンパイルの最後で **クラッシュセーフ** に実行されるため、`lint-report.md` は常に新鮮です。`tesserae compile --strict` は結果をゼロ以外の終了コードに変えます。また、lint 自体がクラッシュする場合は **閉じている** 状態で失敗します。オプトインの `lint --verify-claims` はさらに先に進みます：LLM は、引用されたノードが実際に引用文をサポートしているかどうかを確認します（キャップされ、決定論的にサンプリングされ、コンパイルブロッカーではありません）。

## 出力スナップショットゲート

各コンパイル後、Tesserae はコンパイルされたアーティファクトをハッシュし、`Output: changed/unchanged` を報告します。`--strict` では、*疑わしい* 状態（入力は変わらないが出力は変わった）がビルドを失敗させます：これはバイト-べき等性クラスのバグの永続的なトリップワイヤーです。すぐにコピーできる CI リフレッシュワークフローは `docs/integrations/ci-refresh.md` にあります。

## エージェントが知識ベースを自分で見つける

`tesserae setup` は、マーカー区切り **Tesserae ポインタブロック** をターゲットリポジトリの `AGENTS.md`/`CLAUDE.md` にインストールするようになりました（べき等；不正なマーカーまたは重複したマーカーでは変更されない状態でベイル；他の管理ブロックと共存）。wiki ルートの `index.md` は **エージェントエントリポイント** として書き直されました：オリエンテーション、MCP ファーストの「クエリ方法」セクション、種類テーブル、トップコミュニティです。コミュニティページは、メンバーソースファイルをリストアップする決定論的な `## Sources` フッターを獲得しました。

## コンパイルがより安くなり、陳腐化が見える

コードグラフレイヤーは、**全層抽出キャッシュ** (`.tesserae/code-graph-cache.json`) を保持するようになりました：ソースツリーの stat マニフェストが変更されていない場合、キャッシュされたグラフは全抽出ウォーク（大規模なリポの場合は数十秒）の完全な支払いではなく、バイト同一に再ハイドレートされます。CLI は `reused` または `+added ~changed -removed` デルタカウントを報告します。ビルド履歴はコンパイル時の git HEAD を記録し、lint は lint は、ソースファイルが変更されたコードグラフノードに対して情報結果を発行します。さらに `contradictions.md` wiki ページはオープン/解決/廃止されたクレーム矛盾を追跡し、`graph_ppr` は Memex スタイルの予期しない接続発見のために `exclude_direct_neighbors` を獲得しました。

コミュニティサマリーキャッシュも、メンバー *コンテンツ* ダイジェスト（メンバーシップだけではなく）で無効化されるため、変更されたタイトルは永遠に陳腐なナレーティブを提供する代わりに再要約されます。

## アップグレード注記

- アップグレード後の最初のコンパイルは `Output: changed` を一度報告します（コミュニティページは Sources セクションを獲得し、`index.md` はエントリポイントになります）。その後のコンパイルはバイト安定です。
- `tesserae setup`（`--yes` を含む）はデフォルトでエージェントポインタをインストールします。プランで `install_agent_pointer=false` を設定してオプトアウトしてください。
