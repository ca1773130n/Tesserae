Fecha de publicación **2026-06-10** · [PyPI](https://pypi.org/project/tesserae/0.7.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.7.1) · `pip install --upgrade tesserae==0.7.1`

`tesserae ingest <file|url>` es un nuevo comando de nivel superior que fusiona un **único** documento o URL en tu base de conocimiento — sin volver a extraer todo el corpus — y a la vez se mantiene **idéntico byte a byte** a una compilación completa. Suelta un archivo, o apúntalo a una página web, y tu grafo se actualiza de forma incremental en lugar de pagar el coste de una recompilación completa cada vez.

## 1. `tesserae ingest <input>...` — ingesta incremental de una sola fuente

El nuevo comando toma una o más entradas — rutas de archivos locales o URLs `http(s)` — y pliega cada una en la base de conocimiento existente por separado. Es distinto de `tesserae code ingest`: esto es ingesta de documento/fuente en el grafo principal, no indexación de código.

Por defecto, `ingest` ejecuta una **vía rápida incremental** que solo toca la fuente nueva. La vía rápida está *protegida por paridad*: se verifica que es idéntica byte a byte a una compilación completa, y si no se puede garantizar la paridad, recurre automáticamente a una recompilación completa, de modo que la corrección nunca corre riesgo. Pasa `--exact` para forzar tú mismo la recompilación completa.

Flags: `--exact`, `--dry-run`, `--title`, `--source-kind`.

## 2. Las URLs se descargan, se convierten y se rastrean con procedencia

Dale a `ingest` una URL `http(s)` y descarga la página, la convierte a markdown y la persiste como una fuente rastreada bajo `data/ingested/<slug>.md` con front-matter de procedencia: `source_url`, `fetched_at`, `content_sha256` y `arxiv_id` cuando se detecta que la fuente es un artículo de arXiv.

La ingesta de URLs se entrega tras un nuevo extra opcional para que la instalación base se mantenga ligera:

```
pip install tesserae[ingest-url]
```

## 3. Los archivos locales fuera del corpus pasan a formar parte del corpus

Cuando ingieres un archivo local que vive fuera del corpus rastreado, `ingest` lo copia dentro del corpus. De ese modo, una posterior `tesserae compile` completa reproduce exactamente el mismo resultado — la ingesta incremental y una compilación desde cero convergen en bytes idénticos.

## 4. Por dentro: una costura (seam) incremental que preserva la paridad

La vía rápida incremental se apoya en una costura `incremental_override` por invocación dentro de la canalización de compilación. Es **inerte por defecto** — cuando nada la anula, el motor se comporta exactamente como antes y se preserva la paridad de la compilación completa. Una prueba de paridad de referencia protege la funcionalidad, afirmando que una ingesta incremental y una compilación completa producen una salida idéntica byte a byte.

## Endurecimiento

El front-matter de procedencia ahora se escribe a través de una vía segura para YAML, cerrando la inyección de valores en el front-matter (un título o URL manipulado ya no puede escapar del bloque de front-matter).

## Actualizar desde v0.7.0

Reemplazo directo. `tesserae ingest <file>` funciona de inmediato para archivos locales. Para ingerir URLs, instala el extra con `pip install tesserae[ingest-url]`. El comportamiento existente de `tesserae compile` / `refresh` no cambia — la costura incremental permanece inerte a menos que `ingest` la impulse.
