发布于 **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.1) · `pip install --upgrade tesserae==0.10.1`

一个错误修复版本。可直接替换 v0.10.0。

## 修复

- **`tesserae config status` 现在显示整个机器级配置，而不仅仅是 LLM 后端。** 它报告了已解析的提供者/努力级别，但隐藏了 `tesserae config setup` 管理的其他所有内容，因此 cognee 启用和可选依赖项状态是不可见的。`status` 现在添加了**机器级设置**部分（cognee 打开/关闭 + 模式）和**可选依赖项**部分（memex / cognee / raganything / understand-anything — 已安装或未安装），在启动活跃度 ping 之前打印，以便始终显示。

## 本版本中的其他内容

- **cognee** 适配器已移植到 **cognee 1.x**，机器级 cognee 启用（`config setup --enable-cognee`）已推出，因此单个全局设置为每个项目启用 cognify 传递。自捕获会话过滤器已扩展以识别 cognee 1.x 自己的写作助手提示。

## 从 v0.10.0 升级

即插即用。运行 `tesserae config status` 查看更完整的机器级图景。
