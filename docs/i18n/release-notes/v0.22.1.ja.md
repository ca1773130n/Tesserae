Released **2026-07-21** · [PyPI](https://pypi.org/project/tesserae/0.22.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.22.1) · `pip install --upgrade tesserae==0.22.1`

v0.22.0 で出荷されたエージェント組織ツール用の小さなユーザビリティ修正です。

`tesserae agents init` はサブエージェントロールから組織階層を推論しますが、v0.21.0 より前にインポートされたセッションストア（サブエージェント記述子キャプチャが実装された時点）には何もないため、すべてのエージェントがメインの `:default` キーに折りたたまれ、組織は平坦になります。v0.22.0 ではこれが暗黙のうちに発生していたため、結果は機能が何もしなかったように見えました。

これからは `init` が通知するようになり、修正方法も教えてくれます：

```
Note: only main (:default) agents were observed, so the org is flat — no
subagent roles to build a hierarchy from.
If you use subagents, re-import to capture them, then re-run init:
  tesserae sessions discover --import && tesserae agents init --force
```

「レジストリが既に存在している」というメッセージは、古いレジストリが同じ問題の別の半分であるため、同じ再インポートパスを指すようになりました。両方ともは `--flat`（明示的な選択）の場合と、実際の階層が存在する場合は抑制されます。

推論自体の動作に変更はありません。`pip install --upgrade tesserae==0.22.1`（または `npm i -g @jokerized/tesserae@0.22.1`）。
