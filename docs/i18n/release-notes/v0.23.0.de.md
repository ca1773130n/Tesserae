Veröffentlicht **2026-07-22** · [PyPI](https://pypi.org/project/tesserae/0.23.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.23.0) · `pip install --upgrade tesserae==0.23.0`

Das gestaffelte Agenten-Memory (v0.21) konnte destillieren, aber nur auf Anfrage — bei `tesserae refresh` unter Speicherdruck. Diese Version gibt der Always-On-Engine einen **Schlaf-Zyklus**: Sie konsolidiert Agenten-Memory selbstständig, genau wie ein Gehirn während der Ruhe konsolidiert.

## Konsolidierung während der Ruhe

Lassen Sie `tesserae engine` laufen und es beobachtet jetzt eine Aktivitätsuhr. Wenn ein Projekt **untätig** wird — keine Änderungen oder neuen Sessions für einige Minuten — führt es den Destillationspass über alle Agenten dieses Projekts aus und reorganisiert sowie komprimiert deren gesammelte Erfahrung während Sie weg sind. Eine periodische **Obergrenze** (Standard 6h) garantiert, dass auch ein kontinuierlich beschäftigtes Projekt noch konsolidiert wird.

```bash
tesserae engine                      # idle consolidation on by default
tesserae engine --consolidate-idle 600 --consolidate-every 43200
tesserae engine --all                # every registered project, on idle
tesserae engine --no-consolidate     # opt out
```

Untätigkeit ist der hirngerechte Auslöser: Konsolidierung geschieht, wenn das System in Ruhe ist, nicht zu einer beliebigen Uhrzeit.

## Sicher durch Konstruktion

Der Zyklus umhüllt exakt den bestehenden `maybe_distill_on_refresh`-Pass, sodass alle seine Garantien übertragen werden:

- **Ein No-Op, wenn Sie nicht aktiviert haben.** Nichts läuft, bis `TESSERAE_AGENT_DISTILL=1` — das gleiche Gate, das die Destillation immer verwendet hat, plus die Pro-Agent-Wasserlinie und Speicherdruck-Checks. Die Flaggen sind standardmäßig aktiviert, weil der Pass selbst sich weigert, ohne Opt-In etwas zu tun.
- **Überlappt sich niemals mit einer Recompile.** Konsolidierung läuft unter dem Compile-Gate, daher sind diese und die Pipeline sich gegenseitig ausschließend — und um das im Single-Daemon-Modus zu halten, setzt sich ein ungesetztes Gate jetzt auf einen privaten Semaphor.
- **Stört den Daemon niemals.** Es läuft in seinem eigenen Thread (das bestehende Poller-Idiom des Daemon), wird nie in die Event-Loop gehoben, wird beim Herunterfahren prompt beendet und wird komplett für One-Shot-`engine`-Läufe übersprungen.
- **Deterministische Artefakte, unberührt.** Die destillierten Graphen behalten ihre Byte-Idempotenz; die monotone Aktivitätsuhr wird niemals persistiert.

## Flaggen

| Flagge | Standard | Bedeutung |
|---|---|---|
| `--consolidate` / `--no-consolidate` | an | Schlaf-Zyklus aktivieren |
| `--consolidate-idle` | `300` | Sekunden der Stille vor der Konsolidierung |
| `--consolidate-every` | `21600` | Obergrenze — konsolidieren Sie mindestens so oft (`0` = aus) |
| `--consolidate-check` | `30` | wie oft der Thread die Uhr überprüft |
