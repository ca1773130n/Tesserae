リリース **2026-08-24** · [PyPI](https://pypi.org/project/tesserae/0.33.1/) · [GitHub リリース](https://github.com/ca1773130n/Tesserae/releases/tag/v0.33.1) · `pip install --upgrade tesserae==0.33.1`

回答プロンプトと、それを見張っているはずだった対照群についてのパッチリリースです。どちらも、自ら主張していたものとは別のものを測っていました。

## ランク付けされた文書はすべて二度貼り付けられていました

`_build_synthesis_message` は一つのコーパスの上で二つのレーンを走らせます。文書レーンは、文書を索引する単位ディレクトリを基準に、自分が出力したものを記録していました — 論文一件は `abstract.md` と `paper.md` であり、それらを収めるディレクトリをキーとします。ところがヒットレーンは*ファイル*パスがその集合にあるかを尋ねていました。ファイルパスが親ディレクトリと等しくなることは決してないため、このガードは何も捕まえず、融合レーンがすでに貼り付けた文書はすべて、そのまま二度目も貼り付けられていました。

デモコーパスでの計測では、この重複は**関係不在プロンプトの 15.6%** を占めていました — プランナーの回答ごとの入力トークン請求の 6 分の 1 が、モデルがすでに見せられたテキストを再び見せるために使われていたことになります。現在は `_unit_of` が両レーンに単一のキー空間を与え、読む決定ではなく実際の出力が、その単位を出力済みとして印を付けます。

## ブロックは質問と希少な語を共有する場合にのみ通されます

合成プロンプトは、ハイブリッドのベースラインのプロンプトに、より弱い第二のレーンを重ねたものでした。追加ブロックは中央値で約 8 件、証拠文字数の 30.7% を占めます。その見返りに正解カバレッジは 0.303 に対して 0.388 になりましたが、棄権の対照群における捏造は **38.2% に対して 52.9%** になりました。かすっただけの材料が増えれば、同一の仕組みで両方が同時に上がります。

順位では、追加レーンの有用なブロックとかすっただけのブロックを分けられません。順位による判別力は AUC 0.474 と測定され、これは偶然と同じ水準です。希少性なら分けられます。コーパスの 5% 以下にしか現れない質問語は、ブロックを*その*質問に繋ぎ止めます。融合上位 10 件と `kg:` ブロックは今も無条件で通るため、拮抗するトークン F1 を出していた系統はバイト単位で変わっていません — 352 件のデモ質問すべてで検証し、変化した文書ブロックは 0 件、kg ブロックも 0 件でした。

## プロトコルゲートは真実を却下し、虚構を受け入れていました

公開ベンチマークとの比較が鍵一つで済むのかと問うたところ、引用できない主張を止めるために存在するゲートが、フラグを打ち込むだけで満たせてしまいました。手書きの `answers.json` が四つの対照すべてを満たすと宣言すると阻止理由はゼロになり、実際の OpenAI エンベッダーに対する正直な実行は**失敗しました**。バックエンドが自らを `openai:text-embedding-3-small` と名乗る一方、プロトコルは素のモデル名を保持していたからです。

宣言は今や証拠を要する主張であり、`answer_calls` と `judge_calls` を記録します。実行は自分が何をしたかを記録できますが、手書きのファイルにはそれができないからです。そして判定の対照群は、意図的に、そして目に見える形で、どの実行によっても満たせないものになりました。このリポジトリには判定の実装がどこにも存在しないため、ゲートはフラグの既定値に実体の代役をさせるのではなく、そう述べます。

## 対応のあるシステムには対応のある検定を

同じ質問群で採点された二つのシステムは対応のあるデータであり、周辺比率を比べることはその対応を捨てることです。捏造の問いではこれが決定的でした。6/48 対 2/48 は Fisher の **p = 0.268** であり、プローブ集合を大きくしても解決しません。周辺検定では、二つのシステムが同じ質問で失敗したのか別々の質問で失敗したのかが見えないからです。

`mcnemar` は不一致ペアを条件とし、カイ二乗ではなく正確二項両側検定を用います。このベンチマークが生む度数は一桁だからです。`n_discordant` を返すのは意図的です — 標本サイズは総数ではなくこの値です。

## コーパスなしの規則には勝てない対照群

元の 48 件の棄権対照群は、棄権を測っていませんでした。実データ集合の 57 語に対して 31 語だったため、「40 トークン未満なら何でも拒否する」という — コーパスに一切触れない — 規則が、幻覚 2.1%、過剰拒否 4.6% を記録し、本物の知識信号のすべてに勝ってしまいました。今日までに報告された幻覚の数値はすべて、その集合から出たものです。

これらは 68 件の対照群に置き換えられ、長さを揃えて作成したうえで、そのまま受け入れるのではなく攻撃を加えました。新しい集合では、かつての抜け道は同じ過剰拒否率で幻覚 **100%** を記録し、語数だけによる AUC は 0.988 から 0.456 へ落ちます。
