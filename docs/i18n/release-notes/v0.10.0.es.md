Lanzado **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.0) · `pip install --upgrade tesserae==0.10.0`

Una versión de características: intercambio de conocimiento, búsqueda de sesión más rápida, y configuración de una sola vez en toda la máquina. Todo es aditivo — un simple `tesserae compile` no cambia, y la configuración por proyecto sigue anulando los nuevos valores por defecto globales.

## 1. Importación/exportación de Google OKF v0.1

`tesserae export okf` escribe el gráfico como un paquete de [Google **Open Knowledge Format** v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog) — un árbol de archivos Markdown con frontmatter YAML y relaciones con enlaces relativos. `--import DIR` lee uno de vuelta. Los propios paquetes de Tesserae hacen round-trip **sin pérdida** vía un namespace de frontmatter `x_tesserae` (ids de nodo reales + aristas tipificadas + metadatos de aristas); los paquetes externos se importan según el mejor esfuerzo (tipo desconocido → `Concept`, enlaces sin tipo → `references`), tolerando tipos faltantes y archivos rotos/enlazados simbólicamente según la especificación.

## 2. Búsqueda rápida de transcripciones en el panel de sesiones

`tesserae serve` gana un cuadro de búsqueda de texto completo sobre cada transcripción de Claude/Codex indexada en el panel de sesiones, impulsado por [`nicosuave/memex`](https://github.com/nicosuave/memex) (BM25). Es opcional y con degradación elegante: sin el binario `memex` el cuadro muestra un mensaje procesable y el resto del panel no se ve afectado. El endpoint `GET /api/transcript-search` se limita a llamadas del mismo origen/loopback para que una página web visitada no pueda sondear el historial local, y los resultados se renderean vía `textContent` (sin inyección de marcado).

## 3. Disciplina de lectura estilo memex para MCP

Inspirado en el "bloc de notas programable" de Databricks, `compile_context` ahora acepta `preview=N`: en lugar de volcar un cuerpo enorme en el contexto del agente, devuelve una vista previa acotada más un **handle** con clave de contenido, y la nueva herramienta **`get_handle`** pagina el resto bajo demanda. El `preview=0` por defecto mantiene el comportamiento de cuerpo completo.

## 4. Señales de calidad de extracción

Los hallazgos de sesión ahora llevan `confidence` + `confidence_rationale` + `revisit_signals` destilados del extractor (ideas de Jonasb8/memex; sin código copiado). Van en el caché de extracción con clave de contenido, por lo que permanecen byte-idempotentes, y se muestran en la herramienta MCP `fresh_insights` como banderas (nunca garantías de verdad).

## 5. Configuración en toda la máquina + instalaciones de dependencias

`tesserae config setup` establece valores por defecto de LLM para **todos** los proyectos (`--llm-provider`, `--reasoning-effort`, `--codex-home`, `--claude-config-dir`) **e** instala dependencias opcionales (`--install all`) en un solo paso. `tesserae config deps` lista/instala **memex**, **cognee**, **raganything**, y **understand-anything**; `tesserae config llm` ganó `--reasoning-effort`; e `tesserae init` ofrece instalar memex durante una configuración interactiva. Orden de resolución: env → configuración del proyecto → configuración en toda la máquina → incorporada.

## Actualización desde v0.9.x

Drop-in. Ejecuta `tesserae config setup` para configurar los valores por defecto en toda la máquina una vez, o mantén tu `.tesserae/config.json` por proyecto — sigue ganando.
