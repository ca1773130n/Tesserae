Released **2026-06-20** · [PyPI](https://pypi.org/project/tesserae/0.10.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.10.0) · `pip install --upgrade tesserae==0.10.0`

機能リリース: ナレッジ交換、より高速なセッション検索、ワンショット マシン規模セットアップ。すべての機能は追加型です — プレーン `tesserae compile` は変わりません、そしてプロジェクト単位の設定は新しいグローバルデフォルトをオーバーライドし続けます。

## 1. Google OKF v0.1 インポート/エクスポート

`tesserae export okf` はグラフを [Google **Open Knowledge Format**
v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog) バンドル — YAML フロントマターを持つマークダウンファイルツリーと相対リンク関係として出力します。`--import
DIR` は逆方向に読み込みます。Tesserae 独自のバンドルは `x_tesserae` フロントマター名前空間を経由して **無損失** にラウンドトリップします (実際のノード id + 型付きエッジ + エッジメタデータ)；外部バンドルは最善努力でインポートします (未知の `type` → `Concept`, 型なしリンク → `references`)、仕様ごとに欠落した型と破損/シンボリックリンク済みファイルを許容します。

## 2. セッションダッシュボード上の高速トランスクリプト検索

`tesserae serve` のセッションダッシュボードはすべてのインデックス済み Claude/Codex トランスクリプト上の全文検索ボックスを獲得します、[`nicosuave/memex`](https://github.com/nicosuave/memex) (BM25) によって駆動されます。これはオプションで優雅です: `memex` バイナリなしでは、ボックスは実行可能なメッセージを表示し、ダッシュボードの残りは影響を受けません。`GET /api/transcript-search` エンドポイントは同一オリジン/ループバック呼び出し元にゲートされるため、訪問したウェブページはローカル履歴をプローブできず、結果は `textContent` 経由でレンダリングされます (マークアップインジェクションなし)。

## 3. MCP 用 memex スタイルの読み規律

Databricks の「プログラム可能スクラッチパッド」にインスパイアされた、`compile_context` は `preview=N` を受け入れるようになりました: 巨大な本体をエージェントのコンテキストにダンプする代わりに、それは有界プレビュー + コンテンツキー付き **ハンドル** を返し、新しい **`get_handle`** ツールはオンデマンドで残りをページングします。デフォルト `preview=0` は完全なボディ動作を保持します。

## 4. 抽出品質シグナル

セッション検出結果は `confidence` + `confidence_rationale` + `revisit_signals` を運ぶようになりました、抽出器から蒸留されます (Jonasb8/memex からのアイデア；コードのコピーなし)。それらはコンテンツキー付き抽出キャッシュに乗りますため、バイト等冪性を保持し、`fresh_insights` MCP ツールでフラグとして表面化します (真実保証ではありません)。

## 5. マシン規模セットアップ + 依存関係インストール

`tesserae config setup` はすべてのプロジェクト用 LLM デフォルトを設定します (`--llm-provider`, `--reasoning-effort`, `--codex-home`, `--claude-config-dir`) **そして** ワンショットでオプション依存関係をインストールします (`--install all`)。`tesserae config deps` は **memex**, **cognee**, **raganything**、**understand-anything** をリスト/インストール; `tesserae config llm` は `--reasoning-effort` を獲得; そして `tesserae init` はインタラクティブセットアップ中に memex インストールを提供します。解決順序: env → プロジェクト設定 → マシン規模設定 → ビルトイン。

## v0.9.x からのアップグレード

ドロップイン。`tesserae config setup` を実行してマシン規模デフォルトを一度設定するか、プロジェクト単位の `.tesserae/config.json` を保持します — それはまだ勝ちます。
