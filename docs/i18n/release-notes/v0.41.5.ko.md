공개일 **2026-09-17** · [PyPI](https://pypi.org/project/tesserae/0.41.5/) · [GitHub 릴리스](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.5) · `pip install --upgrade tesserae==0.41.5`

주장 71,783개로 된 그래프에서 야간 모순 검사가 멈췄습니다. 모순 탐지가 모든 주장 쌍을 비교하면서
쌍마다 두 텍스트를 다시 만들었고, 끝나지 않았습니다. 정답은 쌍이 하나도 없는 것이었습니다.
`CONTRADICTING_CLAIMS` lint 검사에도 같은 루프가 있었습니다.

## 무엇이 바뀌었나

- **모순 탐지가 서로 모순될 수 있는 주장끼리만 비교합니다.** 모순이 되려면 "outperforms"라고
  말하는 주장과 "is outperformed by"라고 말하는 주장이 하나씩 필요합니다. 이제 주장을 둘 중 무엇을
  말하는지에 따라 나누고, 양쪽에서 하나씩 뽑은 쌍만 비교합니다. 한쪽이 비어 있으면 아무것도 비교하지
  않습니다. 그 그래프와 같은 모양의 합성 주장은 이제 0.042초가 걸립니다.
- **`lint`도 같은 수정을 받았습니다.** `CONTRADICTING_CLAIMS` 검사가 똑같이 모든 쌍을 도는
  루프였습니다.
- **결과는 바뀌지 않았습니다.** 두 함수 모두 이전과 정확히 같은 결과를 돌려주며, 수천 개의
  무작위 그래프에서 이전 코드와 대조해 확인했습니다.

## 업그레이드

이전할 것은 없습니다. 한 주제의 양쪽에 주장이 수천 개씩 있는 그래프는 여전히 시간이 걸립니다.
그 쌍 하나하나가 답의 일부이기 때문입니다.
