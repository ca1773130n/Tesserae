Выпущено **2026-07-10** · [PyPI](https://pypi.org/project/tesserae/0.18.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.18.0) · `pip install --upgrade tesserae==0.18.0`

Полная ревизия командной поверхности, движимая одним наблюдением: `tesserae ask "what happened recently?"` раньше возвращал статические концептуальные страницы и честное пожатие плечами. Лейтмотив: **команды теперь делают то, что обещают их имена.**

## `ask` планирует свой поиск — и отвечает по умолчанию

`tesserae ask` больше не нуждается в `--llm`: модель сначала читает ваш вопрос, планирует, какие примитивы графа знаний могут на него ответить (временная шкала, недавние сессии, дайджест активности, темпоральные факты, страницы вики), выполняет этот план и синтезирует ответ с цитатами. Темпоральные вопросы получают датированные доказательства вместо супа из концептуальных страниц. `--no-llm` принудительно включает режим только-поиск; `TESSERAE_QUERY_DRY_RUN` и классический путь BM25 остаются детерминированным запасным вариантом при любом сбое. Сырой поиск — совпадения BM25, семантический поиск и явные бэкенды raganything/cognee — теперь живёт в `tesserae query`.

## Дневные чанки сессий: в 20× быстрее выборка по временному диапазону

Тейлер сессий движка теперь записывает каждый наблюдаемый ход в дневное хранилище чанков (`.tesserae/session_chunks.db`), а `refresh` инкрементально дозаполняет его под блокировкой skip-if-held. Оконные чтения (`summary`, `decisions`, поиск активности в ask, MCP) обслуживают покрытые дни из чанков — измерено 2.3 с против 48.8 с на проекте с 45k узлов — с гарантированным по паритету запасным вариантом сырого сканирования, поэтому отсутствующая или повреждённая база чанков никогда не может изменить результаты, только скорость. `tesserae sessions chunk-backfill [--since]` строит историю по требованию.

## `tesserae doctor`

Двадцать проверок здоровья примерно за две секунды: init/граф/разбор конфига, согласованность реестра, устаревание, живые блокировки, состояние логина, гигиена. `--fix` применяет только доказуемо безопасные исправления (устаревшие pid-файлы, разросшиеся логи хуков, чистка реестра, пересборки сайта) и никогда не трогает живую блокировку компиляции. Отчёты сохраняются в `.tesserae/doctor-report.{md,json}` и отдаются через MCP как `doctor_report`.

## `init` — это вся установка

`tesserae init` обнаруживает LLM CLI на вашей машине, проверяет, что они действительно залогинены, и позволяет выбрать — включая **кастомную claude-совместимую конечную точку** (`--llm-provider custom --llm-base-url … --llm-api-key … --llm-model …`). Ключи разрешаются в порядке env → проект → глобальный (`ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL`, `TESSERAE_LLM_MODEL`); ключ, сохранённый открытым текстом, предупреждает один раз. Повторный init сливает вашу конфигурацию вместо её затирания.

## Более компактные бэкенды, честные флаги

cognee теперь выключен по умолчанию, приглушён при использовании, устанавливается как `tesserae[cognee]`, а режим `codex_cognify` удалён (−556 LOC). understand-anything больше не подключается автоматически при наличии артефактов. А состязательный проход по всем 26 командам переименовал или удалил каждый лгущий флаг — `summary --project`→`--name` (со строгой валидацией имени), `context --synthesize`→`--llm`, `refresh --skip-sessions`→`--no-sessions`, `vault --poll-interval`→`--interval`, `ingest --exact`→`--full`, мёртвые флаги удалены — каждое старое написание печатает однострочный указатель на новое и выходит с кодом 2. Попутно едут исправления поведения: пустой `sessions import` больше не может стереть хранилище, `ingest --dry-run` действительно сухой, `serve --dry-run` выполняется до сборок, а сервер MCP наконец сообщает свою настоящую версию.

## Ломающие изменения

Каждый удалённый или переименованный флаг/команда печатает свою замену и выходит с кодом 2 — ничто не падает молча. Полная таблица: `ask --llm|--wiki|--backend|--cognee-*`, `query --llm|--no-llm|--model`, `summary|decisions --project`, `context --synthesize`, `refresh --skip-sessions`, `vault sync --poll-interval`, `vault export --vault`, `ingest --exact`, `research --no-web`, `compile --claude-timeout`, `config setup`, `wiki|projects activate`.
