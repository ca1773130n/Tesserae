リリース **2026-06-30** · [PyPI](https://pypi.org/project/tesserae/0.13.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.13.0) · `pip install --upgrade tesserae==0.13.0`

Tesseraeは LLM wikiです。`compile`は構造的なスケルトンだけでなく、デフォルトで**コンセプト/クレイムレイヤー**を構築するようになりました。

## `compile`がコンセプトレイヤーをデフォルトで構築

以前は、`tesserae compile`はデフォルトで**決定的な**エクストラクタを実行していました。高速でバイト安定でしたが、構造的なもののみ — ソース、セクション、明示的なリンク、そしてスパースなコンセプトレイヤーです。より豊かなレイヤー(コンセプト、クレイム、機能、技術用語、証拠スパン、およびそれらの間の型付きエッジ)は、オプトイン、Claude限定の`--extractor claude-cli`フラグの背後に隠されていました。LLM wikiとしては、これは逆でした。

現在は:

- **`--extractor llm`がデフォルトです。** `tesserae compile`は、**設定されたプロバイダー** — codex / claude / Anthropic API、`llm_provider`に従って — セッション抽出がすでに使用しているのと同じ`LLMJsonClient`を使用して各ドキュメントを読み込みます。もう Claude限定のパスはありません。
- **`deterministic`は明示的なオプトアウトです** — `tesserae compile --extractor deterministic`で高速、キーフリー、バイト安定モード(CI / 再現可能なビルド)です。バイト等価性は変わっていません。これは常にこのモードの特性でした。
- **デフォルトのタイムアウトはありません。** 古い`--claude-timeout=180`は大きな設計ドキュメントを静かに劣化したフォールバックに切り詰めていました。抽出は完了まで実行されるようになりました。タイムアウトはオプトインのみです。
- **プロバイダーニュートラルフラグ:** `--llm-provider`、`--llm-model`、`--llm-include`、`--llm-limit`。(`claude-cli` / `selective-claude`および`--claude-*`フラグは非推奨エイリアスとしてまだ機能します。)
- **ロバスト + 優雅。** バックエンドが設定されていない場合は、失敗ではなく警告と共に決定的に劣化します。1つのドキュメント上のバックエンドエラーは、コンパイル全体を中止する代わりにそのドキュメント用に決定的にフォールバックされ、コンテンツキーのキャッシュは変更されていないドキュメントの再コンパイルが以前の抽出を再利用することを意味します。

```bash
tesserae compile                        # LLMコンセプトレイヤー、設定されたプロバイダー
tesserae compile --extractor deterministic   # 構造的 / バイト安定 / キーフリー
tesserae compile --extractor selective-llm \
  --llm-include "docs/**/*.md" --llm-limit 20   # コスト意識的
```

## より速いフェデレーテッド`ask`

フェデレーテッド`ask`は、*すべての*クエリでクロスプロジェクトグラフを再組み立てしていました(読み込み + 解析 + 名前空間 + すべてのメンバープロジェクトのアイデンティティマージ) — 約4分の1のレイテンシで、同じプロジェクトセットに対する会話の各フォローアップで再実行されます。アセンブルされたグラフは、各メンバーのグラフファイル変更シグネチャをキーとしてプロセス内でメモ化されるようになりました。繰り返しクエリはインスタント キャッシュヒットであり、エントリは**任意のメンバープロジェクトが再コンパイルされた瞬間に自己無効化されます**(ディスクキャッシュなし、老化なし)。実際の 6プロジェクト / 22.6k ノード フェデレーションでは、繰り返しクエリごとにスキップされる約0.6秒のアセンブリです。

## v0.12.xからのアップグレード

唯一の動作変更は、`tesserae compile`がデフォルトで LLM抽出を実行するようになったことです。古い構造のみの動作が必要な場合(例えば CI での、またはLLMバックエンドなし)、`--extractor deterministic`を渡してください — 設定されたプロバイダーがないマシンでは、コンパイルはすでに自動的にそれにフォールバックされます。
