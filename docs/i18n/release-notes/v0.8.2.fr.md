Released **2026-06-13** · [PyPI](https://pypi.org/project/tesserae/0.8.2/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.8.2) · `pip install --upgrade tesserae==0.8.2`

Version mineure qui ajoute un accès via navigateur à la base de connaissances. Le pilier « ingestion autonome et proactive de connaissances » est maintenant accessible en un clic depuis n'importe quelle page web — et la même ingestion est exposée aux agents via MCP.

## 1. Point de terminaison d'ingestion Web Clip (`POST /api/clip`)

`tesserae serve` gagne une route JSON qui transforme une page découpée en nœuds de graphe typés. Elle écrit un `data/ingested/<slug>.md` estampillé avec la provenance (front-matter contenant `url`/`title`/`tags`/`note`/`clipped_at`, un `## TL;DR` optionnel, votre `## Note`, et le `## Content`), puis exécute le même chemin `ingest_sources` incrémental que l'interface de ligne de commande utilise. Le TL;DR est de meilleur effort via la couche Claude soutenue par l'interface de ligne de commande (aucune clé API) ; un résumeur manquant ou défaillant n'interfère jamais avec le clip. La réponse rapporte `{status, path, tldr, node_count, edge_count}`.

## 2. Outil MCP `ingest`

Le même noyau d'ingestion est maintenant un outil MCP, afin qu'un agent puisse ingérer le contenu qu'il a trouvé — aucun navigateur requis. Entrées : `content` (obligatoire), `url`, `title`, `note`, `tags`, `tldr` (activé par défaut). Il ingère dans le projet actif et retourne le même rapport que `/api/clip`.

## 3. Extension Chrome (Web Clipper)

Une extension Manifest V3 se trouve dans `extension/` (charger-décompressé ; une liste de Chrome Web Store est en cours d'examen). Elle capture le contenu lisible d'une page — ou simplement votre sélection — avec une note optionnelle et des balises et un bouton de basculement TL;DR par clip, puis POST vers votre `tesserae serve` local. Raccourci par défaut `Ctrl+Shift+S` (macOS `Cmd+Shift+S`). Voir [docs/integrations/chrome-extension.md](../integrations/chrome-extension.md).

## 4. Le point de terminaison du clip est renforcé par défaut

Parce qu'un navigateur parle maintenant à `localhost`, `/api/clip` est verrouillé :

- **CORS vérifié par origine.** Seules les origines d'extension de navigateur (`chrome-extension://…`) et de bouclage local sont reflétées ; une origine d'un site web étranger est rejetée avec `403` avant tout travail — donc une page que vous visitez par hasard ne peut pas envoyer de POST dans votre graphe.
- **Accès au réseau privé.** La pré-demande répond avec `Access-Control-Allow-Private-Network: true`, afin qu'une extension de Web Store puisse atteindre `localhost` sous Chrome actuel.
- **Limite de corps.** Les requêtes sont limitées (5 MB) avant d'être lues en mémoire.

## Mise à niveau depuis v0.8.1

Tout inclus. Pour utiliser le clipper, mettez à niveau afin que `tesserae serve` expose `/api/clip`, puis exécutez `tesserae serve` et chargez l'extension. Aucune modification du graphe ou de la configuration n'est requise.
