Новый механизм **сводки активности**: попросите Tesserae рассказать, что произошло в день или за неделю, и он восстановит ответ из вашей реальной работы — каждой сессии агента, коммита, PR и проглоченного документа — во всех ваших AI-агентских аккаунтах.

## `tesserae summary`

```bash
tesserae summary --day 2026-07-05
tesserae summary --week
tesserae summary --day 2026-07-05 --project agented   # scoping к одному проекту
```

Также доступно как инструмент MCP **`activity_summary`** (чтобы агент мог получить дайджест в качестве контекста) и команда слэша **`/summary`**.

### Что это делает

- **Читает каждый AI-аккаунт напрямую.** Он сканирует корни конфигурации harness — `~/.claude*`, `~/.codex*`, worktrees и всё остальное — для запрошенного окна, вместо того, чтобы доверять фоновому индексу, который может отстать. День затрагивает только несколько транскриптов, поэтому полное сканирование кроссаккаунтов остаётся быстрым.
- **Окна на собственной временной метке каждого хода**, в **KST**, никогда не на старте долгоживущей сессии — поэтому многодневная сессия вносит вклад только в ходы, которые действительно попадают в день.
- **Собирает весь день:** сообщения агента, коммиты git, GitHub PR (открыты / слиты / закрыты) и проглоченные документы — каждый в окне собственного времени.
- **Суммирует беседы, не просто подсчитывает.** Выход — структурированное, ежепроектное повествование — **Отправлено / Исправлено / Решения & Идеи / В процессе / Документы / Наблюдение** — плюс однострочная сводка того, что **каждая сессия** действительно сделала. Детерминированный, проверяемый дайджест фактов находится ниже.
- **Еженедельно** объединяет семь дней в одно повествование.

Сводки записываются в `.tesserae/summaries/<project>/daily-YYYY-MM-DD.md`.

## Цитирования отображают имена, а не `node-<hash>`

Приведённые доказательства в `ask`, `compile_context` и синтезе wiki предыдущей версии протекали необработанные идентификаторы узлов (`node-<hash>`) как маркеры цитирования. Теперь они разрешаются на фактический заголовок объекта, поэтому ответы разборчивы.

## Обновление

Простое обновление поверх v0.13.x. Новая команда является дополнительной; ничего больше не изменяется. `tesserae summary` читает ваши существующие сессии на лету — миграция или перекомпиляция не требуются.
