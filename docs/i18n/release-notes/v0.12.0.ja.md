リリース **2026-06-29** · [PyPI](https://pypi.org/project/tesserae/0.12.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.12.0) · `pip install --upgrade tesserae==0.12.0`

「アクティブプロジェクト」の概念はもはや存在しません。すべての登録済みプロジェクトが同時にライブになります — `ask` はプロジェクト間でルーティングされ、`serve` はすべてのプロジェクトを1つのサイト下で提供し、`compile` は決定論的抽出器が省略する LLM コンセプト層を構築できるようになりました。

## アクティブプロジェクトなし — スマートな `ask` ルーター

「アクティブプロジェクト」という概念は廃止されました：`tesserae projects activate` と `activate_project` MCP ツールが削除され、すべてのプロジェクト単位のコマンドは、現在のディレクトリから プロジェクトを解決します。すべての登録済みプロジェクトは対等です。

裸の `tesserae ask` は現在、自動的に **ルーティング** されます：

- プロジェクト名を指定 → そのプロジェクト；
- 比較的なものまたは一般的なもの → **フェデレーション** （マージされた、相互参照される、統合に対する回答）；
- フォローアップ（「そしてなぜ？」）は前のルートを保ちます；トピック変更（「*他の* ものはどう？」）は再ルーティングします。

明確なケースは無料で解決されます；オプションの LLM タイブレーカーは本当に曖昧な中間を処理し、短い会話ごとの履歴は複数質問のスレッドを一貫性を保つのに役立てます。明示的な `--scope current|all-registered|federated` はまだ機能します。

## すべてのプロジェクト用の1つのサーバー — `tesserae serve`

裸の `tesserae serve` は現在、単一のサーバーの下で **すべての登録済みプロジェクト** を提供します：`/` でのプロジェクトランディング、各プロジェクトは `/<alias>/`、ヘッダーのプロジェクトスイッチャー、およびプロジェクト単位のセッションビュー。ページ内の ask ウィジェットはライブで動作し、質問したページのプロジェクトにルーティングされます。`tesserae serve --project X` は引き続き単一プロジェクトを提供します。リクエストはパス含有です（プロジェクトのサイトディレクトリをエスケープできません）し、ask エンドポイントは同一オリジンゲート化され、リクエストサイズキャップがあります。

## `compile` でコンセプト層を構築 — `--extractor`

`tesserae compile --extractor claude-cli` （または `--extractor selective-claude --claude-include "<glob>" --claude-limit N`）は、決定論的なデフォルトが疎のままにするコンセプト/クレーム層を構築します — コンセプト、クレーム、機能、エビデンス スパン、型付きエッジ。実際のコーパスに対して強化されています。1つのノイズのあるか遅いドキュメントが以前は全体のコンパイルを中止していました：

- 制御された語彙の外側のエッジタイプは **ドロップ** され、致命的ではありません；
- ドキュメントが文書ごとのタイムアウトを超える場合、そのファイルの決定論的抽出に **フォールバック** します；
- 一過的な無効な生成は **再試行** されます（モデルは非決定論的なので、再呼び出しはほぼ常に検証します）。

## このリリースの他の内容

- **Cognee 1.0 互換性** — Cognee 1.0 は Tesserae がデフォルトとしていた `INSIGHTS` 検索タイプを削除し、これは cognee `ask` バックエンドを黙然と破断しました。これで `GRAPH_COMPLETION` （知識グラフ上の回答）にマップされるため、cognee は再び機能します；生のレトリーバルのために `--cognee-search-type CHUNKS` を渡します。
- **`tesserae setup`** — トップレベルのインタラクティブな機械全体のセットアップ（LLM プロバイダー/努力 + インストールするオプション依存関係）；フラグはプロンプトをスキップし、インストールは pip-less `uv tool` 環境で機能します。
- **ドキュメント** — README、クイックスタート、インストール、MCP ガイド、機能マップ、および統合ガイドは上記のために更新されました（もはや「アクティブプロジェクト」なし）。

## v0.11.x からのアップグレード

ほとんどドロップイン。**破断：** `tesserae projects activate` と `activate_project` MCP ツールが削除されました — プロジェクト単位のコマンドは現在のディレクトリで解決され、`ask` はプロジェクト全体を自動的にルーティングします。`projects activate` をスクリプト化した場合は、削除してください。シングルプロジェクト使用は変更されていません。
