新的**活动摘要**引擎：向 Tesserae 询问某一天或一周内发生了什么，它会从你的实际工作中重建答案 — 所有代理会话、提交、PR 和摄入的文档 — 跨越你的所有 AI 代理账户。

## `tesserae summary`

```bash
tesserae summary --day 2026-07-05
tesserae summary --week
tesserae summary --day 2026-07-05 --project agented   # scope to one project
```

也可作为**`activity_summary`** MCP 工具（这样代理可以作为上下文拉取摘要）和**`/summary`** 斜杠命令使用。

### 它的功能

- **直接读取每个 AI 账户。** 它扫描你的硬件配置根目录 — `~/.claude*`、`~/.codex*`、worktree 及其所有内容 — 查找请求的时间窗口，而不是依赖可能滞后的后台索引。一天只涉及少量记录，因此完整的跨账户扫描保持快速。
- **窗口基于每个轮次自身的时间戳**（**KST**），而不是长时间运行的会话的开始 — 所以多天会话只贡献实际落在该天内的轮次。
- **收集整个一天：** 代理消息、git 提交、GitHub PR（已打开/已合并/已关闭）和摄入的文档 — 每个都按其自身时间窗口。
- **总结对话，而不仅仅是计数。** 输出是结构化的、按项目的叙述 — **已发布/已修复/决策和见解/进行中/文档/关注** — 加上每个*会话*实际做了什么的一行摘要。确定性、可审计的事实摘要位于其下方。
- **每周**将七天汇总为一个叙述。

摘要写入 `.tesserae/summaries/<project>/daily-YYYY-MM-DD.md`。

## 引用呈现名称，而不是 `node-<hash>`

`ask`、`compile_context` 和 wiki 合成中的引用证据之前泄露原始节点 ID（`node-<hash>`）作为引用标记。它们现在解析为实体的实际标题，所以答案是可读的。

## 升级

直接覆盖 v0.13.x。新命令是添加性的；其他都不改变。`tesserae summary` 即时读取你的现有会话 — 无需迁移或重新编译。
