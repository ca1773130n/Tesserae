Объединяет один файл документа или URL в базу знаний.

## Использование

    tesserae ingest <input>...  [--title T] [--source-kind K] [--exact] [--dry-run]

`<input>` — это один или несколько путей к локальным файлам или `http(s)` URL. URL загружаются,
преобразуются в markdown и сохраняются в `data/ingested/<slug>.md` с front-matter происхождения
(`source_url`, `fetched_at`, `content_sha256`, а также `arxiv_id`, если он обнаружен), после чего
объединяются. Локальные файлы за пределами проекта копируются в `data/ingested/`, чтобы стать
отслеживаемыми источниками (последующая полная компиляция воспроизводит их идентично).

Загрузка по URL требует необязательного дополнения:

    pip install tesserae[ingest-url]

## Как это работает

По умолчанию `ingest` объединяет новый источник с помощью инкрементальной компиляции — он не
извлекает заново весь корпус — и результат побайтово идентичен полной компиляции (автоматический
откат к полной перекомпиляции гарантирует корректность для любого случая, который инкрементальный
путь не может обработать). Передайте `--exact`, чтобы принудительно выполнить полную
перекомпиляцию всего корпуса.

## Флаги

- `--exact` — принудительно выполнить полную перекомпиляцию всего корпуса.
- `--dry-run` — загрузить и сообщить, что было бы загружено; граф не записывается.
- `--title` — переопределение заголовка, полезно для «голых» URL.
- `--source-kind` — переопределить классификацию источника.

## Связанные команды

- `tesserae compile` (без аргументов) заново извлекает весь отслеживаемый корпус.
- `tesserae ingest <x>` добавляет один источник инкрементально.
- `tesserae code ingest` создаёт граф кода из исходного кода Python (это другая команда).
