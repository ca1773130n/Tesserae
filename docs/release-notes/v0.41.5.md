Released **2026-09-17** · [PyPI](https://pypi.org/project/tesserae/0.41.5/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.5) · `pip install --upgrade tesserae==0.41.5`

A nightly contradiction pass froze on a graph of 71,783 claims. Contradiction
detection compared every pair of claims, rebuilding both texts for each pair,
and never finished. The right answer was no pairs at all. The
`CONTRADICTING_CLAIMS` lint check had the same loop.

## What changed

- **Contradiction detection compares only claims that could contradict.** A
  contradiction needs one claim saying "outperforms" and another saying "is
  outperformed by". Claims are now split by which of the two they say, and
  only pairs with one claim from each side are compared. When one side is
  empty nothing is compared: synthetic claims shaped like that graph now take
  0.042 seconds.
- **`lint` got the same fix.** Its `CONTRADICTING_CLAIMS` check walked the
  same every-pair loop.
- **Results are unchanged.** Both return exactly what they returned before,
  checked against the old code on thousands of random graphs.

## Upgrade

Nothing to migrate. A graph with thousands of claims on both sides of one
topic still takes time, because each of those pairs is part of the answer.
