Released **2026-08-24** · [PyPI](https://pypi.org/project/tesserae/0.33.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.33.1) · `pip install --upgrade tesserae==0.33.1`

A patch release about the answer prompt, and about the controls that were
supposed to be watching it. Both turned out to be measuring something other
than what they claimed.

## Every ranked document was pasted twice

`_build_synthesis_message` runs two lanes over one corpus. The document lane
recorded what it emitted under the unit directory that indexes a document — a
paper is `abstract.md` plus `paper.md`, keyed on the directory holding them.
The hit lane then asked whether a *file* path was in that set. A file path is
never equal to its parent directory, so the guard matched nothing, and every
document the fusion lane had already pasted was pasted a second time, verbatim.

On the demo corpus that duplicate was **15.6% of every absent-relation prompt** —
a sixth of the input-token bill of every planner answer, spent showing the model
text it had already been shown. `_unit_of` now gives both lanes one key space,
and emission rather than the decision to read is what marks a unit as emitted.

## A block gets in only if it shares a rare word with the question

The synthesis prompt was the hybrid baseline's prompt plus a weaker second lane:
a median of ~8 extra blocks and 30.7% of the evidence characters. That bought
gold coverage 0.388 against 0.303 — and fabrication on the abstention controls
of **52.9% against 38.2%**. More near-miss material raises both, by one mechanism.

Rank cannot separate the extra lane's useful blocks from its near misses;
discrimination on it measured AUC 0.474, which is chance. Scarcity can. A
question term occurring in at most 5% of the corpus anchors a block to *that*
question. The fusion top-10 and the `kg:` blocks still pass unconditionally, so
the arm producing the tied token F1 is byte-for-byte unaltered — verified across
all 352 demo questions, 0 document blocks and 0 kg blocks changed.

## The protocol gate rejected the truth and accepted the fiction

Asked whether a published-benchmark comparison was one key away, the gate that
exists to stop unquotable claims could be satisfied by typing flags. A
hand-written `answers.json` asserting all four controls returned no blockers; an
honest run against the real OpenAI embedder **failed**, because the backend names
itself `openai:text-embedding-3-small` while the protocol held the bare model.

Declarations are now claims that require evidence, recording `answer_calls` and
`judge_calls`, because a run can record what it did and a hand-written file
cannot. And the judge control is now unmeetable by any run, deliberately and
visibly: there is no judge implementation in this repository, so the gate says
so instead of letting a flag default stand in for the thing.

## Paired systems get a paired test

Two systems scored on the same questions are paired data, and comparing their
marginal rates discards the pairing. On the fabrication question that is
decisive: 6/48 against 2/48 is Fisher **p = 0.268**, and enlarging the probe set
does not help, because a marginal test cannot see whether the two systems failed
on the same questions or on different ones.

`mcnemar` conditions on the discordant pairs, exact two-sided binomial rather
than chi-square because this benchmark produces counts in single digits.
`n_discordant` is returned deliberately — it, not the total, is the sample size.

## Controls a corpus-free rule cannot beat

The original 48 abstention controls did not measure abstention. At 31 words
against the live set's 57, "refuse anything under 40 tokens" — a rule with no
access to the corpus at all — scored 2.1% hallucination and 4.6% over-refusal,
beating every genuine knowledge signal. Every hallucination number reported
before today came off that set.

They are replaced by 68 controls, authored length-matched and then attacked
rather than accepted. On the new set the old exploit scores **100%** hallucination
at the same over-refusal, and word count alone falls from AUC 0.988 to 0.456.
