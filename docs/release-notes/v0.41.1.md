Released **2026-09-12** · [PyPI](https://pypi.org/project/tesserae/0.41.1/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.1) · `pip install --upgrade tesserae==0.41.1`

Every command in the CLI was audited by running it, not by reading it. Six
defects survived reproduction and an adversarial second opinion. Three of them
deleted files.

## What changed

- **Three exporters no longer delete whatever `--output` names.** `export
  site`, `export kuzu` and `export okf` each opened by removing their
  destination, and that destination is a path you type. A directory holding
  two files held 54 after one `export site --output`, and the originals were
  gone. The OKF sweep is recursive, so it reached documents in subdirectories
  no bundle ever writes to.
- **A destination that is not a previous export is refused.** The test is not
  "is it empty", because re-exporting over your own output has to stay silent.
  Each exporter recognises its own work instead: the site by its files, Kuzu by
  the `KUZU` magic in the file itself rather than the name, a bundle by
  `index.md` and `log.md`. Anything else needs `--overwrite`.
- **`--overwrite`, deliberately not `--force`.** `export site --force` already
  means "deploy with a dirty tree". Giving one flag two meanings is how somebody
  deletes a folder while trying to publish one.
- **`export site` reports where the site actually is.** Since v0.40.0 it printed
  the staging directory, which the atomic swap deletes on its way out, so the
  path in front of you was already gone.
- **`graph-map --scope org:root` returns the agent tree instead of crashing.**
  It is the only entry point into the agent memory hierarchy, and on any real
  project it raised a `RecursionError`: the org root is an agent node, anything
  undeclared reports to the root, so the root reported to itself and the walk
  never ended. The walk is iterative now, and a parent cycle degrades instead
  of taking the server down.
- **`distill` can serve the agents it exists for.** It failed for every agent
  with real history: the busiest rendered 79,445 characters against a
  48,000-character one-read bound, and truncation only sheds index entries, so
  the one lever available could not move the number that mattered. The bound
  stays the default because it protects something real. `--artifact-chars N` is
  now a declared way past it, and the refusal tells you the command to run.

## Upgrade

Nothing to migrate. If you script `export site`, `export kuzu` or `export okf`
against a directory that holds anything other than a previous export, that call
now exits 2 instead of deleting it; add `--overwrite` if the deletion was the
point.
