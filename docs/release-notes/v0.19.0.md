Released **2026-07-11** · [PyPI](https://pypi.org/project/tesserae/0.19.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.19.0) · `pip install --upgrade tesserae==0.19.0`

The backend end-of-life release. Since v0.18.0 the default knowledge-graph update and retrieval loop has been fully in-house — the typed ResearchGraph pipeline writes the graph (native code-graph extraction included), and `ask` plans retrieval over it with the LLM. This release removes the two bolted-on backends that no longer earned their keep.

## understand-anything: removed

Its sole contribution — merging an externally generated `knowledge-graph.json` of code-structure nodes into the ResearchGraph — has been redundant since the native code-graph extractor shipped. The adapter, refresh module, compile-time merge, deps detection, and setup entries are gone. `tesserae integrations refresh understand-anything` prints a one-line pointer to native code ingest and exits 2. Old configs carrying an understand-anything `external_tools` entry load with a single note; UA-minted nodes in existing graphs remain valid.

## cognee: removed

cognee duplicated the graph *outward* into its own store and never fed anything back; before 0.18 it also leaked log spam and an `OperationalError` fallback into `ask` output on default installs. After one release of off-by-default grace, it is fully removed: the adapter/direct/query modules, the compile-time cognify pass and bundle export, the `[cognee]` extra, wizard prompts, and MCP schema references (~1,100 LOC and 6 test files). `query --backend cognee` and every `--cognee-*` / `--enable-cognee` flag print a one-line removal stub and exit 2. Configs carrying a `memory_backends.cognee` section still load and compile — with exactly one note per process.

## rag-anything: kept, on purpose

The one backend with a capability the knowledge graph genuinely lacks — multimodal document RAG (PDFs, images) — stays as the optional `tesserae[raganything]` extra, off by default, reachable via `tesserae query --backend raganything`.

## Breaking changes

Per the project convention, nothing fails silently — every removed surface prints its replacement or an explanation and exits 2: `integrations refresh understand-anything`, `query --backend cognee`, `--cognee-search-type`, `--cognee-dataset`, `--enable-cognee` and the remaining `--cognee-*` setup/extract flags. Net effect of the two removals: **−5,500 lines** against +1,600, with the full test suite green (2,251 passed).
