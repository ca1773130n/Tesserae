Released **2026-08-17** · [PyPI](https://pypi.org/project/tesserae/0.32.0/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.32.0) · `pip install --upgrade tesserae==0.32.0`

A graph with sixty thousand nodes has the problem a company with sixty thousand
employees has. You cannot walk in the front door and start reading. Until now
the entry point handed an agent the biggest nodes it had, ranked by size, and
left it to work out what they were for. On this project's own graph that came to
1,852 unnamed cards in 32.5 seconds — a directory of every desk in the building,
sorted by desk.

This release gives the graph an org chart.

## The charter

A compile now derives an institution from the corpus. Divisions, departments and
teams, each one a domain with a name a person would recognise and an anchor that
can be pointed at. Entry goes through that tree instead of through a size rank,
and on the same graph that is four titled cards in 1.6 seconds.

`graph_map` opens on a directory of names, and a card with no name is not
promoted for being large. `charter_route` places a task three tiers into the
tree, or it names nothing at all — a router that always answers is a router
that is sometimes confidently wrong, and this one would rather abstain. Behind
each domain sits a brief: a community summary keyed on the domain's slug,
generated once and cached, which is the readable paragraph an agent gets instead
of a node dump.

A domain is dated by its sources, and says so when it cannot be dated at all.
That distinction matters more than it sounds. A derived date presented as a fact
is how a graph starts asserting things its corpus never said.

The `engine` daemon warms briefs during idle ticks, so readers stop arriving at
domains with nothing written behind them, and two new lint probes check the
charter file on disk rather than the object in memory — those being the two
things that drift apart. Measured on Tesserae's own corpus: 1,411 domains, of
which 1,410 warm. The one that stays cold is the census domain, which never
warms by design.

## Retrieval stops paying twice

Four changes here, and all four remove work that was being redone. Vectors now
persist, so a query stops re-embedding a corpus it already embedded. The BM25
lane stops rebuilding the corpus on every query. The embedding lane scores the
corpus as a single matrix product rather than a loop. And a query reports what
each lane cost, which turns a slow answer into something you can attribute
instead of guess at.

Alongside those, retrieval gained a view registry — named edge partitions with
view-scoped traversal — and multi-view traversal with rank fusion, where a
result can say which view produced it.

## Time, and being wrong on purpose

The sidecar gains a transaction-time axis, and one clock stops calling itself
two. When a fact is superseded, `resolved_by` closes the interval from the
losing side: the fact that lost records what replaced it, rather than the winner
claiming the ground. Facts are searched as content now, and *undated* became a
predicate you can ask for instead of a gap you have to notice.

Being wrong is handled more directly than before. An agent can retract a fact —
say "this is wrong" — without being forced to invent a replacement for it. A
dead node id resolves to its survivor, so merging two nodes no longer turns
every prior reference into a dangling pointer. A candidate pair rejected in one
run stays rejected in the next. And a read can name its reader, when someone
asks it to.

## Evidence over claims

This release spent real effort on the least glamorous thing a project can do,
which is checking whether its own README was true.

Tesserae now answers Neo4j's TCK, and fails 34 of its 93 conformance queries on
purpose: 57 of 93 Bronze, 0 of 67 Silver. The tier is stated rather than
implied. There is a QA scorer, so a competitor run produces a number instead of
a narrative. On LongMemEval-MAB, BM25 scores 0.843 against dense retrieval's
0.473 recall@10, measured for free and repeatable — both of those are baselines,
and Tesserae's own arm on that benchmark is **not yet measured**, which the
report says outright rather than letting the table imply otherwise.

There is also a harness for the harder question: whether a memory improves when
the corpus does *not*. It freezes a corpus, runs consolidation over it, and
re-measures. Two properties fell out of building it. Association costs zero LLM
calls, because it is cosine similarity over the local embedder. And it is
idempotent, so on a frozen corpus the honest shape of the curve is a step rather
than a ramp — which is a narrower claim than "improves continuously without
input", and the one that survives someone running three cycles to check.

Seven overstated claims in the docs were corrected, and three comparative claims
retracted outright because nothing in the repository measured them.

## Documentation that cannot silently rot

Every doc under `docs/` is mirrored into seven languages. A mechanical parity
ratchet now runs across all 553 mirrors: a translation may not drop an
identifier or a structural element that the English has. It cannot catch a wrong
translation, only a missing one, so it ships next to a glossary of the terms
that have been mistranslated more than once. Four live mistranslations were
cleared against it.

## Also

A compile with no terminal attached narrates itself rather than looking like a
hang, and narrates by default rather than only when asked. Figures, tables and
equations become first-class Artifact evidence nodes; a figure's number belongs
to its document and rides the edge; artifact figures reach the site as bytes.
The compile lock is portable, so Windows appends cannot tear it. Every entry
under `.tesserae/` now says who owns it and what deleting it costs. And the
ontology growth loop is closed at last — proposals are surfaced and linted,
while promotion stays a human edit.

## Upgrading

```bash
pip install --upgrade tesserae==0.32.0
```

Existing graphs are read as they are, and nothing here forces a rebuild. The
charter is derived on the next compile, and the rest of the engine works without
it — a project that never compiles again keeps the graph it has.
