Released **2026-09-16** · [PyPI](https://pypi.org/project/tesserae/0.41.3/) · [GitHub release](https://github.com/ca1773130n/Tesserae/releases/tag/v0.41.3) · `pip install --upgrade tesserae==0.41.3`

v0.41.2 closed the twelve most serious findings from the command audit. This
closes the other nineteen, which is all of them.

## What changed

- **Seven commands answer a mistake with a sentence.** A bad path, an
  unparseable date, a config value that is not a provider: each of these used
  to end in a stack trace. The worst was `tesserae compile`, which aborted a
  whole corpus over a single unreadable file; it now names what it skipped and
  compiles the rest.
- **Seven commands stopped reporting what did not happen.** `status` showed a
  compile time for a project that had never been compiled. `config status`
  credited settings to the default when a file had set them. `schema-drift`
  said clustering found nothing for a type it never clustered. `graph-map`
  returned a paging cursor identical to the one it was given, so a caller that
  followed it looped forever.
- **Five commands stopped accepting what they should refuse.** A misspelled
  agent name answered as though it were real. `projects register` silently
  deregistered another project when two directories produced the same name.
  `domains status` told a directory that is not a project to run a compile.
- **A preview previews the thing it previews.** `sessions prune-internal
  --dry-run` printed the total number of stored records where it meant the
  number it would delete.

## Upgrade

Nothing to migrate. More commands exit 2 where they used to exit 0 quietly, so
a script that relied on the silence will start reporting failures it was
already having.
